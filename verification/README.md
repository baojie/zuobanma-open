## 精答是怎么核验的

1. **检索**：从问题里抽检索词，在三书原文里检索，选出相关段落组成本题的证据包。
2. **写作**：AI 只依据证据包写答案，每句挂 PN，直接引用原文时加引号或用引用块。
3. **核验**：程序逐条检查——PN 是否存在、是否在证据包里；直引是否与所挂 PN 的原文逐字吻合。
4. **改正**：有问题时，把问题清单交回 AI 改一轮，再核验一次，然后发布。
5. **重核**：导出本仓库时，用当时的原文把已发布的答案再核一遍，结果写在每份记录的「按现行语料重核」一节。
