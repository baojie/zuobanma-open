### 经

<a id="ZZ-066-001"></a>[\[ZZ-066-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-001) 三年春，王正月，不雨。

<a id="ZZ-066-002"></a>[\[ZZ-066-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-002) 夏，四月，不雨。徐人取舒。

<a id="ZZ-066-003"></a>[\[ZZ-066-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-003) 六月，雨。

<a id="ZZ-066-004"></a>[\[ZZ-066-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-004) 秋，齐侯、宋公、江人、黄人会于阳谷。

<a id="ZZ-066-005"></a>[\[ZZ-066-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-005) 冬，公子友如齐莅盟。楚人伐郑。

### 传

<a id="ZZ-066-006"></a>[\[ZZ-066-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-006) 三年春，不雨。

<a id="ZZ-066-007"></a>[\[ZZ-066-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-007) 夏，六月，雨。自十月不雨，至于五月，不曰旱，不为灾也。

<a id="ZZ-066-008"></a>[\[ZZ-066-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-008) 秋，会于阳谷，谋伐楚也。齐侯为阳谷之会，来寻盟。

<a id="ZZ-066-009"></a>[\[ZZ-066-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-009) 冬，公子友如齐莅盟。

<a id="ZZ-066-010"></a>[\[ZZ-066-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-010) 楚人伐郑，郑伯欲成。孔叔不可，曰：「齐方勤我，弃德不祥。」

<a id="ZZ-066-011"></a>[\[ZZ-066-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-066-011) 齐侯与蔡姬乘舟于囿，荡公。公惧，变色。禁之，不可。公怒，归之，未之绝也。蔡人嫁之。
