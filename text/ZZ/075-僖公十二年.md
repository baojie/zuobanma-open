### 经

<a id="ZZ-075-001"></a>[\[ZZ-075-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-001) 十有二年春，王三月，庚午，日有食之。

<a id="ZZ-075-002"></a>[\[ZZ-075-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-002) 夏，楚人灭黄。

<a id="ZZ-075-003"></a>[\[ZZ-075-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-003) 秋，七月。

<a id="ZZ-075-004"></a>[\[ZZ-075-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-004) 冬，十有二月，丁丑，陈侯杵臼卒。

### 传

<a id="ZZ-075-005"></a>[\[ZZ-075-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-005) 十二年春，诸侯城卫楚丘之郛，惧狄难也。

<a id="ZZ-075-006"></a>[\[ZZ-075-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-006) 黄人恃诸侯之睦于齐也，不共楚职，曰：「自郢及我九百里，焉能害我？」

<a id="ZZ-075-007"></a>[\[ZZ-075-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-007) 夏，楚灭黄。

<a id="ZZ-075-008"></a>[\[ZZ-075-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-008) 王以戎难故，讨王子带。

<a id="ZZ-075-009"></a>[\[ZZ-075-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-009) 秋，王子带奔齐。

<a id="ZZ-075-010"></a>[\[ZZ-075-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-010) 冬，齐侯使管夷吾平戎于王，使隰朋平戎于晋。

<sub>被引：[Q73](../../qa/Q73.md)、[Q183](../../qa/Q183.md)</sub>

<a id="ZZ-075-011"></a>[\[ZZ-075-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-075-011) 王以上卿之礼飨管仲，管仲辞曰：「臣，贱有司也。有天子之二守国、高在，若节春秋，来承王命，何以礼焉？陪臣敢辞。」王曰：「舅氏，余嘉乃勋，应乃懿德，谓督不忘。往践乃职，无逆朕命。」管仲受下卿之礼而还。
