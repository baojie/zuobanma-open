### 经

<a id="ZZ-115-001"></a>[\[ZZ-115-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-001) 元年春王正月，公即位。公子遂如齐逆女。

<a id="ZZ-115-002"></a>[\[ZZ-115-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-002) 三月，遂以夫人妇姜至自齐。

<a id="ZZ-115-003"></a>[\[ZZ-115-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-003) 夏，季孙行父如齐。晋放其大夫胥甲父于卫。公会齐侯于平州。公子遂如齐。

<a id="ZZ-115-004"></a>[\[ZZ-115-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-004) 六月，齐人取济西田。

<a id="ZZ-115-005"></a>[\[ZZ-115-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-005) 秋，邾子来朝。楚子、郑人，侵陈，遂侵宋。晋赵盾帅师救陈。宋公、陈侯、卫侯、曹伯，会晋师于棐林，伐郑。

<sub>被引：[赵盾](../../entries/person/%E8%B5%B5%E7%9B%BE.md)</sub>

<a id="ZZ-115-006"></a>[\[ZZ-115-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-006) 冬，晋赵穿帅师侵崇。晋人、宋人，伐郑。

### 传

<a id="ZZ-115-007"></a>[\[ZZ-115-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-007) 元年春王正月，公子遂如齐逆女，尊君命也。

<a id="ZZ-115-008"></a>[\[ZZ-115-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-008) 三月，遂以夫人妇姜至自齐，尊夫人也。

<a id="ZZ-115-009"></a>[\[ZZ-115-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-009) 夏，季文子如齐，纳赂，以请会。晋人讨不用命者，放胥甲父于卫，而立胥克，先辛奔齐。会于平州，以定公位。东门襄仲如齐拜成。

<a id="ZZ-115-010"></a>[\[ZZ-115-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-010) 六月，齐人取济西之田。为立公故，以赂齐也。宋人之弑昭公也，晋荀林父以诸侯之师伐宋。宋及晋平，宋文公受盟于晋。又会诸侯于扈，将为鲁讨齐，皆取赂而还。郑穆公曰：「晋不足与也。」遂受盟于楚。陈共公之卒，楚人不礼焉。陈灵公受盟于晋。

<a id="ZZ-115-011"></a>[\[ZZ-115-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-011) 秋，楚子侵陈，遂侵宋。晋赵盾帅师救陈宋，会于棐林，以伐郑也。楚𫇭贾救郑，遇于北林，囚晋解扬，晋人乃还。晋欲求成于秦，赵穿曰：「我侵崇，秦急崇必救之，吾以求成焉。」

<a id="ZZ-115-012"></a>[\[ZZ-115-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-115-012) 冬，赵穿侵崇，秦弗与成。晋人伐郑，以报北林之役。于是晋侯侈，赵宣子为政，骤谏而不入，故不竞于楚。
