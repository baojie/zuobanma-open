### 经

<a id="ZZ-019-001"></a>[\[ZZ-019-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-001) 八年，春，正月己卯，烝。天王使家父来聘。

<a id="ZZ-019-002"></a>[\[ZZ-019-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-002) 夏，五月丁丑，烝。

<a id="ZZ-019-003"></a>[\[ZZ-019-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-003) 秋，伐邾。

<a id="ZZ-019-004"></a>[\[ZZ-019-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-004) 冬，十月，雨雪。祭公来，遂逆王后于纪。

### 传

<a id="ZZ-019-005"></a>[\[ZZ-019-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-005) 八年，春，灭翼。随少师有宠。楚斗伯比曰：「可矣。雠有衅，不可失也。」

<a id="ZZ-019-006"></a>[\[ZZ-019-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-006) 夏，楚子合诸侯于沈鹿。黄、随不会，使䓕章让黄。楚子伐随，军于汉淮之间。季梁请下之：「弗许而后战，所以怒我而怠寇也。」少师谓随侯曰：「必速战，不然，将失楚师。」随侯御之，望楚师，季梁曰：「楚人上左，君必左，无与王遇，且攻其右。右无良焉，必败。偏败，众乃携矣。」少师曰：「不当王，非敌也。」弗从。战于速杞，随师败绩。随侯逸，斗丹获其戎车，与其戎右少师。

<a id="ZZ-019-007"></a>[\[ZZ-019-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-007) 秋，随及楚平。楚子将不许。斗伯比曰：「天去其疾矣，随未可克也。」乃盟而还。

<a id="ZZ-019-008"></a>[\[ZZ-019-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-019-008) 冬，王命虢仲立晋哀侯之弟缗于晋。祭公来，遂逆王后于纪，礼也。
