### 经

<a id="ZZ-141-001"></a>[\[ZZ-141-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-001) 九年春。王正月。杞伯来逆叔姬之丧以归。公会晋侯。齐侯。宋公。卫侯。郑伯。曹伯。莒子。杞伯。同盟于蒲。公至自会。

<a id="ZZ-141-002"></a>[\[ZZ-141-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-002) 二月。伯姬归于宋。

<a id="ZZ-141-003"></a>[\[ZZ-141-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-003) 夏。季孙行父如宋致女。晋人来媵。

<a id="ZZ-141-004"></a>[\[ZZ-141-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-004) 秋。七月。丙子。齐侯无野卒。晋人执郑伯。晋栾书帅师伐郑。

<sub>被引：[栾书](../../entries/person/%E6%A0%BE%E4%B9%A6.md)</sub>

<a id="ZZ-141-005"></a>[\[ZZ-141-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-005) 冬。十有一月。葬齐顷公。楚公子婴齐帅师伐莒。庚申。莒溃。楚人入郓。秦人白狄伐晋。郑人围许。城中城。

### 传

<a id="ZZ-141-006"></a>[\[ZZ-141-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-006) 九年春。杞桓公来逆叔姬之丧。请之也。杞叔姬卒。为杞故也。逆叔姬。为我也。为归汶阳之田。故诸侯贰于晋。晋人惧。会于蒲。以寻马陵之盟。季文子谓范文子曰。德则不竞。寻盟何为。范文子曰。勤以抚之。宽以待之。坚彊以御之。明神以要之。柔服而伐贰。德之次也。是行也。将始会吴。吴人不至。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-141-007"></a>[\[ZZ-141-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-007) 二月。伯姬归于宋。楚人以重赂求郑。郑伯会楚公子成于邓。

<a id="ZZ-141-008"></a>[\[ZZ-141-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-008) 夏‧季文子如宋致女。复命。公享之。赋韩奕之五章。穆姜出于房。再拜曰。大夫勤辱。不忘先君。以及嗣君。施及未亡人。先君犹有望也。敢拜大夫之重勤。又赋绿衣之卒章而入。晋人来媵。礼也。

<a id="ZZ-141-009"></a>[\[ZZ-141-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-009) 秋。郑伯如晋。晋人讨其贰于楚也。执诸铜鞮。栾书伐郑。郑人使伯蠲行成。晋人杀之。非礼也。兵交。使在其间可也。楚子重侵陈以救郑。晋侯观于军府。见钟仪。问之曰。南冠而絷者。谁也。有司对曰。郑人所献楚囚也。使税之。召而吊之。再拜稽首。问其族。对曰。泠人也。公曰。能乐乎。对曰。先父之职官也。敢有二事。使与之琴。操南音。公曰。君王何如。对曰。非小人之所得知也。固问之。对曰。其为大子也。师保奉之。以朝于婴齐。而夕于侧也。不知其他。公语范文子。文子曰。楚囚。君子也。言称先职。不背本也。乐操土风。不忘旧也。称大子。抑无私也。名其二卿。尊君也。不背本。仁也。不忘旧。信也。无私。忠也。尊君。敏也。仁以接事。信以守之。忠以成之。敏以行之。事虽大必济。君盍归之。使合晋楚之成。公从之。重为之礼。使归求成。

<a id="ZZ-141-010"></a>[\[ZZ-141-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-010) 冬。十一月。楚子重自陈伐莒。围渠丘。渠丘城恶。众溃。奔莒。戊申。楚入渠丘。莒人囚楚公子平。楚人曰。勿杀。吾归而俘。莒人杀之。楚师围莒。莒城亦恶。庚申。莒溃。楚遂入郓。莒无备故也。君子曰。恃陋而不备。罪之大者也。备豫不虞。善之大者也。莒恃其陋。而不修城郭。浃辰之间。而楚克其三都。无备也夫。诗曰。虽有丝麻。无弃菅蒯。虽有姬姜。无弃蕉萃。凡百君子。莫不代匮。言备之不可以已也。秦人白狄伐晋。诸侯贰故也。郑人围许。示晋不急君也。是则公孙申谋之曰。我出师以围许。为将改立君者。而纾晋使。晋必归君。城中城。书时也。

<a id="ZZ-141-011"></a>[\[ZZ-141-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-141-011) 十二月。楚子使公子辰如晋。报钟仪之使。请修好结成。
