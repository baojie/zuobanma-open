### 经

<a id="ZZ-038-001"></a>[\[ZZ-038-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-001) 九年春，齐人杀无知。公及齐大夫盟于蔇。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-038-002"></a>[\[ZZ-038-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-002) 夏，公伐齐纳子纠。齐小白入于齐。

<sub>被引：[Q26](../../qa/Q26.md)</sub>

<a id="ZZ-038-003"></a>[\[ZZ-038-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-003) 秋七月丁酉，葬齐襄公。

<sub>被引：[Q115](../../qa/Q115.md)</sub>

<a id="ZZ-038-004"></a>[\[ZZ-038-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-004) 八月庚申，及齐师战于干时，我师败绩。九月，齐人取子纠杀之。

<a id="ZZ-038-005"></a>[\[ZZ-038-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-005) 冬，浚洙。

### 传

<a id="ZZ-038-006"></a>[\[ZZ-038-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-006) 九年春，雍廪杀无知。

<a id="ZZ-038-007"></a>[\[ZZ-038-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-007) 公及齐大夫盟于蔇，齐无君也。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-038-008"></a>[\[ZZ-038-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-008) 夏，公伐齐，纳子纠。桓公自莒先入。

<sub>被引：[Q26](../../qa/Q26.md)</sub>

<a id="ZZ-038-009"></a>[\[ZZ-038-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-009) 秋，师及齐师战于干时，我师败绩，公丧戎路，传乘而归。秦子、梁子以公旗辟于下道，是以皆止。

<a id="ZZ-038-010"></a>[\[ZZ-038-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-038-010) 鲍叔帅师来言曰：『子纠，亲也，请君讨之。管、召、仇也，请受而甘心焉。』乃杀子纠于生窦，召忽死之。管仲请囚，鲍叔受之，及堂阜而税之。归而以告曰：『管夷吾治于高傒，使相可也。』公从之。

<sub>被引：[管仲](../../entries/person/%E7%AE%A1%E4%BB%B2.md)、[Q73](../../qa/Q73.md)、[Q183](../../qa/Q183.md)</sub>
