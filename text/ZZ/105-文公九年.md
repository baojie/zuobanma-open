### 经

<a id="ZZ-105-001"></a>[\[ZZ-105-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-001) 春，毛伯来求金，夫人姜氏如齐。

<a id="ZZ-105-002"></a>[\[ZZ-105-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-002) 二月，叔孙得臣如京师。辛丑，葬襄王。晋人杀其大夫先都。

<a id="ZZ-105-003"></a>[\[ZZ-105-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-003) 三月，夫人姜氏至自齐。
<a id="ZZ-105-004"></a>[\[ZZ-105-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-004) 晋人杀其大夫士縠，及箕郑父。
<a id="ZZ-105-005"></a>[\[ZZ-105-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-005) 楚人伐郑。公子遂会晋人、宋人、卫人、许人，救郑。

<a id="ZZ-105-006"></a>[\[ZZ-105-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-006) 夏，狄侵齐。

<a id="ZZ-105-007"></a>[\[ZZ-105-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-007) 秋，八月，曹伯襄卒。

<sub>被引：[Q178](../../qa/Q178.md)</sub>

<a id="ZZ-105-008"></a>[\[ZZ-105-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-008) 九月，癸酉，地震。

<sub>被引：[Q120](../../qa/Q120.md)</sub>

<a id="ZZ-105-009"></a>[\[ZZ-105-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-009) 冬，楚子使椒来聘。秦人来归僖公成风之襚，葬曹共公。

### 传

<a id="ZZ-105-010"></a>[\[ZZ-105-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-010) 春，王正月，己酉，使贼杀先克。
<a id="ZZ-105-011"></a>[\[ZZ-105-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-011) 乙丑，晋人杀先都，梁益耳。
<a id="ZZ-105-012"></a>[\[ZZ-105-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-012) 毛伯卫来求金，非礼也。不书王命，未葬也。

<a id="ZZ-105-013"></a>[\[ZZ-105-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-013) 二月，庄叔如周葬襄王。

<a id="ZZ-105-014"></a>[\[ZZ-105-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-014) 三月，甲戌，晋人杀箕郑父，士縠，蒯得。
<a id="ZZ-105-015"></a>[\[ZZ-105-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-015) 范山言于楚子曰：「晋君少，不在诸侯，北方可图也。」

<sub>[二校](../../collation/review.md)：改字 1 处</sub>
<a id="ZZ-105-016"></a>[\[ZZ-105-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-016) 楚子师于狼渊以伐郑，囚公子坚，公子尨，及乐耳。
<a id="ZZ-105-017"></a>[\[ZZ-105-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-017) 郑及楚平，公子遂会晋赵盾、宋华耦、卫孔达、许大夫，救郑，不及楚师。
<a id="ZZ-105-018"></a>[\[ZZ-105-018\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-018) 卿不书，缓也，以惩不恪。

<a id="ZZ-105-019"></a>[\[ZZ-105-019\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-019) 夏，楚侵陈，克壶丘，以其服于晋也。

<a id="ZZ-105-020"></a>[\[ZZ-105-020\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-020) 秋，楚公子朱自东夷伐陈，陈人败之，获公子茷。
<a id="ZZ-105-021"></a>[\[ZZ-105-021\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-021) 陈惧，乃及楚平。

<a id="ZZ-105-022"></a>[\[ZZ-105-022\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-022) 冬，楚子越椒来聘，执币傲。
<a id="ZZ-105-023"></a>[\[ZZ-105-023\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-023) 叔仲惠伯曰：「是必灭若敖氏之宗，傲其先君，神弗福也。」

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-105-024"></a>[\[ZZ-105-024\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-024) 秦人来归僖公成风之襚，礼也。
<a id="ZZ-105-025"></a>[\[ZZ-105-025\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-105-025) 诸侯相吊贺也，虽不当事，苟有礼焉，书也，以无忘旧好。
