### 经

<a id="ZZ-073-001"></a>[\[ZZ-073-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-001) 十年春，王正月，公如齐。狄灭温，温子奔卫。晋里克弑其君卓，及其大夫荀息。

<sub>被引：[Q118](../../qa/Q118.md)</sub>

<a id="ZZ-073-002"></a>[\[ZZ-073-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-002) 夏，齐侯、许男伐北戎。晋杀其大夫里克。

<a id="ZZ-073-003"></a>[\[ZZ-073-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-003) 秋，七月。

<a id="ZZ-073-004"></a>[\[ZZ-073-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-004) 冬，大雨雪。

### 传

<a id="ZZ-073-005"></a>[\[ZZ-073-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-005) 十年春，狄灭温，苏子无信也。苏子叛王即狄，又不能于狄，狄人伐之，王不救，故灭。苏子奔卫。

<a id="ZZ-073-006"></a>[\[ZZ-073-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-006) 夏，四月，周公忌父、王子党，会齐隰朋，立晋侯。晋侯杀里克以说。将杀里克，公使谓之曰：「微子则不及此。虽然，子弑二君与一大夫，为子君者，不亦难乎？」对曰：「不有废也，君何以兴？欲加之罪，其无辞乎？臣闻命矣。」伏剑而死。于是丕郑聘于秦，且谢缓赂，故不及。

<sub>被引：[Q60](../../qa/Q60.md)、[Q118](../../qa/Q118.md) · 对读：[SJ-039-040](../SJ/039-%E6%99%8B%E4%B8%96%E5%AE%B6.md#SJ-039-040)</sub>

<a id="ZZ-073-007"></a>[\[ZZ-073-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-007) 晋侯改葬共大子。

<a id="ZZ-073-008"></a>[\[ZZ-073-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-008) 秋，狐突适下国，遇大子。大子使登仆，而告之曰：「夷吾无礼，余得请于帝矣，将以晋畀秦，秦将祀余。」对曰：「臣闻之，神不歆非类，民不祀非族，君祀无乃殄乎！且民何罪？失刑乏祀，君其图之。」君曰：「诺，吾将复请。七日，新城西偏，将有巫者而见我焉。」许之，遂不见。及期而往，告之曰：「帝许我罚有罪矣，敝于韩。」

<sub>对读：[SJ-039-041](../SJ/039-%E6%99%8B%E4%B8%96%E5%AE%B6.md#SJ-039-041)</sub>

<a id="ZZ-073-009"></a>[\[ZZ-073-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-009) 丕郑之如秦也，言于秦伯曰：「吕甥、郤称、冀芮实为不从。若重问以召之，臣出晋君，君纳重耳，蔑不济矣。」

<sub>被引：[Q44](../../qa/Q44.md)</sub>

<a id="ZZ-073-010"></a>[\[ZZ-073-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-010) 冬，秦伯使泠至报问，且召三子。郤芮曰：币重而言甘，诱我也。遂杀丕郑、祁举及七舆大夫：左行共华、右行贾华、叔坚、骓歂、累虎、特宫、山祁，皆里丕之党也。

<sub>被引：[Q44](../../qa/Q44.md)</sub>

<a id="ZZ-073-011"></a>[\[ZZ-073-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-073-011) 丕豹奔秦，言于秦伯曰：「晋侯背大主而忌小怨，民弗与也。伐之必出。」公曰：「失众，焉能杀？违祸，谁能出君？」
