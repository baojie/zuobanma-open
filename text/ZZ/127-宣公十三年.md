### 经

<a id="ZZ-127-001"></a>[\[ZZ-127-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-001) 十有三年春，齐师伐莒。

<a id="ZZ-127-002"></a>[\[ZZ-127-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-002) 夏，楚子伐宋。

<a id="ZZ-127-003"></a>[\[ZZ-127-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-003) 秋，螽。

<a id="ZZ-127-004"></a>[\[ZZ-127-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-004) 冬，晋杀其大夫先縠。

### 传

<a id="ZZ-127-005"></a>[\[ZZ-127-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-005) 十三年春，齐师伐莒，莒恃晋而不事齐故也。

<a id="ZZ-127-006"></a>[\[ZZ-127-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-006) 夏，楚子伐宋，以其救萧也。君子曰：「清丘之盟，唯宋可以免焉。」

<a id="ZZ-127-007"></a>[\[ZZ-127-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-007) 秋，赤狄伐晋，及清。先縠召之也。

<a id="ZZ-127-008"></a>[\[ZZ-127-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-127-008) 冬，晋人讨邲之败，与清之师，归罪于先縠而杀之，尽灭其族。君子曰：「恶之来也，己则取之，其先縠之谓乎？清丘之盟，晋以卫之救陈也，讨焉，使人弗去，曰：『罪无所归，将加而师。』孔达曰：『苟利社稷，请以我说。罪我之由，我则为政，而亢大国之讨，将以谁任？我则死之。』」
