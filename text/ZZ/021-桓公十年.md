<a id="ZZ-021-004"></a>[\[ZZ-021-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-004) 冬，十有二月丙午，齐侯、卫侯、郑伯来战于郎。

### 传

<a id="ZZ-021-005"></a>[\[ZZ-021-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-005) 十年春，曹桓公卒。

<a id="ZZ-021-006"></a>[\[ZZ-021-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-006) 虢仲谮其大夫詹父于王。詹父有辞，以王师伐虢。夏，虢公出奔虞。

<a id="ZZ-021-007"></a>[\[ZZ-021-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-007) 秋，秦人纳芮伯万于芮。

<a id="ZZ-021-008"></a>[\[ZZ-021-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-008) 初，虞叔有玉，虞公求旃。弗献。既而悔之。曰：「周谚有之：『匹夫无罪，怀璧其罪。』吾焉用此，其以贾害也？」乃献之。又求其宝剑。叔曰：「是无厌也。无厌，将及我。」遂伐虞公，故虞公出奔共池。

<sub>被引：[Q162](../../qa/Q162.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-021-009"></a>[\[ZZ-021-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-009) 冬，齐、卫、郑来战于郎，我有辞也。

<a id="ZZ-021-010"></a>[\[ZZ-021-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-021-010) 初，北戎病齐，诸侯救之。郑公子忽有功焉。齐人饩诸侯，使鲁次之。鲁以周班后郑。郑人怒，请师于齐。齐人以卫师助之。故不称侵伐。先书齐、卫，王爵也。
