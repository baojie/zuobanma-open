### 经

<a id="ZZ-071-001"></a>[\[ZZ-071-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-001) 八年春，王正月。公会王人、齐侯、宋公、卫侯、许男、曹伯、陈世子款盟于洮。郑伯乞盟。

<a id="ZZ-071-002"></a>[\[ZZ-071-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-002) 夏，狄伐晋。

<a id="ZZ-071-003"></a>[\[ZZ-071-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-003) 秋，七月，禘于大庙，用致夫人。

<a id="ZZ-071-004"></a>[\[ZZ-071-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-004) 冬，十有二月，丁未，天王崩。

### 传

<a id="ZZ-071-005"></a>[\[ZZ-071-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-005) 八年春，盟于洮，谋王室也。郑伯乞盟，请服也。襄王定位而后发丧。

<a id="ZZ-071-006"></a>[\[ZZ-071-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-006) 晋里克帅师，梁由靡御，虢射为右，以败狄于采桑。梁由靡曰：「狄无耻，从之必大克。」里克曰：「惧之而已，无速众狄。」虢射曰：「期年狄必至，示之弱矣。」

<a id="ZZ-071-007"></a>[\[ZZ-071-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-007) 夏，狄伐晋，报采桑之役也，复期月。

<a id="ZZ-071-008"></a>[\[ZZ-071-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-008) 秋，禘而致哀姜焉，非礼也。凡夫人不薨于寝，不殡于庙，不赴于同，不祔于姑，则弗致也。

<a id="ZZ-071-009"></a>[\[ZZ-071-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-009) 冬，王人来告丧，难故也，是以缓。

<a id="ZZ-071-010"></a>[\[ZZ-071-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-071-010) 宋公疾，大子兹父固请曰：「目夷长且仁，君其立之。」公命子鱼。子鱼辞曰：「能以国让，仁孰大焉？！臣不及也！且又不顺。」遂走而退。
