### 经

<a id="ZZ-119-001"></a>[\[ZZ-119-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-001) 五年春，公如齐。

<a id="ZZ-119-002"></a>[\[ZZ-119-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-002) 夏，公至自齐。

<a id="ZZ-119-003"></a>[\[ZZ-119-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-003) 秋，九月，齐高固来逆叔姬，叔孙得臣卒。

<a id="ZZ-119-004"></a>[\[ZZ-119-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-004) 冬，齐高固及子叔姬来，楚人伐郑。

### 传

<a id="ZZ-119-005"></a>[\[ZZ-119-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-005) 五年春，公如齐，高固使齐侯止公，请叔姬焉。

<a id="ZZ-119-006"></a>[\[ZZ-119-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-006) 夏，公至自齐，书过也。

<a id="ZZ-119-007"></a>[\[ZZ-119-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-007) 秋，九月，齐高固来逆女，自为也，故书曰：「逆叔姬」，卿自逆也。

<a id="ZZ-119-008"></a>[\[ZZ-119-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-119-008) 冬，来，反马也。楚子伐郑，陈及楚平，晋荀林父救郑伐陈。
