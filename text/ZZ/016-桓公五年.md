### 经

<a id="ZZ-016-001"></a>[\[ZZ-016-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-001) 五年春正月，甲戌、己丑，陈侯鲍卒。

<a id="ZZ-016-002"></a>[\[ZZ-016-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-002) 夏，齐侯郑伯如纪。天王使仍叔之子来聘。葬陈桓公。城祝丘。

<a id="ZZ-016-003"></a>[\[ZZ-016-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-003) 秋，蔡人、卫人、陈人从王伐郑。大雩。螽。

<sub>被引：[Q120](../../qa/Q120.md)</sub>

<a id="ZZ-016-004"></a>[\[ZZ-016-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-004) 冬，州公如曹。

### 传

<a id="ZZ-016-005"></a>[\[ZZ-016-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-005) 五年春正月，甲戌，己丑，陈侯鲍卒，再赴也。于是陈乱，文公子佗杀大子免而代之。公疾病而乱作，国人分散，故再赴。

<sub>对读：[SJ-036-008](../SJ/036-%E9%99%88%E6%9D%9E%E4%B8%96%E5%AE%B6.md#SJ-036-008)</sub>

<a id="ZZ-016-006"></a>[\[ZZ-016-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-006) 夏，齐侯、郑伯朝于纪，欲以袭之。纪人知之。

<a id="ZZ-016-007"></a>[\[ZZ-016-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-007) 王夺郑伯政，郑伯不朝。秋，王以诸侯伐郑，郑伯御之。

<a id="ZZ-016-008"></a>[\[ZZ-016-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-008) 王为中军；虢公林父将右军，蔡人、卫人属焉；周公黑肩将左军，陈人属焉。

<sub>被引：[Q60](../../qa/Q60.md)</sub>

<a id="ZZ-016-009"></a>[\[ZZ-016-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-009) 郑子元请为左拒，以当蔡人、卫人；为右拒，以当陈人，曰：「陈乱，民莫有斗心，若先犯之，必奔。王卒顾之，必乱。蔡、卫不枝，固将先奔，既而萃于王卒，可以集事。」从之。曼伯为右拒，祭仲足为左拒，原繁、高渠弥以中军奉公，为鱼丽之陈，先偏后伍，伍承弥缝。战于𦈡葛，命二拒曰：「旝动而鼓。」蔡、卫、陈皆奔，王卒乱，郑师合以攻之，王卒大败。祝聃射王中肩，王亦能军。祝聃请从之。公曰：「君子不欲多上人，况敢陵天子乎！苟自救也，社稷无陨，多矣。」

<a id="ZZ-016-010"></a>[\[ZZ-016-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-010) 夜，郑伯使祭足劳王，且问左右。

<a id="ZZ-016-011"></a>[\[ZZ-016-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-011) 仍叔之子，弱也。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-016-012"></a>[\[ZZ-016-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-012) 秋，大雩，书，不时也。凡祀，启蛰而郊，龙见而雩，始杀而尝，闭蛰而烝。过则书。

<a id="ZZ-016-013"></a>[\[ZZ-016-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-016-013) 冬，淳于公如曹。度其国危，遂不复。
