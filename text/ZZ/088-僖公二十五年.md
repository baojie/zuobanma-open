### 经

<a id="ZZ-088-001"></a>[\[ZZ-088-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-001) 二十有五年春，王正月，丙午，卫侯毁灭邢。

<a id="ZZ-088-002"></a>[\[ZZ-088-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-002) 夏，四月，癸酉，卫侯毁卒。宋荡伯姬来逆妇。宋杀其大夫。

<a id="ZZ-088-003"></a>[\[ZZ-088-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-003) 秋，楚人围陈。纳顿子于顿。葬卫文公。

<a id="ZZ-088-004"></a>[\[ZZ-088-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-004) 冬，十有二月，癸亥，公会卫子、莒庆盟于洮。

### 传

<a id="ZZ-088-005"></a>[\[ZZ-088-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-005) 二十五年春，卫人伐邢，二礼从国子巡城，掖以赴外，杀之。

<a id="ZZ-088-006"></a>[\[ZZ-088-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-006) 正月，丙午。卫侯毁灭邢，同姓也，故名。礼至为铭曰：「余掖杀国子，莫余敢止。」

<a id="ZZ-088-007"></a>[\[ZZ-088-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-007) 秦伯师于河上，将纳王。狐偃言于晋侯曰：「求诸侯莫如勤王。诸侯信之，且大义也。继文之业，而信宣于诸侯，今为可矣。」

<sub>被引：[Q44](../../qa/Q44.md)、[Q164](../../qa/Q164.md)</sub>

<a id="ZZ-088-008"></a>[\[ZZ-088-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-008) 使卜偃卜之，曰：「吉。遇黄帝战于阪泉之兆。」公曰：「吾不堪也。」对曰：「周礼未改，今之王，古之帝也。」公曰：「筮之。」筮之，遇大有之睽，曰：「吉。遇公用享于天子之卦也。战克而王飨，吉孰大焉。且是卦也，天为泽以当日，天子降心以逆公，不亦可乎？大有去睽而复，亦其所也。」

<sub>被引：[Q59](../../qa/Q59.md)、[Q123](../../qa/Q123.md)、[Q153](../../qa/Q153.md)</sub>

<a id="ZZ-088-009"></a>[\[ZZ-088-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-009) 晋侯辞秦师而下。三月，甲辰。次于阳樊，右师围温，左师逆王。

<a id="ZZ-088-010"></a>[\[ZZ-088-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-010) 夏，四月，丁巳。王入于王城，取大叔于温，杀之于隰城。

<a id="ZZ-088-011"></a>[\[ZZ-088-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-011) 戊午，晋侯朝王。王飨醴，命之宥。请隧，弗许，曰：「王章也。未有代德而有二王，亦叔父之所恶也。」与之阳樊、温、原、𪴙茅之田。晋于是始启南阳。

<sub>被引：[Q70](../../qa/Q70.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-088-012"></a>[\[ZZ-088-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-012) 阳樊不服，围之。苍葛呼曰：「德以柔中国，刑以威四夷，宜吾不敢服也。此谁非王之亲姻，其俘之也？」乃出其民。

<a id="ZZ-088-013"></a>[\[ZZ-088-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-013) 秋，秦、晋伐鄀。楚鬭克、屈御寇以申息之师戍商密。秦人过析，隈入而系舆人，以围商密，昏而傅焉。宵，坎血加书，伪与子仪、子边盟者。商密人惧曰：「秦取析矣，戍人反矣！」乃降秦师。秦师囚申公子仪、息公子边以归。楚令尹子玉追秦师，弗及。遂围陈，纳顿子于顿。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-088-014"></a>[\[ZZ-088-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-014) 冬，晋侯围原，命三日之粮。原不降，命去之。谍出，曰：「原将降矣。」军吏曰：「请待之。」公曰：「信，国之宝也，民之所庇也。得原失信，何以庇之？所亡滋多。」退一舍而原降。迁原伯贯于冀。赵衰为原大夫，狐溱为温大夫。

<sub>被引：[Q164](../../qa/Q164.md)</sub>

<a id="ZZ-088-015"></a>[\[ZZ-088-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-015) 卫人平莒于我。

<a id="ZZ-088-016"></a>[\[ZZ-088-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-016) 十二月，盟于洮，修卫文公之好，且及莒平也。

<a id="ZZ-088-017"></a>[\[ZZ-088-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-088-017) 晋侯问原守于寺人勃鞮。对曰：「昔赵衰以壶飧从径，馁而弗食。」故使处原。
