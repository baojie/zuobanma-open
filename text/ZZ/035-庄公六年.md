### 经

<a id="ZZ-035-001"></a>[\[ZZ-035-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-001) 六年春王正月，王人子突救卫。

<a id="ZZ-035-002"></a>[\[ZZ-035-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-002) 夏六月，卫侯朔入于卫。

<a id="ZZ-035-003"></a>[\[ZZ-035-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-003) 秋，公至自伐卫。螟。

<a id="ZZ-035-004"></a>[\[ZZ-035-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-004) 冬，齐人来归卫俘。

### 传

<a id="ZZ-035-005"></a>[\[ZZ-035-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-005) 六年春，王人救卫。

<a id="ZZ-035-006"></a>[\[ZZ-035-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-006) 夏，卫侯入，放公子黔牟于周，放宁跪于秦，杀左公子泄、右公子职，乃即位。

<a id="ZZ-035-007"></a>[\[ZZ-035-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-007) 君子以二公子之立黔牟为不度矣。夫能固位者，必度于本末而后立衷焉。不知其本，不谋。知本之不枝，弗强。《诗》云：『本枝百世。』

<a id="ZZ-035-008"></a>[\[ZZ-035-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-008) 冬，齐人来归卫宝，文姜请之也。

<a id="ZZ-035-009"></a>[\[ZZ-035-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-035-009) 楚文王伐申，过邓。邓祁侯曰：『吾甥也。』止而享之。骓甥、聃甥、养甥请杀楚子，邓侯弗许。三甥曰：『亡邓国者，必此人也。若不早图，后君噬齐。其及图之乎？图之，此为时矣。』邓侯曰：『人将不食吾余。』对曰：『若不从三臣，抑社稷实不血食，而君焉取余？』弗从。还年，楚子伐邓。十六年，楚复伐邓，灭之。
