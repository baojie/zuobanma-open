### 经

<a id="ZZ-029-001"></a>[\[ZZ-029-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-001) 十有八年，春，王正月，公会齐侯于泺。公与夫人姜氏遂如齐。

<a id="ZZ-029-002"></a>[\[ZZ-029-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-002) 夏，四月丙子，公薨于齐。丁酉，公之丧至自齐。

<a id="ZZ-029-003"></a>[\[ZZ-029-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-003) 秋，七月。

<a id="ZZ-029-004"></a>[\[ZZ-029-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-004) 冬，十有二月己丑，葬我君桓公。

### 传

<a id="ZZ-029-005"></a>[\[ZZ-029-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-005) 十八年春，公将有行，遂与姜氏如齐。申𦈡曰：「女有家，男有室，无相渎也，谓之有礼。易此，必败。」

<a id="ZZ-029-006"></a>[\[ZZ-029-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-006) 公会齐侯于泺，遂及文姜如齐。齐侯通焉。公谪之，以告。

<sub>被引：[Q115](../../qa/Q115.md)</sub>

<a id="ZZ-029-007"></a>[\[ZZ-029-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-007) 夏四月丙子，享公。使公子彭生乘公，公薨于车。

<sub>被引：[Q149](../../qa/Q149.md)</sub>

<a id="ZZ-029-008"></a>[\[ZZ-029-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-008) 鲁人告于齐曰：「寡君畏君之威，不敢宁居，来修旧好，礼成而不反，无所归咎，恶于诸侯。请以彭生除之。」齐人杀彭生。

<sub>对读：[SJ-033-038](../SJ/033-%E9%B2%81%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#SJ-033-038)</sub>

<a id="ZZ-029-009"></a>[\[ZZ-029-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-009) 秋，齐侯师于首止；子亹会之，高渠弥相。七月戊戌，齐人杀子亹而轘高渠弥，祭仲逆郑子于陈而立之。是行也，祭仲知之，故称疾不往。人曰：「祭仲以知免。」仲曰：「信也。」

<a id="ZZ-029-010"></a>[\[ZZ-029-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-010) 周公欲弑庄王而立王子克。辛伯告王，遂与王杀周公黑肩。王子克奔燕。

<sub>被引：[周公](../../entries/person/%E5%91%A8%E5%85%AC.md)、[Q60](../../qa/Q60.md) · 对读：[SJ-004-046](../SJ/004-%E5%91%A8%E6%9C%AC%E7%BA%AA.md#SJ-004-046)</sub>

<a id="ZZ-029-011"></a>[\[ZZ-029-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-029-011) 初，子仪有宠于桓王，桓王属诸周公。辛伯谏曰：「并后、匹嫡、两政、耦国，乱之本也。」周公弗从，故及。
