### 经

<a id="ZZ-032-001"></a>[\[ZZ-032-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-001) 三年春王正月，溺会齐师伐卫。

<a id="ZZ-032-002"></a>[\[ZZ-032-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-002) 夏四月，葬宋庄公。五月，葬桓王。

<a id="ZZ-032-003"></a>[\[ZZ-032-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-003) 秋，纪季以酅入于齐。

<a id="ZZ-032-004"></a>[\[ZZ-032-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-004) 冬，公次于滑。

### 传

<a id="ZZ-032-005"></a>[\[ZZ-032-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-005) 三年春，溺会齐师伐卫，疾之也。

<a id="ZZ-032-006"></a>[\[ZZ-032-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-006) 夏五月，葬桓王，缓也。

<a id="ZZ-032-007"></a>[\[ZZ-032-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-007) 秋，纪季以酅入于齐，纪于是乎始判。

<a id="ZZ-032-008"></a>[\[ZZ-032-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-032-008) 冬，公次于滑，将会郑伯，谋纪故也。郑伯辞以难。凡师，一宿为舍，再宿为信，过信为次。
