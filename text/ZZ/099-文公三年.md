### 经

<a id="ZZ-099-001"></a>[\[ZZ-099-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-001) 春，王正月，叔孙得臣会晋人、宋人、陈人、卫人、郑人，伐沈，沈溃。

<a id="ZZ-099-002"></a>[\[ZZ-099-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-002) 夏，五月，王子虎卒。秦人伐晋。

<a id="ZZ-099-003"></a>[\[ZZ-099-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-003) 秋，楚人围江，雨螽于宋。

<a id="ZZ-099-004"></a>[\[ZZ-099-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-004) 冬，公如晋。

<a id="ZZ-099-005"></a>[\[ZZ-099-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-005) 十有二月，己巳，公及晋侯盟。晋阳处父帅师伐楚，以救江。

### 传

<a id="ZZ-099-006"></a>[\[ZZ-099-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-006) 春，庄叔会诸侯之师伐沈，以其服于楚也。沈溃。凡民，逃其上曰溃，在上曰逃。卫侯如陈，拜晋成也。

<a id="ZZ-099-007"></a>[\[ZZ-099-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-007) 夏四月，乙亥，王叔文公卒，来赴，吊如同盟，礼也。秦伯伐晋，济河焚舟，取王官及郊。晋人不出，遂自茅津济，封殽尸而还。遂霸西戎，用孟明也。君子是以知，秦穆公之为君也，举人之周也，与人之壹也；孟明之臣也，其不解也，能惧思也；子桑之忠也，其知人也，能举善也。《诗》曰：「于以采蘩？于沼于沚。于以用之？公侯之事。」秦穆有焉；「夙夜匪解，以事一人。」孟明有焉；「诒厥孙谋，以燕翼子。」子桑有焉。

<sub>被引：[Q44](../../qa/Q44.md)</sub>

<a id="ZZ-099-008"></a>[\[ZZ-099-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-008) 秋，雨螽于宋，队而死也。

<a id="ZZ-099-009"></a>[\[ZZ-099-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-009) 楚师围江，晋先仆伐楚以救江。

<a id="ZZ-099-010"></a>[\[ZZ-099-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-010) 冬，晋以江故告于周。王叔桓公、晋阳处父，伐楚，以救江。门于方城，遇息公子朱而还。

<sub>被引：[Q66](../../qa/Q66.md)</sub>

<a id="ZZ-099-011"></a>[\[ZZ-099-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-099-011) 晋人惧其无礼于公也，请改盟。公如晋，及晋侯盟。晋侯飨公，赋《菁菁者莪》，庄叔以公降拜，曰：「小国受命于大国，敢不慎仪？君贶之以大礼，何乐如之？抑小国之乐，大国之惠也。」晋侯降辞，登成拜，公赋《嘉乐》。
