### 经

<a id="ZZ-076-001"></a>[\[ZZ-076-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-001) 十有三年春，狄侵卫。

<a id="ZZ-076-002"></a>[\[ZZ-076-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-002) 夏，四月，葬陈宣公。公会齐侯、宋公、陈侯、卫侯、郑伯、许男、曹伯于咸。

<a id="ZZ-076-003"></a>[\[ZZ-076-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-003) 秋，九月，大雩。

<a id="ZZ-076-004"></a>[\[ZZ-076-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-004) 冬，公子友如齐。

### 传

<a id="ZZ-076-005"></a>[\[ZZ-076-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-005) 十三年春，齐侯使仲孙湫聘于周，且言王子带。事毕，不与王言。归复命曰：「未可。王怒未怠，其十年乎？不十年，王弗召也。」

<a id="ZZ-076-006"></a>[\[ZZ-076-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-006) 夏，会于咸，淮夷病杞故，且谋王室也。

<a id="ZZ-076-007"></a>[\[ZZ-076-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-007) 秋，为戎难故，诸侯戍周。齐仲孙湫致之。

<a id="ZZ-076-008"></a>[\[ZZ-076-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-076-008) 冬，晋荐饥，使乞籴于秦。秦伯谓子桑：「与诸乎？」对曰：「重施而报，君将何求？重施而不报，其民必携，携而讨焉，无众必败。」谓百里：「与诸乎？」对曰：「天灾流行，国家代有。救灾恤邻，道也。行道有福。」丕郑之子豹在秦，请伐晋。秦伯曰：「其君是恶，其民何罪？」秦于是乎输粟于晋，自雍及绛相继，命之曰「泛舟之役」。
