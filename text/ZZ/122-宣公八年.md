### 经

<a id="ZZ-122-001"></a>[\[ZZ-122-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-001) 八年春，公至自会。

<a id="ZZ-122-002"></a>[\[ZZ-122-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-002) 夏，六月，公子遂如齐，至黄，乃复。辛巳，有事于大庙，仲遂卒于垂。壬午，犹绎，万入，去籥。戊子，夫人嬴氏薨。晋师、白狄，伐秦。楚人灭舒蓼。

<a id="ZZ-122-003"></a>[\[ZZ-122-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-003) 秋，七月，甲子，日有食之，既。

<a id="ZZ-122-004"></a>[\[ZZ-122-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-004) 冬，十月，己丑，葬我小君敬嬴，雨不克葬。庚寅，日中而克葬。城平阳，楚师伐陈。

### 传

<a id="ZZ-122-005"></a>[\[ZZ-122-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-005) 春，白狄及晋平。

<a id="ZZ-122-006"></a>[\[ZZ-122-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-006) 夏，会晋伐秦。晋人获秦谍，杀诸绛市，六日而苏。有事于大庙，襄仲卒而绎，非礼也。楚为众舒叛故，伐舒蓼，灭之。楚子疆之，及滑汭，盟吴越而还。晋胥克有蛊疾，郤缺为政。

<a id="ZZ-122-007"></a>[\[ZZ-122-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-007) 秋，废胥克，使赵朔佐下军。

<a id="ZZ-122-008"></a>[\[ZZ-122-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-122-008) 冬，葬敬嬴，旱无麻，始用葛茀，雨不克葬，礼也。礼，卜葬先远日，辟不怀也。城平阳，书时也。陈及晋平，楚师伐陈，取成而还。
