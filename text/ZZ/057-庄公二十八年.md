### 经

<a id="ZZ-057-001"></a>[\[ZZ-057-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-001) 二十有八年春，王三月甲寅，齐人伐卫。卫人及齐人战，卫人败绩。

<a id="ZZ-057-002"></a>[\[ZZ-057-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-002) 夏四月丁未，邾子琐卒。

<a id="ZZ-057-003"></a>[\[ZZ-057-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-003) 秋，荆伐郑，公会齐人、宋人救郑。

<a id="ZZ-057-004"></a>[\[ZZ-057-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-004) 冬，筑郿。大无麦、禾，臧孙辰告籴于齐。

### 传

<a id="ZZ-057-005"></a>[\[ZZ-057-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-005) 二十八年春，齐侯伐卫。战，败卫师。数之以王命，取赂而还。

<a id="ZZ-057-006"></a>[\[ZZ-057-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-006) 晋献公娶于贾，无子。烝于齐姜，生秦穆夫人及大子申生。又娶二女于戎，大戎狐姬生重耳，小戎子生夷吾。晋伐骊戎，骊戎男女以骊姬。归，生奚齐。其娣生卓子。骊姬嬖，欲立其子，赂外嬖梁五，与东关嬖五，使言于公曰：『曲沃，君之宗也。蒲与二屈，君之疆也。不可以无主。宗邑无主则民不威，疆埸无主则启戎心。戎之生心，民慢其政，国之患也。若使大子主曲沃，而重耳、夷吾主蒲与屈，则可以威民而惧戎，且旌君伐。』使俱曰：『狄之广莫，于晋为都。晋之启土，不亦宜乎？』晋侯说之。

<sub>被引：[重耳](../../entries/person/%E9%87%8D%E8%80%B3.md)、[Q44](../../qa/Q44.md)、[Q117](../../qa/Q117.md)</sub>

<a id="ZZ-057-007"></a>[\[ZZ-057-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-007) 夏，使大子居曲沃，重耳居蒲城，夷吾居屈。群公子皆鄙，唯二姬之子在绛。二五卒与骊姬谮群公子而立奚齐，晋人谓之二五耦。

<sub>被引：[重耳](../../entries/person/%E9%87%8D%E8%80%B3.md)、[Q117](../../qa/Q117.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-057-008"></a>[\[ZZ-057-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-008) 楚令尹子元欲蛊文夫人，为馆于其宫侧，而振万焉。夫人闻之，泣曰：『先君以是舞也，习戎备也。今令尹不寻诸仇雠，而于未亡人之侧，不亦异乎！』御人以告子元。子元曰：『妇人不忘袭仇，我反忘之！』

<a id="ZZ-057-009"></a>[\[ZZ-057-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-009) 秋，子元以车六百乘伐郑，入于桔柣之门。子元、鬭御疆、鬭梧、耿之不比为旆，鬭班、王孙游、王孙喜殿。众车入自纯门，及逵市。县门不发，楚言而出。子元曰：『郑有人焉。』诸侯救郑，楚师夜遁。郑人将奔桐丘，谍告曰：『楚幕有乌。』乃止。

<a id="ZZ-057-010"></a>[\[ZZ-057-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-010) 冬，饥。臧孙辰告籴于齐，礼也。

<a id="ZZ-057-011"></a>[\[ZZ-057-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-057-011) 筑郿，非都也。凡邑有宗庙先君之主曰都，无曰邑。邑曰筑，都曰城。
