### 经

<a id="ZZ-048-001"></a>[\[ZZ-048-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-001) 十有九年春王正月。

<a id="ZZ-048-002"></a>[\[ZZ-048-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-002) 夏四月。

<a id="ZZ-048-003"></a>[\[ZZ-048-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-003) 秋，公子结媵陈人之妇于鄄，遂及齐侯、宋公盟。夫人姜氏如莒。

<a id="ZZ-048-004"></a>[\[ZZ-048-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-004) 冬，齐人、宋人、陈人伐我西鄙。

### 传

<a id="ZZ-048-005"></a>[\[ZZ-048-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-005) 十九年春，楚子御之，大败于津。还，鬻拳弗纳。遂伐黄，败黄师于碏陵。还，及湫，有疾。夏六月庚申卒，鬻拳葬诸夕室，亦自杀也，而葬于绖皇。

<a id="ZZ-048-006"></a>[\[ZZ-048-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-006) 初，鬻拳强谏楚子，楚子弗从，临之以兵，惧而从之。鬻拳曰：『吾惧君以兵，罪莫大焉。』遂自刖也。楚人以为大阍，谓之大伯，使其后掌之。君子曰『鬻拳可谓爱君矣，谏以自纳于刑，刑犹不忘纳君于善。』

<a id="ZZ-048-007"></a>[\[ZZ-048-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-048-007) 初，王姚嬖于庄王，生子颓。子颓有宠，𫇭国为之师。及惠王即位。取𫇭国之圃以为囿，边伯之宫近于王宫，王取之。王夺子禽祝跪与詹父田，而收膳夫之秩。故𫇭国、边伯、石速、詹父、子禽祝跪作乱，因苏氏。秋，五大夫奉子颓以伐王，不克，出奔温。苏子奉子颓以奔卫。卫师、燕师伐周。冬，立子颓。
