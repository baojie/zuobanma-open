### 经

<a id="ZZ-097-001"></a>[\[ZZ-097-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-001) 元年春，王正月，公即位。

<a id="ZZ-097-002"></a>[\[ZZ-097-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-002) 二月，癸亥，日有食之。天王使叔服来会葬。

<a id="ZZ-097-003"></a>[\[ZZ-097-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-003) 夏，四月，丁巳，葬我君僖公。天王使毛伯来锡公命。晋侯伐卫。叔孙得臣如京师。卫人伐晋。

<a id="ZZ-097-004"></a>[\[ZZ-097-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-004) 秋，公孙敖会晋侯于戚。

<a id="ZZ-097-005"></a>[\[ZZ-097-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-005) 冬，十月，丁未，楚世子商臣弑其君𫖳。公孙敖如齐。

### 传

<a id="ZZ-097-006"></a>[\[ZZ-097-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-006) 元年春，王使内史叔服来会葬。公孙敖闻其能相人也，见其二子焉。叔服曰：「谷也食子，难也收子。谷也丰下，必有后于鲁国。」

<a id="ZZ-097-007"></a>[\[ZZ-097-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-007) 于是闰三月，非礼也。先王之正时也，履端于始，举正于中，归余于终。履端于始，序则不愆。举正于中，民则不惑。归余于终，事则不悖。

<sub>对读：[HS-021-025](../HS/021-%E5%BE%8B%E5%8E%86%E5%BF%97.md#HS-021-025)、[SJ-026-007](../SJ/026-%E5%8E%86%E4%B9%A6.md#SJ-026-007)</sub>

<a id="ZZ-097-008"></a>[\[ZZ-097-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-008) 夏，四月，丁巳，葬僖公。

<a id="ZZ-097-009"></a>[\[ZZ-097-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-009) 王使毛伯卫来锡公命，叔孙得臣如周拜。

<a id="ZZ-097-010"></a>[\[ZZ-097-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-010) 晋文公之季年，诸侯朝晋。卫成公不朝，使孔达侵郑，伐緜、訾、及匡。晋襄公既祥，使告于诸侯而伐卫，及南阳。先且居曰：「效尤，祸也。请君朝王，臣从师。」晋侯朝王于温，先且居、胥臣伐卫。

<sub>被引：[Q70](../../qa/Q70.md)</sub>

<a id="ZZ-097-011"></a>[\[ZZ-097-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-011) 五月，辛酉朔，晋师围戚。

<a id="ZZ-097-012"></a>[\[ZZ-097-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-012) 六月，戊戌，取之，获孙昭子。

<a id="ZZ-097-013"></a>[\[ZZ-097-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-013) 卫人使告于陈，陈共公曰：「更伐之，我辞之。」卫孔达帅师伐晋。君子以为古，古者越国而谋。

<a id="ZZ-097-014"></a>[\[ZZ-097-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-014) 秋，晋侯疆戚田，故公孙敖会之。

<a id="ZZ-097-015"></a>[\[ZZ-097-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-015) 初，楚子将以商臣为大子，访诸令尹子上，子上曰：「君之齿未也，而又多爱，黜乃乱也。楚国之举，恒在少者，且是人也，蜂目而豺声，忍人也，不可立也。」弗听。既又欲立王子职而黜大子商臣。商臣闻之而未察，告其师潘崇曰：「若之何而察之？」潘崇曰：「享江芈而勿敬也。」从之。江芈怒曰：「呼，役夫！宜君王之欲杀女而立职也。」告潘崇曰：「信矣。」潘崇曰：「能事诸乎？」曰：「不能。」「能行乎？」曰：「不能。」「能行大事乎？」曰：「能。」

<sub>被引：[Q149](../../qa/Q149.md) · 对读：[SJ-040-018](../SJ/040-%E6%A5%9A%E4%B8%96%E5%AE%B6.md#SJ-040-018) · [二校](../../collation/review.md)：改字 2 处</sub>

<a id="ZZ-097-016"></a>[\[ZZ-097-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-016) 冬，十月，以宫甲围成王。王请食熊蹯而死，弗听。丁未，王缢。谥之曰「灵」，不瞑，曰「成」，乃瞑。

<a id="ZZ-097-017"></a>[\[ZZ-097-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-017) 穆王立，以其为大子之室与潘崇，使为大师，且掌环列之尹。

<a id="ZZ-097-018"></a>[\[ZZ-097-018\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-018) 穆伯如齐，始聘焉，礼也。凡君即位，卿出并聘，践修旧好，要结外援，好事邻国，以卫社稷，忠信卑让之道也。忠，德之正也。信，德之固也。卑让，德之基也。

<a id="ZZ-097-019"></a>[\[ZZ-097-019\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-097-019) 殽之役，晋人既归秦帅，秦大夫及左右皆言于秦伯曰：「是败也，孟明之罪也，必杀之。」秦伯曰：「是孤之罪也。周芮良夫之诗曰：『大风有隧，贪人败类。听言则对，诵言如醉。匪用其良，覆俾我悖。』是贪故也，孤之谓矣。孤实贪以祸夫子，夫子何罪？」复使为政。
