### 传

<a id="ZZ-014-011"></a>[\[ZZ-014-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-014-011) 三年春，曲沃武公伐翼，次于陉庭，韩万御戎，梁弘为右，逐翼侯于汾隰，骖絓而止。夜获之，及栾共叔。

<a id="ZZ-014-012"></a>[\[ZZ-014-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-014-012) 会于嬴，成昬于齐也。

<a id="ZZ-014-013"></a>[\[ZZ-014-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-014-013) 夏，齐侯、卫侯胥命于蒲，不盟也。

<a id="ZZ-014-014"></a>[\[ZZ-014-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-014-014) 公会杞侯于郕，杞求成也。

<a id="ZZ-014-015"></a>[\[ZZ-014-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-014-015) 秋，公子翚如齐逆女。修先君之好。故曰「公子」。

<a id="ZZ-014-016"></a>[\[ZZ-014-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E4%B8%89%E5%B9%B4?pn=ZZ-014-016) 齐侯送姜氏，非礼也。凡公女嫁于敌国，姊妹，则上卿送之，以礼于先君；公子，则下卿送之。于大国，虽公子，亦上卿送之。于天子，则诸卿皆行，公不自送。于小国，则上大夫送之。
