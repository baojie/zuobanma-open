### 经

<a id="ZZ-062-001"></a>[\[ZZ-062-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-001) 元年春，王正月，齐人救邢。

<a id="ZZ-062-002"></a>[\[ZZ-062-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-002) 夏六月，辛酉，葬我君庄公。

<a id="ZZ-062-003"></a>[\[ZZ-062-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-003) 秋八月，公及齐侯盟于落姑。季子来归。

<a id="ZZ-062-004"></a>[\[ZZ-062-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-004) 冬，齐仲孙来。

### 传

<a id="ZZ-062-005"></a>[\[ZZ-062-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-005) 元年春，不书即位，乱故也。

<a id="ZZ-062-006"></a>[\[ZZ-062-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-006) 狄人伐邢。管敬仲言于齐侯曰：「戎狄豺狼，不可厌也；诸夏亲暱，不可弃也；宴安酖毒，不可怀也。《诗》云：『岂不怀归？畏此简书。』简书，同恶相恤之谓也。请救邢以从简书。」齐人救邢。

<sub>被引：[Q73](../../qa/Q73.md)、[Q183](../../qa/Q183.md)</sub>

<a id="ZZ-062-007"></a>[\[ZZ-062-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-007) 夏，六月，葬庄公，乱故，是以缓。

<a id="ZZ-062-008"></a>[\[ZZ-062-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-008) 秋，八月，公及齐侯盟于落姑，请复季友也。齐侯许之，使召诸陈，公次于郎以待之。「季子来归」，嘉之也。

<a id="ZZ-062-009"></a>[\[ZZ-062-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-009) 冬，齐仲孙湫来省难。书曰「仲孙」，亦嘉之也。仲孙归，曰：「不去庆父，鲁难未已。」公曰：「若之何而去之？」对曰：「难不已，将自毙，君其待之。」公曰：「鲁可取乎？」对曰：「不可，犹秉周礼。周礼，所以本也。臣闻之，『国将亡，本必先颠，而后枝叶从之』。鲁不弃周礼，未可动也。君其务宁鲁难而亲之。亲有礼，因重固，间携贰，覆昬乱，霸王之器也。」

<sub>被引：[Q128](../../qa/Q128.md)</sub>

<a id="ZZ-062-010"></a>[\[ZZ-062-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-010) 晋侯作二军，公将上军，大子申生将下军。赵夙御戎，毕万为右，以灭耿、灭霍、灭魏。还，为大子城曲沃。赐赵夙耿，赐毕万魏，以为大夫。

<sub>被引：[Q110](../../qa/Q110.md) · 对读：[SJ-039-027](../SJ/039-%E6%99%8B%E4%B8%96%E5%AE%B6.md#SJ-039-027)</sub>

<a id="ZZ-062-011"></a>[\[ZZ-062-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-011) 士𫇭曰：「大子不得立矣，分之都城，而位以卿，先为之极，又焉得立？不如逃之，无使罪至。为吴大伯，不亦可乎？犹有令名，与其及也。且谚曰：『心苟无瑕，何恤乎无家？』天若祚大子，其无晋乎！」

<sub>对读：[SJ-039-027](../SJ/039-%E6%99%8B%E4%B8%96%E5%AE%B6.md#SJ-039-027)</sub>

<a id="ZZ-062-012"></a>[\[ZZ-062-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-012) 卜偃曰：「毕万之后必大。万，盈数也；魏，大名也。以是始赏，天启之矣。天子曰兆民，诸侯曰万民。今名之大，以从盈数，其必有众。」

<a id="ZZ-062-013"></a>[\[ZZ-062-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%97%B5%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-062-013) 初，毕万筮仕于晋，遇《屯》之《比》。辛廖占之，曰：「吉。《屯》固、《比》入，吉孰大焉？其必蕃昌。《震》为土、车从马、足居之、兄长之、母覆之、众归之、六体不易、合而能固、安而能杀，公侯之卦也。公侯之子孙，必复其始。」
