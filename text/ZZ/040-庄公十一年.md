### 经

<a id="ZZ-040-001"></a>[\[ZZ-040-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-001) 十有一年春王正月。

<a id="ZZ-040-002"></a>[\[ZZ-040-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-002) 夏五月，戊寅，公败宋师于鄑。

<a id="ZZ-040-003"></a>[\[ZZ-040-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-003) 秋，宋大水。

<a id="ZZ-040-004"></a>[\[ZZ-040-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-004) 冬，王姬归于齐。

### 传

<a id="ZZ-040-005"></a>[\[ZZ-040-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-005) 十一年夏，宋为乘丘之役故侵我。公御之，宋师未陈而薄之，败诸鄑。

<a id="ZZ-040-006"></a>[\[ZZ-040-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-006) 凡师，敌未陈曰败某师，皆陈曰战，大崩曰败绩，得隽曰克，覆而败之曰取某师，亰师败曰王师败绩于某。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-040-007"></a>[\[ZZ-040-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-007) 秋，宋大水。公使吊焉，曰：『天作淫雨，害于粢盛，若之何不吊？』对曰：『孤实不敬，天降之灾，又以为君忧，拜命之辱。』臧文仲曰：『宋其兴乎。禹、汤罪己，其兴也悖焉；桀、纣罪人，其亡也忽焉。且列国有凶称孤，礼也。言惧而名礼，其庶乎。』既而闻之曰公子御说之辞也。臧孙达曰：『是宜为君，有恤民之心。』

<sub>被引：[Q120](../../qa/Q120.md)、[Q129](../../qa/Q129.md)、[Q145](../../qa/Q145.md)</sub>

<a id="ZZ-040-008"></a>[\[ZZ-040-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-008) 冬，齐侯来逆共姬。

<a id="ZZ-040-009"></a>[\[ZZ-040-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-040-009) 乘丘之役，公以金仆姑射南宫长万，公右歂孙生搏之。宋人请之，宋公靳之，曰：『始吾敬子，今子，鲁囚也。吾弗敬子矣。』病之。
