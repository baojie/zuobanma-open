### 经

<a id="ZZ-100-001"></a>[\[ZZ-100-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-001) 春，公至自晋。

<a id="ZZ-100-002"></a>[\[ZZ-100-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-002) 夏，逆妇姜于齐。狄侵齐。

<a id="ZZ-100-003"></a>[\[ZZ-100-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-003) 秋，楚人灭江。晋侯伐秦，卫侯使宁俞来聘。

<a id="ZZ-100-004"></a>[\[ZZ-100-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-004) 冬十有一月，壬寅，夫人风氏薨。

### 传

<a id="ZZ-100-005"></a>[\[ZZ-100-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-005) 春，晋人归孔达于卫。以为卫之良也，故免之。

<a id="ZZ-100-006"></a>[\[ZZ-100-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-006) 夏，卫侯如晋拜。曹伯如晋会正。

<a id="ZZ-100-007"></a>[\[ZZ-100-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-007) 逆妇姜于齐，卿不行，非礼也。君子是以知出姜之不允于鲁也，曰：「贵聘而贱逆之，君而卑之，立而废之，弃信而坏其主，在国必乱，在家必亡。不允宜哉。《诗》曰：「畏天之威，于时保之」，敬主之谓也。」

<a id="ZZ-100-008"></a>[\[ZZ-100-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-008) 秋，晋侯伐秦，围邧新城，以报王官之役。

<sub>被引：[Q20](../../qa/Q20.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-100-009"></a>[\[ZZ-100-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-009) 楚人灭江，秦伯为之降服，出次，不举，过数。大夫谏，公曰：「同盟灭，虽不能救，敢不矜乎，吾自惧也。」君子曰，诗云：「惟彼二国，其政不获，惟此四国，爰究爰度，其秦穆之谓矣。」

<sub>被引：[Q44](../../qa/Q44.md)</sub>

<a id="ZZ-100-010"></a>[\[ZZ-100-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-010) 卫宁武子来聘，公与之宴，为赋《湛露》，及《彤弓》。不辞，又不荅赋，使行人私焉。对曰，臣以为肄业及之也，昔诸侯朝正于王，王宴乐之，于是乎赋《湛露》，则天子当阳，诸侯用命也。诸侯敌王所忾，而献其功，王于是乎赐之，彤弓一，彤矢百，玈弓矢千，以觉报宴。今陪臣来继旧好，君辱贶之，其敢干大礼以自取戾。

<a id="ZZ-100-011"></a>[\[ZZ-100-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-100-011) 冬，成风薨。
