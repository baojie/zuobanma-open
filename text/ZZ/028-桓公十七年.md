### 经

<a id="ZZ-028-001"></a>[\[ZZ-028-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-001) 十有七年，春，正月丙辰，公会齐侯、纪侯盟于黄。二月丙午，公会邾仪父，盟于趡。

<a id="ZZ-028-002"></a>[\[ZZ-028-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-002) 夏，五月丙午，及齐师战于奚。六月丁丑，蔡侯封人卒。

<a id="ZZ-028-003"></a>[\[ZZ-028-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-003) 秋，八月，蔡季自陈归于蔡。癸巳，葬蔡桓侯。及宋人、卫人伐邾。

<a id="ZZ-028-004"></a>[\[ZZ-028-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-004) 冬，十月朔，日有食之。

### 传

<a id="ZZ-028-005"></a>[\[ZZ-028-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-005) 十七年春，盟于黄，平齐、纪，且谋卫故也。

<a id="ZZ-028-006"></a>[\[ZZ-028-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-006) 及邾仪父盟于趡，寻蔑之盟也。

<a id="ZZ-028-007"></a>[\[ZZ-028-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-007) 夏，及齐师战于奚，疆事也。于是齐人侵鲁疆，疆吏来告，公曰：「疆埸之事，慎守其一，而备其不虞。姑尽所备焉。事至而战，又何谒焉？」

<a id="ZZ-028-008"></a>[\[ZZ-028-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-008) 蔡桓侯卒。蔡人召蔡季于陈。

<a id="ZZ-028-009"></a>[\[ZZ-028-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-009) 秋，蔡季自陈归于蔡，蔡人嘉之也。

<a id="ZZ-028-010"></a>[\[ZZ-028-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-010) 伐邾，宋志也。

<a id="ZZ-028-011"></a>[\[ZZ-028-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-011) 冬十月朔，日有食之。不书日，官失之也。天子有日官，诸侯有日御。日官居卿以底日，礼也。日御不失日，以授百官于朝。

<a id="ZZ-028-012"></a>[\[ZZ-028-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-028-012) 初，郑伯将以高渠弥为卿，昭公恶之，固谏，不听，昭公立，惧其杀己也。辛卯，弑昭公，而立公子亹。
