### 经

<a id="ZZ-084-001"></a>[\[ZZ-084-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-001) 二十有一年春，狄侵卫。宋人、齐人、楚人盟于鹿上。

<a id="ZZ-084-002"></a>[\[ZZ-084-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-002) 夏，大旱。

<a id="ZZ-084-003"></a>[\[ZZ-084-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-003) 秋，宋公、楚子、陈侯、蔡侯、郑伯、许男、曹伯，会于盂，执宋公以伐宋。

<a id="ZZ-084-004"></a>[\[ZZ-084-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-004) 冬，公伐邾。楚人使宜申来献捷。

<a id="ZZ-084-005"></a>[\[ZZ-084-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-005) 十有二月，癸丑，公会诸侯盟于薄。释宋公。

### 传

<a id="ZZ-084-006"></a>[\[ZZ-084-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-006) 二十一年春，宋人为鹿上之盟，以求诸侯于楚，楚人许之。公子目夷曰：「小国争盟，祸也。宋其亡乎，幸而后败。」

<sub>对读：[SJ-038-037](../SJ/038-%E5%AE%8B%E5%BE%AE%E5%AD%90%E4%B8%96%E5%AE%B6.md#SJ-038-037)</sub>

<a id="ZZ-084-007"></a>[\[ZZ-084-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-007) 夏，大旱，公欲焚巫、尫。臧文仲曰：「非旱备也。修城郭，贬食省用，务穑劝分，此其务也，巫、尫何为？天欲杀之，则如勿生。若能为旱，焚之滋甚。」公从之。是岁也，饥而不害。

<sub>被引：[Q120](../../qa/Q120.md)</sub>

<a id="ZZ-084-008"></a>[\[ZZ-084-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-008) 秋，诸侯会宋公于盂。子鱼曰：「祸其在此乎？君欲已甚，其何以堪之？」于是楚执宋公以伐宋。

<sub>对读：[SJ-038-037](../SJ/038-%E5%AE%8B%E5%BE%AE%E5%AD%90%E4%B8%96%E5%AE%B6.md#SJ-038-037)</sub>

<a id="ZZ-084-009"></a>[\[ZZ-084-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-009) 冬，会于薄以释之。子鱼曰：「祸犹未也，未足以惩君。」

<a id="ZZ-084-010"></a>[\[ZZ-084-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-084-010) 任、宿、须句、颛臾，风姓也。实司大皞与有济之祀，以服事诸夏。邾人灭须句，须句子来奔，因成风也。成风为之言于公曰：「崇明祀，保小寡，周礼也。蛮夷猾夏，周祸也。若封须句，是崇皞济而修祀纾祸也。」
