### 经

<a id="ZZ-069-001"></a>[\[ZZ-069-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-001) 六年春，王正月。

<a id="ZZ-069-002"></a>[\[ZZ-069-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-002) 夏，公会齐侯、宋公、陈侯、卫侯、曹伯伐郑，围新城。

<sub>被引：[Q20](../../qa/Q20.md)</sub>

<a id="ZZ-069-003"></a>[\[ZZ-069-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-003) 秋，楚人围许。诸侯遂救许。

<a id="ZZ-069-004"></a>[\[ZZ-069-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-004) 冬，公至自伐郑。

### 传

<a id="ZZ-069-005"></a>[\[ZZ-069-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-005) 六年春，晋侯使贾华伐屈，夷吾不能守，盟而行，将奔狄。郤芮曰：「后出同走，罪也。不如之梁，梁近秦而幸焉。」乃之梁。

<a id="ZZ-069-006"></a>[\[ZZ-069-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-006) 夏，诸侯伐郑，以其逃首止之盟故也。围新密，郑所以不时城也。

<a id="ZZ-069-007"></a>[\[ZZ-069-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-007) 秋，楚子围许，以救郑。诸侯救许，乃还。

<a id="ZZ-069-008"></a>[\[ZZ-069-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%AD%E5%B9%B4?pn=ZZ-069-008) 冬，蔡穆侯将许僖公以见楚子于武城。许男面缚衔璧，大夫衰绖，士舆榇。楚子问诸逢伯，对曰：「昔武王克殷，微子启如是，武王亲释其缚。受其璧而祓之，焚其榇，礼而命之，使复其所。」楚子从之。
