### 经

<a id="ZZ-005-001"></a>[\[ZZ-005-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-001) 五年，春，公矢鱼于棠。

<a id="ZZ-005-002"></a>[\[ZZ-005-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-002) 夏四月，葬卫桓公。

<a id="ZZ-005-003"></a>[\[ZZ-005-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-003) 秋，卫师入郕。

<a id="ZZ-005-004"></a>[\[ZZ-005-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-004) 九月，考仲子之宫。初献六羽。

<a id="ZZ-005-005"></a>[\[ZZ-005-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-005) 邾人、郑人伐宋。

<a id="ZZ-005-006"></a>[\[ZZ-005-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-006) 螟。

<a id="ZZ-005-007"></a>[\[ZZ-005-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-007) 冬十有二月，辛巳，公子𫸩卒。

<a id="ZZ-005-008"></a>[\[ZZ-005-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-008) 宋人伐郑，围长葛。

### 传

<a id="ZZ-005-009"></a>[\[ZZ-005-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-009) 五年春，公将如棠观鱼者。臧僖伯谏曰：「凡物不足以讲大事，其材不足以备器用，则君不举焉。君，将纳民于轨、物者也。故讲事以度轨量谓之『轨』；取材以章物采谓之『物』。不轨不物谓之乱政。乱政亟行，所以败也。故春搜、夏苗、秋狝、冬狩，皆于农隙以讲事也。三年而治兵，入而振旅，归而饮至，以数军实。昭文章，明贵贱，辨等列，顺少长，习威仪也。鸟兽之肉不登于俎，皮革齿牙、骨角毛羽不登于器，则公不射，古之制也。若夫山林川泽之实，器用之资，皂隶之事，官司之守，非君所及也。」公曰：「吾将略地焉。」遂往，陈鱼而观之。僖伯称疾不从。书曰「公矢鱼于棠」，非礼也，且言远地也。

<a id="ZZ-005-010"></a>[\[ZZ-005-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-010) 曲沃庄伯以郑人、邢人伐翼，王使尹氏、武氏助之。翼侯奔随。

<a id="ZZ-005-011"></a>[\[ZZ-005-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-011) 夏，葬卫桓公。卫乱，是以缓。

<a id="ZZ-005-012"></a>[\[ZZ-005-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-012) 四月，郑人侵卫牧，以报东门之役。卫人以燕师伐郑。郑祭足、原繁、泄驾以三军军其前，使曼伯与子元潜军军其后。燕人畏郑三军而不虞制人。六月，郑二公子以制人败燕师于北制。君子曰：「不备不虞，不可以师。」

<a id="ZZ-005-013"></a>[\[ZZ-005-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-013) 曲沃叛王。秋，王命虢公伐曲沃，而立哀侯于翼。

<a id="ZZ-005-014"></a>[\[ZZ-005-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-014) 卫之乱也，郕人侵卫，故卫师入郕。

<sub>被引：[Q136](../../qa/Q136.md)</sub>

<a id="ZZ-005-015"></a>[\[ZZ-005-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-015) 九月，考仲子之宫，将万焉。公问羽数于众仲。对曰：「天子用八，诸侯用六，大夫四，士二。夫舞，所以节八音，而行八风，故自八以下。」公从之。于是初献六羽，始用六佾也。

<sub>被引：[Q142](../../qa/Q142.md)</sub>

<a id="ZZ-005-016"></a>[\[ZZ-005-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-016) 宋人取邾田。邾人告于郑曰：「请君释憾于宋，敝邑为道。」郑人以王师会之。伐宋，入其郛，以报东门之役。宋人使来告命。公闻其入郛也，将救之，问于使者曰：「师何及？」对曰：「未及国。」公怒，乃止，辞使者曰：「君命寡人同恤社稷之难，今问诸使者，曰『师未及国』，非寡人之所敢知也。」

<a id="ZZ-005-017"></a>[\[ZZ-005-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-005-017) 冬，十二月辛巳，臧僖伯卒。公曰：「叔父有憾于寡人，寡人弗敢忘。」葬之加一等。
