### 传

<a id="ZZ-002-010"></a>[\[ZZ-002-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-010) 二年春，公会戎于潜，修惠公之好也。戎请盟，公辞。

<a id="ZZ-002-011"></a>[\[ZZ-002-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-011) 莒子娶于向，向姜不安莒而归。夏，莒人入向，以姜氏还。

<a id="ZZ-002-012"></a>[\[ZZ-002-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-012) 司空无骇入极，费庈父胜之。

<a id="ZZ-002-013"></a>[\[ZZ-002-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-013) 戎请盟。秋，盟于唐，复修戎好也。

<a id="ZZ-002-014"></a>[\[ZZ-002-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-014) 九月，纪裂𦈡来逆女，卿为君逆也。

<a id="ZZ-002-015"></a>[\[ZZ-002-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-015) 冬，纪子帛、莒子盟于密，鲁故也。

<a id="ZZ-002-016"></a>[\[ZZ-002-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-002-016) 郑人伐卫，讨公孙滑之乱也。
