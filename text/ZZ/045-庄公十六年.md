### 经

<a id="ZZ-045-001"></a>[\[ZZ-045-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-001) 十有六年春王正月。

<a id="ZZ-045-002"></a>[\[ZZ-045-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-002) 夏，宋人、齐人、卫人伐郑。

<a id="ZZ-045-003"></a>[\[ZZ-045-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-003) 秋，荆伐郑。

<a id="ZZ-045-004"></a>[\[ZZ-045-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-004) 冬十有二月，会齐侯、宋公、陈侯、卫侯、郑伯、许男、滑伯、滕子同盟于幽。邾子克卒。

### 传

<a id="ZZ-045-005"></a>[\[ZZ-045-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-005) 十六年夏，诸侯伐郑，宋故也。

<a id="ZZ-045-006"></a>[\[ZZ-045-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-006) 郑伯自栎入，缓告于楚。秋，楚伐郑，及栎，为不礼故也。

<a id="ZZ-045-007"></a>[\[ZZ-045-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-007) 郑伯治与于雍纠之乱者。九月，杀公子阏，刖强鉏。公父定叔出奔卫。三年而复之，曰：『不可使共叔无后于郑。』使以十月入，曰：『良月也，就盈数焉。』

<a id="ZZ-045-008"></a>[\[ZZ-045-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-008) 君子谓：『强鉏不能卫其足。』

<a id="ZZ-045-009"></a>[\[ZZ-045-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-009) 冬，同盟于幽，郑成也。

<a id="ZZ-045-010"></a>[\[ZZ-045-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-010) 王使虢公命曲沃伯以一军为晋侯。

<a id="ZZ-045-011"></a>[\[ZZ-045-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-045-011) 初，晋武公伐夷，执夷诡诸。𫇭国请而免之。既而弗报。故子国作乱，谓晋人曰：『与我伐夷而取其地。』遂以晋师伐夷，杀夷诡诸。周公忌父出奔虢。惠王立而复之。
