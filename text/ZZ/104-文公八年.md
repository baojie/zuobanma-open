### 传

<a id="ZZ-104-008"></a>[\[ZZ-104-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-008) 春，晋侯使解扬归匡、戚之田于卫，
<a id="ZZ-104-009"></a>[\[ZZ-104-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-009) 且复致公婿池之封，自申至于虎牢之竟。

<a id="ZZ-104-010"></a>[\[ZZ-104-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-010) 夏，秦人伐晋，取武城，以报令狐之役。

<a id="ZZ-104-011"></a>[\[ZZ-104-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-011) 秋，襄王崩，晋人以扈之盟来讨。

<a id="ZZ-104-012"></a>[\[ZZ-104-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-012) 冬，襄仲会晋赵孟，盟于衡雍，报扈之盟也。
<a id="ZZ-104-013"></a>[\[ZZ-104-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-013) 遂会伊雒之戎，书曰，公子遂，珍之也。
<a id="ZZ-104-014"></a>[\[ZZ-104-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-104-014) 穆伯如周吊丧，不至，以币奔莒，从己氏焉。
