### 经

<sub>被引：[Q178](../../qa/Q178.md)</sub>

<a id="ZZ-053-002"></a>[\[ZZ-053-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-002) 夏，公如齐逆女。

<a id="ZZ-053-003"></a>[\[ZZ-053-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-003) 秋，公至自齐。八月丁丑，夫人姜氏入。

<a id="ZZ-053-004"></a>[\[ZZ-053-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-004) 戊寅，大夫宗妇觌，用币。大水。

<a id="ZZ-053-005"></a>[\[ZZ-053-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-005) 冬，戎侵曹。曹羁出奔陈。赤归于曹。郭公。

### 传

<a id="ZZ-053-006"></a>[\[ZZ-053-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-006) 二十四年春，刻其桷，皆非礼也。御孙谏曰：『臣闻之：「俭，德之共也；侈，恶之大也。」先君有共德而君纳诸大恶，无乃不可乎！』

<a id="ZZ-053-007"></a>[\[ZZ-053-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-007) 秋，哀姜至。公使宗妇觌，用币，非礼也。御孙曰：『男贽大者玉帛，小者禽鸟，以章物也。女贽不过榛栗枣修，以告虔也。今男女同贽，是无别也。男女之别，国之大节也。而由夫人乱之，无乃不可乎！』

<a id="ZZ-053-008"></a>[\[ZZ-053-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-053-008) 晋士𫇭又与群公子谋，使杀游氏之二子。士𫇭告晋侯曰：『可矣。不过二年，君必无患。』
