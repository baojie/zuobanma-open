### 经

<a id="ZZ-064-001"></a>[\[ZZ-064-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-001) 元年春，王正月。齐师、宋师、曹伯次于聂北，救邢。

<sub>被引：[Q178](../../qa/Q178.md)</sub>

<a id="ZZ-064-002"></a>[\[ZZ-064-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-002) 夏，六月，邢迁于夷仪。齐师、宋师、曹师城邢。

<a id="ZZ-064-003"></a>[\[ZZ-064-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-003) 秋，七月，戊辰。夫人姜氏薨于夷，齐人以归。楚人伐郑。

<a id="ZZ-064-004"></a>[\[ZZ-064-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-004) 八月，公会齐侯、宋公、郑伯、曹伯、邾人于柽。

<a id="ZZ-064-005"></a>[\[ZZ-064-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-005) 九月，公败邾师于偃。

<a id="ZZ-064-006"></a>[\[ZZ-064-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-006) 冬，十月，壬午，公子友帅师败莒师于郦，获莒拏。

<a id="ZZ-064-007"></a>[\[ZZ-064-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-007) 十有二月，丁巳，夫人氏之丧至自齐。

### 传

<a id="ZZ-064-008"></a>[\[ZZ-064-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-008) 元年春，不称即位，公出故也。公出复入不书，讳之也。讳国恶，礼也。

<a id="ZZ-064-009"></a>[\[ZZ-064-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-009) 诸侯救邢。邢人溃，出奔师。师遂逐狄人，具邢器用而迁之，师无私焉。

<a id="ZZ-064-010"></a>[\[ZZ-064-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-010) 夏，邢迁于夷仪。诸侯城之，救患也。凡侯伯，救患、分灾、讨罪，礼也。

<a id="ZZ-064-011"></a>[\[ZZ-064-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-011) 秋，楚人伐郑，郑即齐故也。

<a id="ZZ-064-012"></a>[\[ZZ-064-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-012) 盟于荦，谋救郑也。

<a id="ZZ-064-013"></a>[\[ZZ-064-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-013) 九月，公败邾师于偃，虚丘之戍将归者也。

<a id="ZZ-064-014"></a>[\[ZZ-064-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-014) 冬，莒人来求赂，公子友败诸郦，获莒子之弟拏。非卿也，嘉获之也。公赐季友汶阳之田，及费。

<a id="ZZ-064-015"></a>[\[ZZ-064-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-064-015) 夫人氏之丧至自齐，君子以齐人之杀哀姜也，为已甚矣。女子从人者也。
