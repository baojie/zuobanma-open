### 经

<a id="ZZ-090-001"></a>[\[ZZ-090-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-001) 二十有七年春，杞子来朝。

<a id="ZZ-090-002"></a>[\[ZZ-090-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-002) 夏，六月，庚寅，齐侯昭卒。

<a id="ZZ-090-003"></a>[\[ZZ-090-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-003) 秋，八月，乙未，葬齐孝公。乙巳，公子遂帅师入杞。

<a id="ZZ-090-004"></a>[\[ZZ-090-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-004) 冬，楚人、陈侯、蔡侯、郑伯、许男围宋。十有二月，甲戌，公会诸侯盟于宋。

### 传

<a id="ZZ-090-005"></a>[\[ZZ-090-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-005) 二十七年春，杞桓公来朝，用夷礼，故曰「子」。公卑杞，杞不共也。

<a id="ZZ-090-006"></a>[\[ZZ-090-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-006) 夏，齐孝公卒，有齐怨，不废丧纪，礼也。

<sub>被引：[Q7](../../qa/Q7.md)</sub>

<a id="ZZ-090-007"></a>[\[ZZ-090-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-007) 秋，入杞，责无礼也。

<a id="ZZ-090-008"></a>[\[ZZ-090-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-008) 楚子将围宋，使子文治兵于睽，终朝而毕，不戮一人。子玉复治兵于𫇭，终日而毕，鞭七人，贯三人耳。国老皆贺子文，子文饮之酒。𫇭贾尚幼，后至，不贺。子文问之，对曰：「不知所贺。子之传政于子玉，曰：『以靖国也。』靖诸内而败诸外，所获几何？子玉之败，子之举也，举以败国，将何贺焉？子玉刚而无礼，不可以治民，过三百乘，其不能以入矣。苟入而贺，何后之有？」

<a id="ZZ-090-009"></a>[\[ZZ-090-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-009) 冬，楚子及诸侯围宋，宋公孙固如晋告急。先轸曰：「报施救患，取威定霸，于是乎在矣。」狐偃曰：「楚始得曹，而新昏于卫，若伐曹、卫，楚必救之，则齐、宋免矣。」于是乎搜于被庐，作三军，谋元帅。赵衰曰：「郤縠可。臣亟闻其言矣，说《礼》、《乐》而敦《诗》、《书》。《诗》、《书》，义之府也；《礼》、《乐》，德之则也；德、义，利之本也。《夏书》曰：『赋纳以言，明试以功，车服以庸。』君其试之。」乃使郤縠将中军，郤溱佐之；使狐偃将上军，让于狐毛而佐之；命赵衰为卿，让于栾枝、先轸；使栾枝将下军，先轸佐之。荀林父御戎，魏犨为右。

<a id="ZZ-090-010"></a>[\[ZZ-090-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-090-010) 晋侯始入而教其民，二年，欲用之。子犯曰：「民未知义，未安其居。」于是乎出定襄王，入务利民，民怀生矣。将用之，子犯曰：「民未知信，未宣其用。」于是乎伐原以示之信。民易资者，不求丰焉，明征其辞。公曰：「可矣乎？」子犯曰：「民未知礼，未生其共。」于是乎大搜以示之礼。作执秩以正其官，民听不惑，而后用之。出谷戍，释宋围，一战而霸，文之教也。
