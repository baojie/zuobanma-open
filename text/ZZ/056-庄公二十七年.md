### 经

<a id="ZZ-056-001"></a>[\[ZZ-056-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-001) 二十有七年春，公会杞伯姬于洮。

<a id="ZZ-056-002"></a>[\[ZZ-056-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-002) 夏六月，公会齐侯、宋公、陈侯、郑伯同盟于幽。

<a id="ZZ-056-003"></a>[\[ZZ-056-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-003) 秋，公子友如陈，葬原仲。

<a id="ZZ-056-004"></a>[\[ZZ-056-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-004) 冬，杞伯姬来。莒庆来逆叔姬。杞伯来朝。公会齐侯于城濮。

### 传

<a id="ZZ-056-005"></a>[\[ZZ-056-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-005) 二十七年春，公会杞伯姬于洮，非事也。天子非展义不巡守，诸侯非民事不举，卿非君命不越竟。

<a id="ZZ-056-006"></a>[\[ZZ-056-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-006) 夏，同盟于幽，陈、郑服也。

<a id="ZZ-056-007"></a>[\[ZZ-056-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-007) 秋，公子友如陈，葬原仲，非礼也。原仲，季友之旧也。

<a id="ZZ-056-008"></a>[\[ZZ-056-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-008) 冬，杞伯姬来，归宁也。凡诸侯之女，归宁曰来，出曰来归。夫人归宁曰如某，出曰归于某。

<a id="ZZ-056-009"></a>[\[ZZ-056-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-009) 晋侯将伐虢，士𫇭曰：『不可，虢公骄，若骤得胜于我，必弃其民。无众而后伐之，欲御我谁与？夫礼乐慈爱，战所畜也。夫民让事乐和，爱亲哀丧而后可用也。虢弗畜也，亟战将饥。』

<a id="ZZ-056-010"></a>[\[ZZ-056-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-056-010) 王使召伯廖赐齐侯命，且请伐卫，以其立子颓也。
