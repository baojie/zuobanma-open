### 经

<a id="ZZ-008-001"></a>[\[ZZ-008-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-001) 八年，春，宋公、卫侯遇于垂。

<a id="ZZ-008-002"></a>[\[ZZ-008-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-002) 三月，郑伯使宛来归祊。庚寅，我入祊。

<a id="ZZ-008-003"></a>[\[ZZ-008-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-003) 夏，六月，己亥，蔡侯考父卒。辛亥，宿男卒。

<a id="ZZ-008-004"></a>[\[ZZ-008-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-004) 秋，七月，庚午，宋公、齐侯、卫侯盟于瓦屋。

<a id="ZZ-008-005"></a>[\[ZZ-008-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-005) 八月，葬蔡宣公。

<a id="ZZ-008-006"></a>[\[ZZ-008-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-006) 九月辛卯，公及莒人盟于浮来。

<a id="ZZ-008-007"></a>[\[ZZ-008-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-007) 螟。

<a id="ZZ-008-008"></a>[\[ZZ-008-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-008) 冬十有二月，无骇卒。

### 传

<a id="ZZ-008-009"></a>[\[ZZ-008-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-009) 八年春，齐侯将平宋、卫，有会期。宋公以币请于卫，请先相见，卫侯许之，故遇于犬丘。

<a id="ZZ-008-010"></a>[\[ZZ-008-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-010) 郑伯请释泰山之祀而祀周公，以泰山之祊易许田。三月，郑伯使宛来归祊，不祀泰山也。

<sub>被引：[Q33](../../qa/Q33.md)、[Q60](../../qa/Q60.md)</sub>

<a id="ZZ-008-011"></a>[\[ZZ-008-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-011) 夏，虢公忌父始作卿士于周。

<a id="ZZ-008-012"></a>[\[ZZ-008-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-012) 四月甲辰，郑公子忽如陈逆妇妫。辛亥，以妫氏归。甲寅，入于郑。陈针子送女。先配而后祖。针子曰：「是不为夫妇。诬其祖矣，非礼也，何以能育？」

<a id="ZZ-008-013"></a>[\[ZZ-008-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-013) 齐人卒平宋、卫于郑。秋，会于温，盟于瓦屋，以释东门之役，礼也。

<a id="ZZ-008-014"></a>[\[ZZ-008-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-014) 八月丙戌，郑伯以齐人朝王，礼也。

<a id="ZZ-008-015"></a>[\[ZZ-008-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-015) 公及莒人盟于浮来，以成纪好也。

<a id="ZZ-008-016"></a>[\[ZZ-008-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-016) 冬，齐侯使来告成三国。公使众仲对曰：「君释三国之图，以鸠其民，君之惠也。寡君闻命矣，敢不承受君之明德。」

<a id="ZZ-008-017"></a>[\[ZZ-008-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%AB%E5%B9%B4?pn=ZZ-008-017) 无骇卒。羽父请谥与族。公问族于众仲。众仲对曰：「天子建德，因生以赐姓，胙之土而命之氏。诸侯以字为谥，因以为族。官有世功，则有官族，邑亦如之。」公命以字为展氏。
