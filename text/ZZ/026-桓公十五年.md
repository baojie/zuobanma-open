### 经

<a id="ZZ-026-001"></a>[\[ZZ-026-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-001) 十有五年，春，二月，天王使家父来求车。三月乙未，天王崩。

<a id="ZZ-026-002"></a>[\[ZZ-026-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-002) 夏，四月己巳，葬齐僖公。五月，郑伯突出奔蔡。郑世子忽复归于郑。许叔入于许。公会齐侯于艾。邾人、牟人、葛人来朝。

<a id="ZZ-026-003"></a>[\[ZZ-026-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-003) 秋，九月，郑伯突入于栎。

<a id="ZZ-026-004"></a>[\[ZZ-026-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-004) 冬，十有一月，公会宋公、卫侯、陈侯于袲，伐郑。

### 传

<a id="ZZ-026-005"></a>[\[ZZ-026-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-005) 十五年春，天王使家父来求车，非礼也。诸侯不贡车、服，天子不私求财。

<a id="ZZ-026-006"></a>[\[ZZ-026-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-006) 祭仲专，郑伯患之，使其婿雍纠杀之。将享诸郊。雍姬知之，谓其母曰：「父与夫孰亲？」其母曰：「人尽夫也，父一而已，胡可比也？」遂告祭仲曰：「雍氏舍其室而将享子于郊，吾惑之，以告。」祭仲杀雍纠，尸诸周氏之汪。公载以出，曰：「谋及妇人，宜其死也。」夏，厉公出奔蔡。

<a id="ZZ-026-008"></a>[\[ZZ-026-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-008) 许叔入于许。

<a id="ZZ-026-009"></a>[\[ZZ-026-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-009) 公会齐侯于艾，谋定许也。

<a id="ZZ-026-010"></a>[\[ZZ-026-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-010) 秋，郑伯因栎人杀檀伯，而遂居栎。

<a id="ZZ-026-011"></a>[\[ZZ-026-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%94%E5%B9%B4?pn=ZZ-026-011) 冬，会于袲，谋伐郑，将纳厉公也。弗克而还。
