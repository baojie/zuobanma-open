### 经

<a id="ZZ-010-001"></a>[\[ZZ-010-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-001) 十年，春，王二月，公会齐侯、郑伯于中丘。

<a id="ZZ-010-002"></a>[\[ZZ-010-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-002) 夏，翚帅师会齐人、郑人伐宋。

<a id="ZZ-010-003"></a>[\[ZZ-010-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-003) 六月，壬戌，公败宋师于菅。辛未，取郜。辛巳，取防。

<a id="ZZ-010-004"></a>[\[ZZ-010-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-004) 秋，宋人、卫人入郑。宋人、蔡人、卫人伐戴。郑伯伐取之。

<a id="ZZ-010-005"></a>[\[ZZ-010-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-005) 冬，十月，壬午，齐人、郑人入郕。

### 传

<a id="ZZ-010-006"></a>[\[ZZ-010-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-006) 十年春，王正月，公会齐侯，郑伯于中丘。癸丑，盟于邓，为师期。

<a id="ZZ-010-007"></a>[\[ZZ-010-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-007) 夏五月，羽父先会齐侯、郑伯伐宋。

<a id="ZZ-010-008"></a>[\[ZZ-010-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-008) 六月戊申，公会齐侯、郑伯于老桃。壬戌，公败宋师于菅。庚午，郑师入郜。辛未，归于我。庚辰，郑师入防。辛巳，归于我。君子谓：「郑庄公于是乎可谓正矣。以王命讨不庭，不贪其土以劳王爵，正之体也。」

<a id="ZZ-010-009"></a>[\[ZZ-010-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-009) 蔡人、卫人、郕人不会王命。

<a id="ZZ-010-010"></a>[\[ZZ-010-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-010) 秋七月庚寅，郑师入郊。犹在郊，宋人、卫人入郑。蔡人从之伐戴。八月壬戌，郑伯围戴。癸亥，克之，取三师焉。宋、卫既入郑，而以伐戴召蔡人，蔡人怒，故不和而败。

<a id="ZZ-010-011"></a>[\[ZZ-010-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-011) 九月戊寅，郑伯入宋。

<a id="ZZ-010-012"></a>[\[ZZ-010-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-010-012) 冬，齐人、郑人入郕，讨违王命也。
