### 经

<a id="ZZ-065-001"></a>[\[ZZ-065-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-001) 二年春，王正月。城楚丘。

<a id="ZZ-065-002"></a>[\[ZZ-065-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-002) 夏五月，辛巳，葬我小君哀姜。虞师、晋师灭下阳。

<a id="ZZ-065-003"></a>[\[ZZ-065-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-003) 秋九月，齐侯、宋公、江人、黄人盟于贯。

<a id="ZZ-065-004"></a>[\[ZZ-065-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-004) 冬十月，不雨。楚人侵郑。

### 传

<a id="ZZ-065-005"></a>[\[ZZ-065-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-005) 二年春，诸侯城楚丘而封卫焉。不书，所会后也。

<a id="ZZ-065-006"></a>[\[ZZ-065-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-006) 晋荀息请以屈产之乘，与垂棘之璧，假道于虞以伐虢。公曰：「是吾宝也。」对曰：「若得道于虞，犹外府也。」公曰：「宫之奇存焉。」对曰：「宫之奇之为人也，懦而不能强谏。且少长于君，君暱之。虽谏，将不听。」乃使荀息假道于虞，曰：「冀为不道，入自颠𫐉，伐鄍三门。冀之既病，则亦唯君故。今虢为不道，保于逆旅，以侵敝邑之南鄙。敢请假道以请罪于虢。」虞公许之，且请先伐虢。宫之奇谏，不听，遂起师。

<a id="ZZ-065-007"></a>[\[ZZ-065-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-007) 夏，晋里克、荀息帅师会虞师伐虢，灭下阳。先书虞，贿故也。

<a id="ZZ-065-008"></a>[\[ZZ-065-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-008) 秋，盟于贯，服江、黄也。

<a id="ZZ-065-009"></a>[\[ZZ-065-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-009) 齐寺人貂始漏师于多鱼。

<a id="ZZ-065-010"></a>[\[ZZ-065-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-010) 虢公败戎于桑田。晋卜偃曰：「虢必亡矣。亡下阳不惧，而又有功，是天夺之鉴，而益其疾也！必易晋而不抚其民矣，不可以五稔。」

<a id="ZZ-065-011"></a>[\[ZZ-065-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%B9%B4?pn=ZZ-065-011) 冬，楚人伐郑，斗章囚郑聃伯。
