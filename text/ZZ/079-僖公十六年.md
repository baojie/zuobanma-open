### 经

<a id="ZZ-079-001"></a>[\[ZZ-079-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-001) 十有六年春，王正月，戊申朔，陨石于宋五。是月，六鹢退飞，过宋都。

<sub>被引：[Q120](../../qa/Q120.md) · 对读：[HS-027-411](../HS/027-%E4%BA%94%E8%A1%8C%E5%BF%97.md#HS-027-411)</sub>

<a id="ZZ-079-002"></a>[\[ZZ-079-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-002) 三月，壬申，公子季友卒。

<a id="ZZ-079-003"></a>[\[ZZ-079-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-003) 夏，四月，丙申，鄫季姬卒。

<a id="ZZ-079-004"></a>[\[ZZ-079-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-004) 秋，七月，甲子，公孙兹卒。

<a id="ZZ-079-005"></a>[\[ZZ-079-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-005) 冬，十有二月，公会齐侯、宋公、陈侯、卫侯、郑伯、许男、邢侯、曹伯于淮。

### 传

<a id="ZZ-079-006"></a>[\[ZZ-079-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-006) 十六年春，陨石于宋五，陨星也。六鹢退飞，过宋都，风也。周内史叔兴聘于宋，宋襄公问焉，曰：「是何祥也？吉凶焉在？」对曰：「今兹鲁多大丧，明年齐有乱。君将得诸侯而不终。」退而告人曰：「君失问。是阴阳之事，非吉凶所生也。吉凶由人，吾不敢逆君故也。」

<sub>被引：[Q120](../../qa/Q120.md) · 对读：[HS-027-411](../HS/027-%E4%BA%94%E8%A1%8C%E5%BF%97.md#HS-027-411)</sub>

<a id="ZZ-079-007"></a>[\[ZZ-079-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-007) 夏，齐伐厉，不克。救徐而还。

<a id="ZZ-079-008"></a>[\[ZZ-079-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-008) 秋，狄侵晋，取狐、厨、受铎，涉汾，及昆都，因晋败也。

<a id="ZZ-079-009"></a>[\[ZZ-079-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-009) 王以戎难告于齐，齐征诸侯而戍周。

<a id="ZZ-079-010"></a>[\[ZZ-079-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-010) 冬，十一月，乙卯，郑杀子华。

<a id="ZZ-079-011"></a>[\[ZZ-079-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-011) 十二月，会于淮，谋鄫，且东略也。

<a id="ZZ-079-012"></a>[\[ZZ-079-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-079-012) 城鄫，役人病，有夜登丘而呼曰：「齐有乱。」不果城而还。
