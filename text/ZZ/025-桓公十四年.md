### 经

<a id="ZZ-025-001"></a>[\[ZZ-025-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-001) 十有四年，春，正月，公会郑伯于曹。无冰。

<sub>被引：[Q120](../../qa/Q120.md)</sub>

<a id="ZZ-025-002"></a>[\[ZZ-025-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-002) 夏，五，郑伯使其弟语来盟。

<a id="ZZ-025-003"></a>[\[ZZ-025-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-003) 秋，八月壬申，御廪灾。乙亥，尝。

<a id="ZZ-025-004"></a>[\[ZZ-025-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-004) 冬，十有二月丁巳，齐侯禄父卒。宋人以齐人、蔡人、卫人、陈人伐郑。

### 传

<a id="ZZ-025-005"></a>[\[ZZ-025-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-005) 十四年春，会于曹。曹人致饩，礼也。

<a id="ZZ-025-006"></a>[\[ZZ-025-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-006) 夏，郑子人来寻盟，且修曹之会。

<a id="ZZ-025-007"></a>[\[ZZ-025-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-007) 秋八月壬申，御廪灾。乙亥，尝。书，不害也。

<a id="ZZ-025-008"></a>[\[ZZ-025-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-025-008) 冬，宋人以诸侯伐郑，报宋之战也。焚渠门，入，及大逵。伐东郊，取牛首。以大宫之椽归，为卢门之椽。
