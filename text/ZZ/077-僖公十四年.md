### 经

<a id="ZZ-077-001"></a>[\[ZZ-077-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-001) 十有四年春，诸侯城缘陵。

<a id="ZZ-077-002"></a>[\[ZZ-077-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-002) 夏，六月，季姬及鄫子遇于防，使鄫子来朝。

<a id="ZZ-077-003"></a>[\[ZZ-077-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-003) 秋，八月，辛卯，沙鹿崩。狄侵郑。

<a id="ZZ-077-004"></a>[\[ZZ-077-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-004) 冬，蔡侯肸卒。

### 传

<a id="ZZ-077-005"></a>[\[ZZ-077-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-005) 十四年春，诸侯城缘陵而迁杞焉。不书其人，有阙也。

<a id="ZZ-077-006"></a>[\[ZZ-077-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-006) 鄫季姬来宁，公怒，止之，以鄫子之不朝也。

<a id="ZZ-077-007"></a>[\[ZZ-077-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-007) 夏，遇于防，而使来朝。

<a id="ZZ-077-008"></a>[\[ZZ-077-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-008) 秋，八月，辛卯，沙鹿崩。晋卜偃曰：「期年将有大咎，几亡国。」

<a id="ZZ-077-009"></a>[\[ZZ-077-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-077-009) 冬，秦饥，使乞籴于晋。晋人弗与。庆郑曰：「背施无亲，幸灾不仁，贪爱不祥，怒邻不义。四德皆失，何以守国？」虢射曰：「皮之不存，毛将安傅？」庆郑曰：「弃信背邻，患孰恤之？无信患作，失援必毙。是则然矣。」虢射曰：「无损于怨，而厚于寇，不如勿与。」庆郑曰：「背施幸灾，民所弃也。近犹雠之，况怨敌乎？」弗听。退曰：「君其悔是哉！」
