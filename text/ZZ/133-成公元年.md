### 经

<a id="ZZ-133-001"></a>[\[ZZ-133-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-001) 元年春。王正月。公即位。

<a id="ZZ-133-002"></a>[\[ZZ-133-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-002) 二月。辛酉。葬我君宣公。无冰。

<a id="ZZ-133-003"></a>[\[ZZ-133-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-003) 三月。作丘甲。

<a id="ZZ-133-004"></a>[\[ZZ-133-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-004) 夏。臧孙许。及晋侯。盟于赤棘。

<a id="ZZ-133-005"></a>[\[ZZ-133-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-005) 秋。王师败绩于茅戎。

<a id="ZZ-133-006"></a>[\[ZZ-133-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-006) 冬。十月。

### 传

<a id="ZZ-133-007"></a>[\[ZZ-133-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-007) 元年春。晋侯使瑕嘉平戎于王。单襄公如晋拜成。刘康公徼戎。将遂伐之。叔服曰。背盟而欺大国。此必败。背盟不祥。欺大国不义。神人弗助。将何以胜。不听。遂伐茅戎。

<a id="ZZ-133-008"></a>[\[ZZ-133-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-008) 三月。癸未。败绩于徐吾氏。为齐难故。作丘甲。闻齐将出楚师。

<a id="ZZ-133-009"></a>[\[ZZ-133-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-009) 夏。盟于赤棘。

<a id="ZZ-133-010"></a>[\[ZZ-133-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-010) 秋。王人来告败。

<a id="ZZ-133-011"></a>[\[ZZ-133-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-133-011) 冬。臧宣叔令修赋缮完。具守备。曰。齐楚结好。我新与晋盟。晋楚争盟。齐师必至。虽晋人伐齐。楚必救之。是齐楚同我也。知难而有备。乃可以逞。
