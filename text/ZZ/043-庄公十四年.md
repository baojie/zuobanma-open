### 经

<a id="ZZ-043-001"></a>[\[ZZ-043-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-001) 十有四年春，齐人、陈人、曹人伐宋。

<a id="ZZ-043-002"></a>[\[ZZ-043-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-002) 夏，单伯会伐宋。

<a id="ZZ-043-003"></a>[\[ZZ-043-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-003) 秋七月，荆入蔡。

<a id="ZZ-043-004"></a>[\[ZZ-043-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-004) 冬，单伯会齐侯、宋公、卫侯、郑伯于鄄。

### 传

<a id="ZZ-043-005"></a>[\[ZZ-043-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-005) 十四年春，诸侯伐宋，齐请师于周。夏，单伯会之，取成于宋而还。

<a id="ZZ-043-006"></a>[\[ZZ-043-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-006) 郑厉公自栎侵郑，及大陵，获傅瑕。傅瑕曰：『苟舍我，吾请纳君。』与之盟而赦之。六月甲子，傅瑕杀郑子及其二子而纳厉公。

<a id="ZZ-043-007"></a>[\[ZZ-043-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-007) 初，内蛇与外蛇斗于郑南门中，内蛇死。六年而厉公入。公闻之，问于申𦈡曰：『犹有妖乎？』对曰：『人之所忌，其气焰以取之，妖由人兴也。人无衅焉，妖不自作。人弃常则妖兴，故有妖。』

<sub>被引：[Q120](../../qa/Q120.md) · 对读：[HS-027-282](../HS/027-%E4%BA%94%E8%A1%8C%E5%BF%97.md#HS-027-282)</sub>

<a id="ZZ-043-008"></a>[\[ZZ-043-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-008) 厉公入，遂杀傅瑕。使谓原繁曰：『傅瑕贰，周有常刑，既伏其罪矣。纳我而无二心者，吾皆许之上大夫之事，吾愿与伯父图之。且寡人出，伯父无里言，入，又不念寡人，寡人憾焉。』对曰：『先君桓公命我先人典司宗祏。社稷有主而外其心，其何贰如之？苟主社稷，国内之民其谁不为臣？臣无二心，天之制也。子仪在位十四年矣，而谋召君者，庸非二乎。庄公之子犹有八人，若皆以官爵行赂劝贰而可以济事，君其若之何？臣闻命矣。』乃缢而死。

<a id="ZZ-043-009"></a>[\[ZZ-043-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-009) 蔡哀侯为莘故，绳息妫以语楚子。楚子如息，以食入享，遂灭息。以息妫归，生堵敖及成王焉，未言。楚子问之，对曰：『吾一妇人而事二夫，纵弗能死，其又奚言？』楚子以蔡侯灭息，遂伐蔡。秋七月，楚入蔡。

<sub>被引：[Q149](../../qa/Q149.md)</sub>

<a id="ZZ-043-010"></a>[\[ZZ-043-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-010) 君子曰：『《商书》所谓「恶之易也，如火之燎于原，不可乡迩，其犹可扑灭」者，其如蔡哀侯乎。』

<a id="ZZ-043-011"></a>[\[ZZ-043-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4?pn=ZZ-043-011) 冬，会于鄄，宋服故也。
