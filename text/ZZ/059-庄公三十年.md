<a id="ZZ-059-002"></a>[\[ZZ-059-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-002) 夏，次于成。

<a id="ZZ-059-003"></a>[\[ZZ-059-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-003) 秋七月，齐人降鄣。

<a id="ZZ-059-004"></a>[\[ZZ-059-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-004) 八月癸亥，葬纪叔姬。

<a id="ZZ-059-005"></a>[\[ZZ-059-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-005) 九月庚午朔，日有食之。鼓，用牲于社。

### 传

<a id="ZZ-059-007"></a>[\[ZZ-059-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-007) 三十年春，王命虢公讨樊皮。夏四月丙辰，虢公入樊，执樊仲皮，归于亰师。

<a id="ZZ-059-008"></a>[\[ZZ-059-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-008) 楚公子元归自伐郑，而处王宫，鬭射师谏，则执而梏之。

<a id="ZZ-059-009"></a>[\[ZZ-059-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-009) 秋，申公鬭班杀子元，鬭谷於菟为令尹，自毁其家以纾楚国之难。

<a id="ZZ-059-010"></a>[\[ZZ-059-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%B8%89%E5%8D%81%E5%B9%B4?pn=ZZ-059-010) 冬，遇于鲁济，谋山戎也，以其病燕故也。
