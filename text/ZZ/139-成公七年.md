### 经

<a id="ZZ-139-001"></a>[\[ZZ-139-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-001) 七年春。王正月。鼷鼠食郊牛角。改卜牛。鼷鼠又食其角。乃免牛。吴伐郯。

<sub>对读：[HS-027-090](../HS/027-%E4%BA%94%E8%A1%8C%E5%BF%97.md#HS-027-090)</sub>

<a id="ZZ-139-002"></a>[\[ZZ-139-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-002) 夏。五月。曹伯来朝。不郊犹三望。

<a id="ZZ-139-003"></a>[\[ZZ-139-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-003) 秋。楚公子婴齐帅师伐郑。公会晋侯。齐侯。宋公。卫侯。曹伯。莒子。邾子。杞伯。救郑。

<a id="ZZ-139-004"></a>[\[ZZ-139-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-004) 八月。戊辰。同盟于马陵。公至自会。吴入州来。

<a id="ZZ-139-005"></a>[\[ZZ-139-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-005) 冬。大雩。卫孙林父出奔晋。

### 传

<a id="ZZ-139-006"></a>[\[ZZ-139-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-006) 七年春。吴伐郯。郯成。季文子曰。中国不振旅。蛮夷入伐。而莫之或恤。无吊者也。夫。诗曰。不吊昊天。乱靡有定。其此之谓乎。有上不吊。其谁不受乱。吾亡无日矣。君子曰。知惧如是。斯不亡矣。郑子良相成公以如晋见。且拜师。

<a id="ZZ-139-007"></a>[\[ZZ-139-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-007) 夏。曹宣公来朝。

<sub>被引：[Q178](../../qa/Q178.md)</sub>

<a id="ZZ-139-008"></a>[\[ZZ-139-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-008) 秋。楚子重伐郑。师于泛。诸侯救郑。郑共仲。侯羽。军楚师。囚郧公钟仪。献诸晋。

<a id="ZZ-139-009"></a>[\[ZZ-139-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-139-009) 八月。同盟于马陵。寻虫牢之盟。且莒服故也。晋人以钟仪归。囚诸军府。楚围宋之役。师还。子重请取于申吕。以为赏田。王许之。申公巫臣曰。不可。此申吕所以邑也。是以为赋。以御北方。若取之。是无申吕也。晋郑必至于汉。王乃止。子重是以怨巫臣。子反欲取夏姬。巫臣止之。遂取以行。子反亦怨之。及共王即位。子重。子反。杀巫臣之族子阎。子荡。及清尹弗忌。及襄老之子黑要。而分其室。子重取子阎之室。使沈尹。与王子罢。分子荡之室。子反取黑要。与清尹之室。巫臣自晋遗二子书曰。尔以谗慝贪惏事君。而多杀不辜。余必使尔罢于奔命以死。巫臣请使于吴。晋侯许之。吴子寿梦说之。乃通吴于晋。以两之一卒适吴。舍偏两之一焉。与其射御。教吴乘车。教之战陈。教之叛楚。寘其子狐庸焉。使为行人于吴。吴始伐楚。伐巢。伐徐。子重奔命。马陵之会。吴入州来。子重自郑奔命。子重。子反。于是乎一岁七奔命。蛮夷属于楚者。吴尽取之。是以始大。通吴于上国。卫定公恶孙林父。冬。孙林父出奔晋。卫侯如晋。晋反戚焉。
