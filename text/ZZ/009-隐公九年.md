### 传

<a id="ZZ-009-007"></a>[\[ZZ-009-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-007) 九年春，王三月癸酉，大雨霖以震，书始也。庚辰，大雨雪，亦如之。书，时失也。凡雨，自三日以往为霖。平地尺为大雪。

<a id="ZZ-009-008"></a>[\[ZZ-009-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-008) 夏，城郎，书，不时也。

<a id="ZZ-009-009"></a>[\[ZZ-009-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-009) 宋公不王。郑伯为王左卿士，以王命讨之，伐宋。宋以入郛之役怨公，不告命。公怒，绝宋使。

<a id="ZZ-009-010"></a>[\[ZZ-009-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-010) 秋，郑人以王命来告伐宋。

<a id="ZZ-009-011"></a>[\[ZZ-009-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-011) 冬，公会齐侯于防，谋伐宋也。

<a id="ZZ-009-012"></a>[\[ZZ-009-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-012) 北戎侵郑，郑伯御之。患戎师，曰：「彼徒我车，惧其侵轶我也。」公子突曰：「使勇而无刚者，尝寇而速去之。君为三覆以待之。戎轻而不整，贪而无亲，胜不相让，败不相救。先者见获必务进，进而遇覆必速奔，后者不救，则无继矣。乃可以逞。」从之。

<a id="ZZ-009-013"></a>[\[ZZ-009-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-009-013) 戎人之前遇覆者奔，祝聃逐之。衷戎师，前后击之，尽殪。戎师大奔。十一月甲寅，郑人大败戎师。
