### 经

<a id="ZZ-082-001"></a>[\[ZZ-082-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-001) 十有九年春，王三月，宋人执滕子婴齐。

<a id="ZZ-082-002"></a>[\[ZZ-082-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-002) 夏，六月，宋公、曹人、邾人盟于曹南。鄫子会盟于邾。己酉，邾人执鄫子用之。

<a id="ZZ-082-003"></a>[\[ZZ-082-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-003) 秋，宋人围曹。卫人伐邢。

<a id="ZZ-082-004"></a>[\[ZZ-082-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-004) 冬，会陈人、蔡人、楚人、郑人，盟于齐。梁亡。

### 传

<a id="ZZ-082-005"></a>[\[ZZ-082-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-005) 十九年春，遂城而居之。

<a id="ZZ-082-006"></a>[\[ZZ-082-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-006) 宋人执滕宣公。

<a id="ZZ-082-007"></a>[\[ZZ-082-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-007) 夏，宋公使邾文公用鄫子于次睢之社，欲以属东夷。司马子鱼曰：「古者六畜不相为用，小事不用大牲，而况敢用人乎？祭祀以为人也。民，神之主也。用人，其谁飨之？齐桓公存三亡国以属诸侯，义士犹曰薄德。今一会而虐二国之君，又用诸淫昏之鬼，将以求霸，不亦难乎？得死为幸。」

<sub>被引：[Q26](../../qa/Q26.md)、[Q125](../../qa/Q125.md)、[Q136](../../qa/Q136.md)</sub>

<a id="ZZ-082-008"></a>[\[ZZ-082-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-008) 秋，卫人伐邢，以报菟圃之役。于是卫大旱，卜有事于山川，不吉。宁庄子曰：「昔周饥，克殷而年丰。今邢方无道，诸侯无伯，天其或者欲使卫讨邢乎？」从之，师兴而雨。

<a id="ZZ-082-009"></a>[\[ZZ-082-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-009) 宋人围曹，讨不服也。子鱼言于宋公曰：「文王闻崇德乱而伐之，军三旬而不降。退修教而复伐之，因垒而降。《诗》曰：『刑于寡妻，至于兄弟，以御于家邦。』今君德无乃犹有所阙，而以伐人，若之何？盍姑内省德乎，无阙而后动。」

<sub>被引：[Q47](../../qa/Q47.md)、[Q178](../../qa/Q178.md)</sub>

<a id="ZZ-082-010"></a>[\[ZZ-082-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-010) 陈穆公请修好于诸侯，以无忘齐桓之德。

<sub>被引：[Q26](../../qa/Q26.md)</sub>

<a id="ZZ-082-011"></a>[\[ZZ-082-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-011) 冬，盟于齐，修桓公之好也。

<sub>被引：[Q26](../../qa/Q26.md)</sub>

<a id="ZZ-082-012"></a>[\[ZZ-082-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-082-012) 梁亡，不书其主，自取之也。初，梁伯好土功，亟城而弗处，民罢而弗堪，则曰「某寇将至。」乃沟公宫，曰：「秦将袭我。」民惧而溃，秦遂取梁。
