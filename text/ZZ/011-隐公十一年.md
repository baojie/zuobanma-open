### 经

<a id="ZZ-011-001"></a>[\[ZZ-011-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-001) 十有一年，春，滕侯、薛侯来朝。

<a id="ZZ-011-002"></a>[\[ZZ-011-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-002) 夏，公会郑伯于时来。

<a id="ZZ-011-003"></a>[\[ZZ-011-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-003) 秋，七月，壬午，公及齐侯、郑伯入许。

<a id="ZZ-011-004"></a>[\[ZZ-011-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-004) 冬十有一月，壬辰，公薨。

### 传

<a id="ZZ-011-005"></a>[\[ZZ-011-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-005) 十一年春，滕侯、薛侯来朝，争长。薛侯曰：「我先封。」滕侯曰：「我，周之卜正也。薛，庶姓也，我不可以后之。」

<a id="ZZ-011-006"></a>[\[ZZ-011-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-006) 公使羽父请于薛侯曰：「君与滕君辱在寡人。周谚有之曰：『山有木，工则度之；宾有礼，主则择之。』周之宗盟，异姓为后。寡人若朝于薛，不敢与诸任齿。君若辱贶寡人，则愿以滕君为请。」

<a id="ZZ-011-007"></a>[\[ZZ-011-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-007) 薛侯许之，乃长滕侯。

<a id="ZZ-011-008"></a>[\[ZZ-011-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-008) 夏，公会郑伯于郲，谋伐许也。郑伯将伐许，五月甲辰，授兵于大宫。公孙阏与颍考叔争车，颍考叔挟辀以走，子都拔棘以逐之，及大逵，弗及，子都怒。

<a id="ZZ-011-009"></a>[\[ZZ-011-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-009) 秋七月，公会齐侯、郑伯伐许。庚辰，傅于许，颍考叔取郑伯之旗蝥弧以先登。子都自下射之，颠。瑕叔盈又以蝥弧登，周麾而呼曰：「君登矣！」郑师毕登。壬午，遂入许。许庄公奔卫。

<a id="ZZ-011-010"></a>[\[ZZ-011-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-010) 齐侯以许让公。公曰：「君谓许不共，故从君讨之。许既伏其罪矣，虽君有命，寡人弗敢与闻。」乃与郑人。

<a id="ZZ-011-011"></a>[\[ZZ-011-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-011) 郑伯使许大夫百里奉许叔以居许东偏，曰：「天祸许国，鬼神实不逞于许君，而假手于我寡人。寡人唯是一二父兄不能共亿，其敢以许自为功乎？寡人有弟，不能和协，而使糊其口于四方，其况能久有许乎？吾子其奉许叔以抚柔此民也，吾将使获也佐吾子。若寡人得没于地，天其以礼悔祸于许？无宁兹许公复奉其社稷。唯我郑国之有请谒焉，如旧昬媾，其能降以相从也。无滋他族实偪处此，以与我郑国争此土也。吾子孙其覆亡之不暇，而况能禋祀许乎？寡人之使吾子处此，不唯许国之为，亦聊以固吾圉也。」乃使公孙获处许西偏，曰：「凡而器用财贿，无寘于许。我死，乃亟去之。吾先君新邑于此，王室而既卑矣，周之子孙日失其序。夫许，大岳之胤也，天而既厌周德矣，吾其能与许争乎？」

<a id="ZZ-011-012"></a>[\[ZZ-011-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-012) 君子谓：「郑庄公于是乎有礼。礼，经国家、定社稷、序民人、利后嗣者也。许，无刑而伐之，服而舍之，度德而处之，量力而行之，相时而动，无累后人，可谓知礼矣。」

<a id="ZZ-011-013"></a>[\[ZZ-011-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-013) 郑伯使卒出豭，行出犬、鸡，以诅射颍考叔者。君子谓：「郑庄公失政刑矣。政以治民，刑以正邪，既无德政，又无威刑，是以及邪。邪而诅之，将何益矣！」

<a id="ZZ-011-014"></a>[\[ZZ-011-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-014) 王取邬、刘、𫇭、邘之田于郑，而与郑人苏忿生之田：温、原、𫄨、樊、隰郕、𪴙茅、向、盟、州、陉、𬯎、怀。君子是以知桓王之失郑也。恕而行之，德之则也，礼之经也。己弗能有而以与人，人之不至，不亦宜乎？

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-011-015"></a>[\[ZZ-011-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-015) 郑、息有违言，息侯伐郑。郑伯与战于竟，息师大败而还。君子是以知息之将亡也。不度德，不量力，不亲亲，不征辞，不察有罪，犯五不韪，而以伐人，其丧师也，不亦宜乎！

<sub>被引：[Q152](../../qa/Q152.md)</sub>

<a id="ZZ-011-016"></a>[\[ZZ-011-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-016) 冬十月，郑伯以虢师伐宋。壬戌，大败宋师，以报其入郑也。宋不告命，故不书。凡诸侯有命，告则书，不然则否。师出臧否，亦如之。虽及灭国，灭不告败，胜不告克，不书于策。

<a id="ZZ-011-017"></a>[\[ZZ-011-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-011-017) 羽父请杀桓公，将以求大宰。公曰：「为其少故也，吾将授之矣。使营菟裘，吾将老焉。」羽父惧，反谮公于桓公，而请弑之。公之为公子也，与郑人战于狐壤，止焉。郑人囚诸尹氏，赂尹氏，而祷于其主钟巫，遂与尹氏归，而立其主。十一月，公祭钟巫，齐于社圃，馆于寪氏。壬辰，羽父使贼弑公于寪氏，立桓公，而讨寪氏，有死者。不书葬，不成丧也。
