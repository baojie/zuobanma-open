### 经

<a id="ZZ-081-001"></a>[\[ZZ-081-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-001) 十有八年春，王正月，宋公、曹伯、卫人、邾人，伐齐。

<a id="ZZ-081-002"></a>[\[ZZ-081-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-002) 夏，师救齐。

<a id="ZZ-081-003"></a>[\[ZZ-081-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-003) 五月，戊寅，宋师及齐师战于甗，齐师败绩。狄救齐。

<a id="ZZ-081-004"></a>[\[ZZ-081-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-004) 秋，八月，丁亥，葬齐桓公。

<sub>被引：[Q26](../../qa/Q26.md)</sub>

<a id="ZZ-081-005"></a>[\[ZZ-081-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-005) 冬，邢人、狄人伐卫。

### 传

<a id="ZZ-081-006"></a>[\[ZZ-081-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-006) 十八年春，宋襄公以诸侯伐齐。

<a id="ZZ-081-007"></a>[\[ZZ-081-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-007) 三月，齐人杀无亏。

<a id="ZZ-081-008"></a>[\[ZZ-081-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-008) 郑伯始朝于楚。楚子赐之金，既而悔之，与之盟曰：「无以铸兵。」故以铸三钟。

<a id="ZZ-081-009"></a>[\[ZZ-081-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-009) 齐人将立孝公，不胜四公子之徒，遂与宋人战。

<a id="ZZ-081-010"></a>[\[ZZ-081-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-010) 夏，五月，宋败齐师于甗，立孝公而还。

<sub>被引：[Q45](../../qa/Q45.md)、[Q180](../../qa/Q180.md)</sub>

<a id="ZZ-081-011"></a>[\[ZZ-081-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-011) 秋，八月，葬齐桓公。

<sub>被引：[Q26](../../qa/Q26.md)</sub>

<a id="ZZ-081-012"></a>[\[ZZ-081-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-081-012) 冬，邢人、狄人伐卫，围菟圃。卫侯以国让父兄子弟，及朝众，曰：「苟能治之，毁请从焉。」众不可，而后师于訾娄。狄师还。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>
