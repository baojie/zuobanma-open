### 经

<a id="ZZ-136-001"></a>[\[ZZ-136-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-001) 四年春。宋公使华元来聘。

<a id="ZZ-136-002"></a>[\[ZZ-136-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-002) 三月。壬申。郑伯坚卒。杞伯来朝。

<a id="ZZ-136-003"></a>[\[ZZ-136-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-003) 夏。四月。甲寅。臧孙许卒。公如晋。葬郑襄公。

<a id="ZZ-136-004"></a>[\[ZZ-136-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-004) 秋。公至自晋。

<a id="ZZ-136-005"></a>[\[ZZ-136-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-005) 冬。城郓。郑伯伐许。

### 传

<a id="ZZ-136-006"></a>[\[ZZ-136-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-006) 四年春。宋华元来聘。通嗣君也。杞伯来朝。归叔姬故也。

<sub>被引：[华元](../../entries/person/%E5%8D%8E%E5%85%83.md)</sub>

<a id="ZZ-136-007"></a>[\[ZZ-136-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-007) 夏。公如晋。晋侯见公不敬。季文子曰。晋侯必不免。诗曰。敬之敬之。天惟显思。命不易哉。夫晋侯之命。在诸侯矣。可不敬乎。

<sub>对读：[HS-083-043](../HS/083-%E5%8C%A1%E5%BC%A0%E5%AD%94%E9%A9%AC%E4%BC%A0.md#HS-083-043)</sub>

<a id="ZZ-136-008"></a>[\[ZZ-136-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-008) 秋。公至自晋。欲求成于楚。而叛晋。季文子曰。不可。晋虽无道。未可叛也。国大臣睦。而迩于我。诸侯听焉。未可以贰。史佚之志有之曰。非我族类。其心必异。楚虽大。非吾族也。其肯字我乎。公乃止。

<a id="ZZ-136-009"></a>[\[ZZ-136-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%88%90%E5%85%AC%E5%9B%9B%E5%B9%B4?pn=ZZ-136-009) 冬。十一月。郑公孙申帅师疆许田。许人败诸展陂。郑伯伐许。取鉏任泠敦之田。晋栾书将中军。荀首佐之。士燮佐上军。以救许。伐郑。取泛祭。楚子反救郑。郑伯与许男讼焉。皇戌摄郑伯之辞。子反不能决也。曰。君若辱在寡君。寡君与其二三臣。共听两君之所欲。成其可知也。不然。侧不足以知二国之成。晋赵婴通于赵庄姬。
