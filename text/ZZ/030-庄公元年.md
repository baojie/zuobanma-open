### 经

<a id="ZZ-030-001"></a>[\[ZZ-030-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-001) 元年春王正月。三月，夫人孙于齐。

<a id="ZZ-030-002"></a>[\[ZZ-030-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-002) 夏，单伯送王姬。

<a id="ZZ-030-003"></a>[\[ZZ-030-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-003) 秋，筑王姬之馆于外。

<a id="ZZ-030-004"></a>[\[ZZ-030-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-004) 冬十月乙亥，陈侯林卒。王使荣叔来锡桓公命。王姬归于齐。齐师迁纪、郱、鄑、郚。

### 传

<a id="ZZ-030-005"></a>[\[ZZ-030-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-005) 元年春，不称即位，文姜出故也。

<a id="ZZ-030-006"></a>[\[ZZ-030-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-006) 三月，夫人孙于齐。不称姜氏，绝不为亲，礼也。

<a id="ZZ-030-007"></a>[\[ZZ-030-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-030-007) 秋，筑王姬之馆于外。为外，礼也。
