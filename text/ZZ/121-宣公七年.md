### 经

<a id="ZZ-121-001"></a>[\[ZZ-121-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-001) 七年春，卫侯使孙良夫来盟。

<a id="ZZ-121-002"></a>[\[ZZ-121-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-002) 夏，公会齐侯伐莱。

<a id="ZZ-121-003"></a>[\[ZZ-121-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-003) 秋，公至自伐莱，大旱。

<a id="ZZ-121-004"></a>[\[ZZ-121-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-004) 冬，公会晋侯、宋公、卫侯、郑伯、曹伯，于黑壤。

### 传

<a id="ZZ-121-005"></a>[\[ZZ-121-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-005) 七年春，卫孙桓子来盟，始通，且谋会晋也。

<a id="ZZ-121-006"></a>[\[ZZ-121-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-006) 夏，公会齐侯伐莱，不与谋也。凡师出，与谋曰及，不与谋曰会。赤狄侵晋，取向阴之禾。郑及晋平，公子宋之谋也，故相郑伯以会。

<a id="ZZ-121-007"></a>[\[ZZ-121-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-121-007) 冬，盟于黑壤，王叔桓公临之，以谋不睦。晋侯之立也，公不朝焉，又不使大夫聘，晋人止公于会，盟于黄父，公不与盟，以赂免。故黑壤之盟不书，讳之也。
