### 经

<a id="ZZ-094-001"></a>[\[ZZ-094-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-001) 三十有一年春，取济西田。公子遂如晋。

<a id="ZZ-094-002"></a>[\[ZZ-094-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-002) 夏，四月，四卜郊，不从，乃免牲。犹三望。

<a id="ZZ-094-003"></a>[\[ZZ-094-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-003) 秋，七月。

<a id="ZZ-094-004"></a>[\[ZZ-094-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-004) 冬，杞伯姬来求妇。狄围卫。

<a id="ZZ-094-005"></a>[\[ZZ-094-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-005) 十有二月，卫迁于帝丘。

### 传

<a id="ZZ-094-006"></a>[\[ZZ-094-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-006) 三十一年春，取济西田，分曹地也。使臧文仲往，宿于重馆。重馆人告曰：「晋新得诸侯，必亲其共，不速行，将无及也。」从之。分曹地自洮以南，东傅于济，尽曹地也。

<a id="ZZ-094-007"></a>[\[ZZ-094-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-007) 襄仲如晋，拜曹田也。

<a id="ZZ-094-008"></a>[\[ZZ-094-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-008) 夏，四月，四卜郊，不从，乃免牲，非礼也。犹三望，亦非礼也。礼不卜常祀，而卜其牲日。牛卜日曰牲，牲成而卜郊。上怠慢也。望，郊之细也。不郊，亦无望可也。

<sub>被引：[Q125](../../qa/Q125.md)</sub>

<a id="ZZ-094-009"></a>[\[ZZ-094-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-009) 秋，晋搜于清原，作五军以御狄。赵衰为卿。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-094-010"></a>[\[ZZ-094-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-010) 冬，狄围卫，卫迁于帝丘。卜曰三百年。

<sub>被引：[Q166](../../qa/Q166.md)</sub>

<a id="ZZ-094-011"></a>[\[ZZ-094-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-011) 卫成公梦康叔曰：「相夺予享。」公命祀相。宁武子不可，曰：「鬼神非其族类，不歆其祀。杞、鄫何事？相之不享，于此久矣。非卫之罪也。不可以间成王、周公之命祀，请改祀命。」

<a id="ZZ-094-012"></a>[\[ZZ-094-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%B8%89%E5%8D%81%E4%B8%80%E5%B9%B4?pn=ZZ-094-012) 郑泄驾恶公子瑕，郑伯亦恶之，故公子瑕出奔楚。
