### 经

<a id="ZZ-007-001"></a>[\[ZZ-007-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-001) 七年，春，王三月，叔姬归于纪。

<a id="ZZ-007-002"></a>[\[ZZ-007-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-002) 滕侯卒。

<a id="ZZ-007-003"></a>[\[ZZ-007-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-003) 夏，城中丘。

<a id="ZZ-007-004"></a>[\[ZZ-007-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-004) 齐侯使其弟年来聘。

<a id="ZZ-007-005"></a>[\[ZZ-007-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-005) 秋，公伐邾。

<a id="ZZ-007-006"></a>[\[ZZ-007-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-006) 冬，天王使凡伯来聘。戎伐凡伯于楚丘，以归。

### 传

<a id="ZZ-007-007"></a>[\[ZZ-007-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-007) 七年春，滕侯卒。不书名，未同盟也。凡诸侯同盟，于是称名，故薨则赴以名，告终称嗣也，以继好息民，谓之礼经。

<a id="ZZ-007-008"></a>[\[ZZ-007-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-008) 夏，城中丘，书，不时也。

<a id="ZZ-007-009"></a>[\[ZZ-007-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-009) 齐侯使夷仲年来聘，结艾之盟也。

<a id="ZZ-007-010"></a>[\[ZZ-007-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-010) 秋，宋及郑平。七月庚申，盟于宿。公伐邾，为宋讨也。

<a id="ZZ-007-011"></a>[\[ZZ-007-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-011) 初，戎朝于周，发币于公卿，凡伯弗宾。冬，王使凡伯来聘。还，戎伐之于楚丘以归。

<a id="ZZ-007-012"></a>[\[ZZ-007-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-012) 陈及郑平。十二月，陈五父如郑涖盟。壬申，及郑伯盟，歃如忘。泄伯曰：「五父必不免，不赖盟矣。」郑良佐如陈涖盟，辛巳，及陈侯盟，亦知陈之将乱也。

<a id="ZZ-007-013"></a>[\[ZZ-007-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E4%B8%83%E5%B9%B4?pn=ZZ-007-013) 郑公子忽在王所，故陈侯请妻之。郑伯许之，乃成昬。
