### 经

<a id="ZZ-052-001"></a>[\[ZZ-052-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-001) 二十有三年春，公至自齐。祭叔来聘。

<a id="ZZ-052-002"></a>[\[ZZ-052-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-002) 夏，公如齐观社。公至自齐。荆人来聘。公及齐侯遇于谷。萧叔朝公。

<a id="ZZ-052-003"></a>[\[ZZ-052-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-003) 秋，丹桓宫楹。

<a id="ZZ-052-004"></a>[\[ZZ-052-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-004) 冬十有一月，曹伯射姑卒。

<sub>被引：[Q178](../../qa/Q178.md)</sub>

<a id="ZZ-052-005"></a>[\[ZZ-052-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-005) 十有二月甲寅，公会齐侯盟于扈。

### 传

<a id="ZZ-052-006"></a>[\[ZZ-052-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-006) 二十三年夏，公如齐观社，非礼也。曹刿谏曰：『不可。夫礼，所以整民也。故会以训上下之则，制财用之节；朝以正班爵之义，帅长幼之序；征伐以讨其不然。诸侯有王，王有巡守，以大习之。非是，君不举矣。君举必书，书而不法，后嗣何观？』

<sub>被引：[Q159](../../qa/Q159.md)</sub>

<a id="ZZ-052-007"></a>[\[ZZ-052-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-007) 晋桓、庄之族逼，献公患之。士𫇭曰：『去富子，则群公子可谋也已。』公曰：『尔试其事。』士𫇭与群公子谋，谮富子而去之。

<a id="ZZ-052-008"></a>[\[ZZ-052-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B8%89%E5%B9%B4?pn=ZZ-052-008) 秋，丹桓宫之楹。
