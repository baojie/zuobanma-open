### 经

<a id="ZZ-080-001"></a>[\[ZZ-080-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-001) 十有七年春，齐人、徐人伐英氏。

<a id="ZZ-080-002"></a>[\[ZZ-080-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-002) 夏，灭项。

<a id="ZZ-080-003"></a>[\[ZZ-080-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-003) 秋，夫人姜氏会齐侯于卞。

<a id="ZZ-080-004"></a>[\[ZZ-080-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-004) 九月，公至自会。

<a id="ZZ-080-005"></a>[\[ZZ-080-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-005) 冬，十有二月，乙亥，齐侯小白卒。

### 传

<a id="ZZ-080-006"></a>[\[ZZ-080-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-006) 十七年春，齐人为徐伐英氏，以报娄林之役也。

<a id="ZZ-080-007"></a>[\[ZZ-080-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-007) 夏，晋大子圉为质于秦，秦归河东而妻之。

<a id="ZZ-080-008"></a>[\[ZZ-080-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-008) 惠公之在梁也，梁伯妻之。梁嬴孕，过期。卜招父与其子卜之，其子曰：「将生一男一女。」招曰：「然。男为人臣，女为人妾。」故名男曰圉，女曰妾。及子圉西质，妾为宦女焉。

<sub>对读：[SJ-039-047](../SJ/039-%E6%99%8B%E4%B8%96%E5%AE%B6.md#SJ-039-047)</sub>

<a id="ZZ-080-009"></a>[\[ZZ-080-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-009) 师灭项。淮之会，公有诸侯之事，未归而取项。齐人以为讨而止公。

<a id="ZZ-080-010"></a>[\[ZZ-080-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-010) 秋，声姜以公故，会齐侯于卞。

<a id="ZZ-080-011"></a>[\[ZZ-080-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-011) 九月，公至。书曰「至自会」，犹有诸侯之事焉，且讳之也。

<a id="ZZ-080-012"></a>[\[ZZ-080-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-012) 齐侯之夫人三，王姬、徐嬴、蔡姬，皆无子。齐侯好内，多内宠，内嬖如夫人者六人：长卫姬生武孟，少卫姬生惠公，郑姬生孝公，葛嬴生昭公，密姬生懿公，宋华子生公子雍。公与管仲属孝公于宋襄公，以为大子。

<a id="ZZ-080-013"></a>[\[ZZ-080-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-013) 雍巫有宠于卫共姬，因寺人貂以荐羞于公，亦有宠。公许之，立武孟。管仲卒，五公子皆求立。

<a id="ZZ-080-014"></a>[\[ZZ-080-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E5%8D%81%E4%B8%83%E5%B9%B4?pn=ZZ-080-014) 冬，十月，乙亥，齐桓公卒。易牙入，与寺人貂因内宠以杀群吏，而立公子无亏。孝公奔宋。
