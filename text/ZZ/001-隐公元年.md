### 传

<a id="ZZ-001-001"></a>[\[ZZ-001-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-001) 惠公元妃孟子。孟子卒，继室以声子，生隐公。宋武公生仲子，仲子生而有文在其手，曰「为鲁夫人」。故仲子归于我，生桓公而惠公薨，是以隐公立而奉之。

### 经

<a id="ZZ-001-002"></a>[\[ZZ-001-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-002) 元年，春，王正月。

<a id="ZZ-001-004"></a>[\[ZZ-001-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-004) 夏，五月，郑伯克段于鄢。

### 传

<a id="ZZ-001-009"></a>[\[ZZ-001-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-009) 元年春，王周正月。不书即位，摄也。

<a id="ZZ-001-010"></a>[\[ZZ-001-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-010) 三月，公及邾仪父盟于蔑，邾子克也。未王命，故不书爵。曰「仪父」，贵之也。公摄位而欲求好于邾，故为蔑之盟。

<sub>被引：[Q136](../../qa/Q136.md)</sub>

<a id="ZZ-001-011"></a>[\[ZZ-001-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-011) 夏四月，费伯帅师城郎。不书，非公命也。

<a id="ZZ-001-012"></a>[\[ZZ-001-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-012) 初，郑武公娶于申，曰武姜，生庄公及共叔段。庄公寤生，惊姜氏，故名曰「寤生」，遂恶之。爱共叔段，欲立之。亟请于武公，公弗许。及庄公即位，为之请制。公曰：「制，岩邑也，虢叔死焉，佗邑唯命。」请京，使居之，谓之京城大叔。祭仲曰：「都城过百雉，国之害也。先王之制：大都不过参国之一，中五之一，小九之一。今京不度，非制也，君将不堪。」公曰：「姜氏欲之，焉辟害？」对曰：「姜氏何厌之有？！不如早为之所，无使滋蔓！蔓，难图也。蔓草犹不可除，况君之宠弟乎？！」公曰：「多行不义，必自毙，子姑待之。」

<sub>被引：[Q62](../../qa/Q62.md)、[Q152](../../qa/Q152.md)、[Q153](../../qa/Q153.md)</sub>

<a id="ZZ-001-013"></a>[\[ZZ-001-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-013) 既而大叔命西鄙、北鄙贰于己。公子吕曰：「国不堪贰，君将若之何？欲与大叔，臣请事之；若弗与，则请除之。无生民心。」公曰：「无庸，将自及。」大叔又收贰以为己邑，至于廪延。子封曰：「可矣，厚将得众。」公曰：「不义，不暱，厚将崩。」大叔完聚，缮甲兵，具卒乘，将袭郑。夫人将启之。公闻其期，曰：「可矣！」命子封帅车二百乘以伐京。京叛大叔段，段入于鄢，公伐诸鄢。五月辛丑，大叔出奔共。

<sub>被引：[Q153](../../qa/Q153.md)</sub>

<a id="ZZ-001-014"></a>[\[ZZ-001-014\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-014) 书曰：「郑伯克段于鄢。」段不弟，故不言弟；如二君，故曰克；称郑伯，讥失教也：谓之郑志。不言出奔，难之也。

<sub>被引：[Q152](../../qa/Q152.md)、[Q153](../../qa/Q153.md)</sub>

<a id="ZZ-001-015"></a>[\[ZZ-001-015\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-015) 遂寘姜氏于城颍，而誓之曰：「不及黄泉，无相见也。」既而悔之。

<sub>被引：[Q152](../../qa/Q152.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-001-016"></a>[\[ZZ-001-016\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-016) 颍考叔为颍谷封人，闻之，有献于公，公赐之食，食舍肉。公问之，对曰：「小人有母，皆尝小人之食矣，未尝君之羹，请以遗之。」公曰：「尔有母遗，繄我独无！」颍考叔曰：「敢问何谓也？」公语之故，且告之悔。对曰：「君何患焉？若阙地及泉，隧而相见，其谁曰不然？」公从之。公入而赋：「大隧之中，其乐也融融！」姜出而赋：「大隧之外，其乐也泄泄！」遂为母子如初。

<sub>被引：[Q152](../../qa/Q152.md)</sub>

<a id="ZZ-001-017"></a>[\[ZZ-001-017\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-017) 君子曰：「颍考叔，纯孝也，爱其母，施及庄公。《诗》曰：『孝子不匮，永锡尔类。』其是之谓乎！」

<sub>被引：[Q152](../../qa/Q152.md)</sub>

<a id="ZZ-001-018"></a>[\[ZZ-001-018\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-018) 秋，七月，天王使宰咺来归惠公、仲子之赗。缓，且子氏未薨，故名。天子七月而葬，同轨毕至；诸侯五月，同盟至；大夫三月，同位至；士逾月，外姻至。赠死不及尸，吊生不及哀，豫凶事，非礼也。

<a id="ZZ-001-019"></a>[\[ZZ-001-019\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-019) 八月，纪人伐夷。夷不告，故不书。有蜚。不为灾，亦不书。

<sub>被引：[Q120](../../qa/Q120.md)</sub>

<a id="ZZ-001-020"></a>[\[ZZ-001-020\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-020) 惠公之季年，败宋师于黄。公立，而求成焉。九月，及宋人盟于宿，始通也。

<a id="ZZ-001-021"></a>[\[ZZ-001-021\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-021) 冬，十月，庚申，改葬惠公。公弗临，故不书。惠公之薨也，有宋师，太子少，葬故有阙，是以改葬。卫侯来会葬，不见公，亦不书。

<a id="ZZ-001-022"></a>[\[ZZ-001-022\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-022) 郑共叔之乱，公孙滑出奔卫。卫人为之伐郑，取廪延。郑人以王师、虢师伐卫南鄙。请师于邾，邾子使私于公子豫。豫请往，公弗许，遂行。及邾人、郑人盟于翼。不书，非公命也。

<a id="ZZ-001-023"></a>[\[ZZ-001-023\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-023) 新作南门。不书，亦非公命也。

<a id="ZZ-001-024"></a>[\[ZZ-001-024\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-024) 十二月，祭伯来，非王命也。

<a id="ZZ-001-025"></a>[\[ZZ-001-025\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E9%9A%90%E5%85%AC%E5%85%83%E5%B9%B4?pn=ZZ-001-025) 众父卒。公不与小敛，故不书日。
