### 经

<a id="ZZ-123-001"></a>[\[ZZ-123-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-001) 九年春王正月，公如齐，公至自齐。

<a id="ZZ-123-002"></a>[\[ZZ-123-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-002) 夏，仲孙蔑如京师。齐侯伐莱。

<a id="ZZ-123-003"></a>[\[ZZ-123-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-003) 秋，取根牟。

<a id="ZZ-123-004"></a>[\[ZZ-123-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-004) 八月，滕子卒。

<a id="ZZ-123-005"></a>[\[ZZ-123-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-005) 九月，晋侯、宋公、卫侯、郑伯、曹伯，会于扈。晋荀林父帅师伐陈。辛酉，晋侯黑臀卒于扈。

<a id="ZZ-123-006"></a>[\[ZZ-123-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-006) 冬，十月，癸酉，卫侯郑卒。宋人围滕。楚子伐郑。晋郤缺帅师救郑。陈杀其大夫泄冶。

### 传

<a id="ZZ-123-007"></a>[\[ZZ-123-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-007) 春，王使来征聘。

<a id="ZZ-123-008"></a>[\[ZZ-123-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-008) 夏，孟献子聘于周，王以为有礼，厚贿之。

<a id="ZZ-123-009"></a>[\[ZZ-123-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-009) 秋，取根牟，言易也。滕昭公卒。会于扈，讨不睦也。陈侯不会，晋荀林父以诸侯之师伐陈。晋侯卒于扈，乃还。

<a id="ZZ-123-010"></a>[\[ZZ-123-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E4%B9%9D%E5%B9%B4?pn=ZZ-123-010) 冬，宋人围滕，因其丧也。陈灵公与孔宁、仪行父，通于夏姬，皆衷其衵服以戏于朝。泄冶谏曰：「公卿宣淫，民无效焉，且闻不令，君其纳之。」公曰：「吾能改矣。」公告二子，二子请杀之，公弗禁，遂杀泄冶。孔子曰：「诗云：『民之多辟，无自立辟。』其泄冶之谓乎！」楚子为厉之役故，伐郑。晋郤缺救郑，郑伯败楚师于柳棼，国人皆喜，唯子良忧，曰：「是国之灾也，吾死无日矣。」
