### 经

<a id="ZZ-027-001"></a>[\[ZZ-027-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-001) 十有六年，春，正月，公会宋公、蔡侯、卫侯于曹。

<a id="ZZ-027-002"></a>[\[ZZ-027-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-002) 夏，四月，公会宋公、卫侯、陈侯、蔡侯伐郑。

<a id="ZZ-027-003"></a>[\[ZZ-027-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-003) 秋，七月，公至自伐郑。

<a id="ZZ-027-004"></a>[\[ZZ-027-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-004) 冬，城向。十有一月，卫侯朔出奔齐。

### 传

<a id="ZZ-027-005"></a>[\[ZZ-027-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-005) 十六年春正月，会于曹，谋伐郑也。

<a id="ZZ-027-006"></a>[\[ZZ-027-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-006) 夏，伐郑。

<a id="ZZ-027-007"></a>[\[ZZ-027-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-007) 秋七月，公至自伐郑，以饮至之礼也。

<a id="ZZ-027-008"></a>[\[ZZ-027-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-008) 冬，城向，书，时也。

<a id="ZZ-027-009"></a>[\[ZZ-027-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E5%85%AD%E5%B9%B4?pn=ZZ-027-009) 初，卫宣公烝于夷姜，生急子，属诸右公子。为之娶于齐，而美，公取之，生寿及朔，属寿于左公子。夷姜缢。宣姜与公子朔构急子。公使诸齐，使盗待诸莘，将杀之。寿子告之，使行。不可，曰：「弃父之命，恶用子矣！有无父之国则可也。」及行，饮以酒，寿子载其旌以先，盗杀之。急子至，曰：「我之求也。此何罪？请杀我乎！」又杀之。二公子故怨惠公。
