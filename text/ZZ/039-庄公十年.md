### 经

<a id="ZZ-039-001"></a>[\[ZZ-039-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-001) 十年春王正月，公败齐师于长勺。二月，公侵宋。三月，宋人迁宿。

<sub>被引：[Q159](../../qa/Q159.md)</sub>

<a id="ZZ-039-002"></a>[\[ZZ-039-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-002) 夏六月，齐师、宋师次于郎。公败宋师于乘丘。

<a id="ZZ-039-003"></a>[\[ZZ-039-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-003) 秋九月，荆败蔡师于莘，以蔡侯献舞归。

<a id="ZZ-039-004"></a>[\[ZZ-039-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-004) 冬十月，齐师灭谭，谭子奔莒。

### 传

<a id="ZZ-039-005"></a>[\[ZZ-039-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-005) 十年春，齐师伐我。公将战，曹刿请见。其乡人曰：『肉食者谋之，又何间焉。』刿曰：『肉食者鄙，未能远谋。』乃入见。问何以战。公曰：『衣食所安，弗敢专也，必以分人。』对曰：『小惠未遍，民弗从也。』公曰：『牺牲玉帛，弗敢加也，必以信。』对曰：『小信未孚，神弗福也。』公曰：『小大之狱，虽不能察，必以情。』对曰：『忠之属也，可以一战，战则请从。』

<sub>被引：[Q159](../../qa/Q159.md)</sub>

<a id="ZZ-039-006"></a>[\[ZZ-039-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-006) 公与之乘。战于长勺。公将鼓之。刿曰：『未可。』齐人三鼓，刿曰：『可矣。』齐师败绩。公将驰之。刿曰：『未可。』下，视其辙，登，轼而望之，曰：『可矣。』遂逐齐师。

<sub>被引：[Q159](../../qa/Q159.md)</sub>

<a id="ZZ-039-007"></a>[\[ZZ-039-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-007) 既克，公问其故。对曰：『夫战，勇气也，一鼓作气，再而衰，三而竭。彼竭我盈，故克之。夫大国难测也，惧有伏焉。吾视其辙乱，望其旗靡，故逐之。』

<sub>被引：[Q159](../../qa/Q159.md)</sub>

<a id="ZZ-039-008"></a>[\[ZZ-039-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-008) 夏六月，齐师、宋师次于郎。公子偃曰：『宋师不整，可败也。宋败，齐必还，请击之。』公弗许。自雩门窃出，蒙皋比而先犯之。公从之。大败宋师于乘丘。齐师乃还。

<a id="ZZ-039-009"></a>[\[ZZ-039-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-009) 蔡哀侯娶于陈，息侯亦娶焉。息妫将归，过蔡。蔡侯曰：『吾姨也。』止而见之，弗宾。息侯闻之，怒，使谓楚文王曰：『伐我，吾求救于蔡而伐之。』楚子从之。秋九月，楚败蔡师于莘，以蔡侯献舞归。

<a id="ZZ-039-010"></a>[\[ZZ-039-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%BA%84%E5%85%AC%E5%8D%81%E5%B9%B4?pn=ZZ-039-010) 齐侯之出也，过谭，谭不礼焉。及其入也，诸侯皆贺，谭又不至。冬，齐师灭谭，谭无礼也。谭子奔莒，同盟故也。
