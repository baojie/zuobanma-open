### 经

<a id="ZZ-101-001"></a>[\[ZZ-101-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-001) 春，王正月，王使荣叔归含，且赗。

<a id="ZZ-101-002"></a>[\[ZZ-101-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-002) 三月，辛亥，葬我小君成风。王使召伯来会葬。

<a id="ZZ-101-003"></a>[\[ZZ-101-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-003) 夏，公孙敖如晋。秦人入鄀。

<a id="ZZ-101-004"></a>[\[ZZ-101-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-004) 秋，楚人灭六。

<a id="ZZ-101-005"></a>[\[ZZ-101-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-005) 冬十月，甲申，许男业卒。

### 传

<a id="ZZ-101-006"></a>[\[ZZ-101-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-006) 春，王使荣叔来含，且赗。召昭公来会葬，礼也。初，鄀叛楚即秦，又贰于楚。

<a id="ZZ-101-007"></a>[\[ZZ-101-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-007) 夏，秦人入鄀。六人叛楚，即东夷。

<a id="ZZ-101-008"></a>[\[ZZ-101-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-008) 秋，楚成大心、仲归帅师灭六。冬，楚公子燮灭蓼。臧文仲闻六与蓼灭，曰：「皋陶、庭坚不祀忽诸？德之不建，民之无援，哀哉！」

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-101-009"></a>[\[ZZ-101-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%96%87%E5%85%AC%E4%BA%94%E5%B9%B4?pn=ZZ-101-009) 晋阳处父聘于卫，反过宁，宁嬴从之，及温而还。其妻问之，嬴曰：「以刚。《商书》曰：『沈渐刚克，高明柔克。』夫子壹之，其不没乎！？天为刚德，犹不干时，况在人乎！且华而不实，怨之所聚也。犯而聚怨，不可以定身。余惧不获其利，而离其难，是以去之。」晋赵成子、栾贞子、霍伯、臼季，皆卒。
