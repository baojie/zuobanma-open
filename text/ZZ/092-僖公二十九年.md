### 经

<a id="ZZ-092-001"></a>[\[ZZ-092-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-001) 二十有九年春，介葛卢来。公至自围许。

<a id="ZZ-092-002"></a>[\[ZZ-092-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-002) 夏，六月，会王人、晋人、宋人、齐人、陈人、蔡人、秦人，盟于翟泉。

<a id="ZZ-092-003"></a>[\[ZZ-092-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-003) 秋，大雨雹。

<a id="ZZ-092-004"></a>[\[ZZ-092-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-004) 冬，介葛卢来。

### 传

<a id="ZZ-092-005"></a>[\[ZZ-092-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-005) 二十九年春，介葛卢来朝，舍于昌衍之上。公在会，馈之刍米，礼也。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-092-006"></a>[\[ZZ-092-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-006) 夏，公会王子虎、晋狐偃、宋公孙固、齐国归父、陈辕涛涂、秦小子慭，盟于翟泉，寻践土之盟，且谋伐郑也。卿不书，罪之也。在礼，卿不会公、侯，会伯、子、男可也。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-092-007"></a>[\[ZZ-092-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-007) 秋，大雨雹，为灾也。

<a id="ZZ-092-008"></a>[\[ZZ-092-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E4%B9%9D%E5%B9%B4?pn=ZZ-092-008) 冬，介葛卢来，以未见公，故复来朝，礼之。加燕好，介葛卢闻牛鸣，曰：「是生三牺，皆用之矣，其音云。」问之而信。
