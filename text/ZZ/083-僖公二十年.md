### 经

<a id="ZZ-083-001"></a>[\[ZZ-083-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-001) 二十年春，新作南门。

<a id="ZZ-083-002"></a>[\[ZZ-083-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-002) 夏，郜子来朝。

<a id="ZZ-083-003"></a>[\[ZZ-083-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-003) 五月，乙巳，西宫灾。郑人入滑。

<a id="ZZ-083-004"></a>[\[ZZ-083-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-004) 秋，齐人、狄人盟于邢。

<a id="ZZ-083-005"></a>[\[ZZ-083-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-005) 冬，楚人伐随。

### 传

<a id="ZZ-083-006"></a>[\[ZZ-083-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-006) 二十年春，新作南门。书，不时也。凡启塞从时。

<a id="ZZ-083-007"></a>[\[ZZ-083-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-007) 滑人叛郑，而服于卫。

<a id="ZZ-083-008"></a>[\[ZZ-083-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-008) 夏，郑公子士、泄堵寇，帅师入滑。

<a id="ZZ-083-009"></a>[\[ZZ-083-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-009) 秋，齐狄盟于邢，为邢谋卫难也。于是卫方病邢。

<a id="ZZ-083-010"></a>[\[ZZ-083-010\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-010) 随以汉东诸侯叛楚。

<a id="ZZ-083-011"></a>[\[ZZ-083-011\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-011) 冬，楚鬭谷於菟帅师伐随，取成而还。

<a id="ZZ-083-012"></a>[\[ZZ-083-012\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-012) 君子曰：「随之见伐，不量力也。量力而动，其过鲜矣。善败由己，而由人乎哉？《诗》曰：『岂不夙夜，谓行多露。』」

<a id="ZZ-083-013"></a>[\[ZZ-083-013\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%83%96%E5%85%AC%E4%BA%8C%E5%8D%81%E5%B9%B4?pn=ZZ-083-013) 宋襄公欲合诸侯。臧文仲闻之曰：「以欲从人则可，以人从欲鲜济。」
