### 经

<a id="ZZ-023-001"></a>[\[ZZ-023-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-001) 十有二年，春，正月。

<a id="ZZ-023-002"></a>[\[ZZ-023-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-002) 夏，六月壬寅，公会杞侯、莒子盟于曲池。

<a id="ZZ-023-003"></a>[\[ZZ-023-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-003) 秋，七月丁亥，公会宋公、燕人盟于谷丘。八月壬辰，陈侯跃卒。公会宋公于虚。

<a id="ZZ-023-004"></a>[\[ZZ-023-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-004) 冬，十有一月，公会宋公于龟。丙戌，公会郑伯，盟于武父。丙戌，卫侯晋卒。十有二月，及郑师伐宋。丁未，战于宋。

### 传

<a id="ZZ-023-005"></a>[\[ZZ-023-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-005) 十二年夏，盟于曲池，平杞、莒也。

<a id="ZZ-023-006"></a>[\[ZZ-023-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-006) 公欲平宋、郑。秋，公及宋公盟于句渎之丘。宋成未可知也，故又会于虚。冬，又会于龟。宋公辞平，故与郑伯盟于武父。遂帅师而伐宋，战焉，宋无信也。

<a id="ZZ-023-007"></a>[\[ZZ-023-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-007) 君子曰：「苟信不继，盟无益也。《诗》云：『君子屡盟，乱是用长。』无信也。」

<a id="ZZ-023-008"></a>[\[ZZ-023-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-008) 楚伐绞，军其南门。莫敖屈瑕曰：「绞小而轻，轻则寡谋，请无扞采樵者以诱之。」从之。绞人获三十人。明日，绞人争出，驱楚役徒于山中。楚人坐其北门，而覆诸山下，大败之，为城下之盟而还。

<a id="ZZ-023-009"></a>[\[ZZ-023-009\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E6%A1%93%E5%85%AC%E5%8D%81%E4%BA%8C%E5%B9%B4?pn=ZZ-023-009) 伐绞之役，楚师分涉于彭。罗人欲伐之，使伯嘉谍之，三巡数之。
