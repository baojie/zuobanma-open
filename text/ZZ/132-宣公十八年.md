### 经

<a id="ZZ-132-001"></a>[\[ZZ-132-001\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-001) 十有八年春，晋侯、卫世子臧，伐齐。公伐杞。

<a id="ZZ-132-002"></a>[\[ZZ-132-002\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-002) 夏，四月。

<a id="ZZ-132-003"></a>[\[ZZ-132-003\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-003) 秋，七月，邾人戕鄫子于鄫。甲戌，楚子旅卒。公孙归父如晋。

<a id="ZZ-132-004"></a>[\[ZZ-132-004\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-004) 冬，十月，壬戌，公薨于路寝，归父还自晋，至笙，遂奔齐。

### 传

<a id="ZZ-132-005"></a>[\[ZZ-132-005\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-005) 十八年春，晋侯、卫大子臧，伐齐，至于阳谷。齐侯会晋侯盟于缯，以公子彊为质于晋。晋师还，蔡朝、南郭偃，逃归。

<a id="ZZ-132-006"></a>[\[ZZ-132-006\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-006) 夏，公使如楚乞师，欲以伐齐。

<a id="ZZ-132-007"></a>[\[ZZ-132-007\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-007) 秋，邾人戕鄫子于鄫。凡自内虐其君曰弑，自外曰戕。楚庄王卒，楚师不出。既而用晋师，楚于是乎有蜀之役。公孙归父以襄仲之立公也，有宠，欲去三桓，以张公室，与公谋而聘于晋，欲以晋人去之。

<sub>被引：[Q118](../../qa/Q118.md)、[Q136](../../qa/Q136.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="ZZ-132-008"></a>[\[ZZ-132-008\]](https://zuobanma.memify.wiki/#%E5%B7%A6%E4%BC%A0%C2%B7%E5%AE%A3%E5%85%AC%E5%8D%81%E5%85%AB%E5%B9%B4?pn=ZZ-132-008) 冬，公薨。季文子言于朝曰：「使我杀适立庶，以失大援者，仲也夫。」臧宣叔怒曰：「当其时，不能治也，后之人何罪？子欲去之，许请去之。」遂逐东门氏。子家还及笙，坛帷，复命于介。既复命，袒括发，即位哭，三踊而出，遂奔齐。书曰：「归父还自晋。」善之也。
