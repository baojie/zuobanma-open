### 韩原武子

<a id="SJ-045-001"></a>[\[SJ-045-001\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-001) 韩之先与周同姓，姓姬氏。其后苗裔事晋，得封于韩原，曰韩武子。武子后三世有韩厥，从封姓为韩氏。

### 韩献子

<a id="SJ-045-002"></a>[\[SJ-045-002\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-002) 韩厥，晋景公之三年，晋司寇屠岸贾将作乱，诛灵公之贼赵盾。赵盾已死矣，欲诛其子赵朔。韩厥止贾，贾不听。厥告赵朔令亡。朔曰：「子必能不绝赵祀，死不恨矣。」韩厥许之。及贾诛赵氏，厥称疾不出。程婴、公孙杵臼之藏赵孤赵武也，厥知之。

<sub>被引：[韩厥](../../entries/person/%E9%9F%A9%E5%8E%A5.md)、[赵氏](../../entries/concept/%E8%B5%B5%E6%B0%8F.md)、[Q8](../../qa/Q8.md)</sub>

<a id="SJ-045-003"></a>[\[SJ-045-003\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-003) 景公十一年，厥与郤克将兵八百乘伐齐，败齐顷公于鞍，获逢丑父。于是晋作六卿，而韩厥在一卿之位，号为献子。

<sub>被引：[韩厥](../../entries/person/%E9%9F%A9%E5%8E%A5.md)</sub>

<a id="SJ-045-004"></a>[\[SJ-045-004\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-004) 晋景公十七年，病，卜大业之不遂者为祟。韩厥称赵成季之功，今后无祀，以感景公。景公问曰：「尚有世乎？」厥于是言赵武，而复与故赵氏田邑，续赵氏祀。

<sub>被引：[Q8](../../qa/Q8.md)</sub>

<a id="SJ-045-005"></a>[\[SJ-045-005\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-005) 晋悼公之（十）［七］年，韩献子老。献子卒，子宣子代。宣子徙居州。

<sub>被引：[晋悼公](../../entries/person/%E6%99%8B%E6%82%BC%E5%85%AC.md)</sub>

### 韩宣子

<a id="SJ-045-006"></a>[\[SJ-045-006\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-006) 晋平公十四年，吴季札使晋，曰：「晋国之政卒归于韩、魏、赵矣。」晋顷公十二年，韩宣子与赵、魏共分祁氏、羊舌氏十县。晋定公十五年，宣子与赵简子侵伐范、中行氏。宣子卒，子贞子代立。贞子徙居平阳。

<sub>被引：[季札](../../entries/person/%E5%AD%A3%E6%9C%AD.md)</sub>

<a id="SJ-045-008"></a>[\[SJ-045-008\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-008) 康子与赵襄子、魏桓子共败知伯，分其地，地益大，大于诸侯。康子卒，子武子代。

### 韩景侯

<a id="SJ-045-010"></a>[\[SJ-045-010\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-010) 景侯虔元年，伐郑，取雍丘。二年，郑败我负黍。

<a id="SJ-045-011"></a>[\[SJ-045-011\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-011) 六年，与赵、魏俱得列为诸侯。

<a id="SJ-045-012"></a>[\[SJ-045-012\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-012) 九年，郑围我阳翟。景侯卒，子列侯取立。

### 韩昭侯

<a id="SJ-045-018"></a>[\[SJ-045-018\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-018) 昭侯元年，秦败我西山。二年，宋取我黄池。魏取朱。六年，伐东周，取陵观、邢丘。

<sub>被引：[Q167](../../qa/Q167.md)</sub>

<a id="SJ-045-019"></a>[\[SJ-045-019\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-019) 八年，申不害相韩，修术行道，国内以治，诸侯不来侵伐。

<a id="SJ-045-020"></a>[\[SJ-045-020\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-020) 十年，韩姬弑其君悼公。十一年，昭侯如秦。二十二年，申不害死。二十四年，秦来拔我宜阳。

<sub>被引：[宜阳](../../entries/place/%E5%AE%9C%E9%98%B3.md)</sub>

<a id="SJ-045-021"></a>[\[SJ-045-021\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-021) 二十五年，旱，作高门。屈宜臼曰：「昭侯不出此门。何也？不时。吾所谓时者，非时日也，人固有利不利时。昭侯尝利矣，不作高门。往年秦拔宜阳，今年旱，昭侯不以此时恤民之急，而顾益奢，此谓『时绌举赢』。」二十六年，高门成，昭侯卒，果不出此门。子宣惠王立。

<sub>被引：[宜阳](../../entries/place/%E5%AE%9C%E9%98%B3.md)</sub>

### 韩宣惠王

<a id="SJ-045-022"></a>[\[SJ-045-022\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-022) 宣惠王五年，张仪相秦。八年，魏败我将韩举。十一年，君号为王。与赵会区鼠。十四年，秦伐败我鄢。

<sub>被引：[Q5](../../qa/Q5.md) · [二校](../../collation/review.md)：改字 1 处</sub>

<a id="SJ-045-023"></a>[\[SJ-045-023\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-023) 十六年，秦败我修鱼，虏得韩将鲠、申差于浊泽。韩氏急，公仲谓韩王曰：「与国非可恃也。今秦之欲伐楚久矣，王不如因张仪为和于秦，赂以一名都，具甲，与之南伐楚，此以一易二之计也。」韩王曰：「善。」乃警公仲之行，将西购于秦。楚王闻之大恐，召陈轸告之。陈轸曰：「秦之欲伐楚久矣，今又得韩之名都一而具甲，秦韩并兵而伐楚，此秦所祷祀而求也。今已得之矣，楚国必伐矣。王听臣为之警四境之内，起师言救韩，命战车满道路，发信臣，多其车，重其币，使信王之救己也。纵韩不能听我，韩必德王也，必不为鴈行以来，是秦韩不和也，兵虽至，楚不大病也。为能听我绝和于秦，秦必大怒，以厚怨韩。韩之南交楚，必轻秦；轻秦，其应秦必不敬：是因秦、韩之兵而免楚国之患也。」楚王曰：「善。」乃警四境之内，兴师言救韩。命战车满道路，发信臣，多其车，重其币。谓韩王曰：「不谷国虽小，已悉发之矣。愿大国遂肆志于秦，不谷将以楚殉韩。」韩王闻之大说，乃止公仲之行。公仲曰：「不可。夫以实伐我者秦也，以虚名救我者楚也。王恃楚之虚名，而轻绝彊秦之敌，王必为天下大笑。且楚韩非兄弟之国也，又非素约而谋伐秦也。已有伐形，因发兵言救韩，此必陈轸之谋也。且王已使人报于秦矣，今不行，是欺秦也。夫轻欺彊秦而信楚之谋臣，恐王必悔之。」韩王不听，遂绝于秦。秦因大怒，益甲伐韩，大战，楚救不至韩。十九年，大破我岸门。太子仓质于秦以和。

<sub>被引：[陈轸](../../entries/person/%E9%99%88%E8%BD%B8.md)</sub>

<a id="SJ-045-024"></a>[\[SJ-045-024\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-024) 二十一年，与秦共攻楚，败楚将屈丐，斩首八万于丹阳。是岁，宣惠王卒，太子仓立，是为襄王。

### 韩襄王

<a id="SJ-045-025"></a>[\[SJ-045-025\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-025) 襄王四年，与秦武王会临晋。其秋，秦使甘茂攻我宜阳。五年，秦拔我宜阳，斩首六万。秦武王卒。六年，秦复与我武遂。九年，秦复取我武遂。十年，太子婴朝秦而归。十一年，秦伐我，取穰。与秦伐楚，败楚将唐眛。

<sub>被引：[临晋](../../entries/place/%E4%B8%B4%E6%99%8B.md)、[秦武王](../../entries/person/%E7%A7%A6%E6%AD%A6%E7%8E%8B.md)、[宜阳](../../entries/place/%E5%AE%9C%E9%98%B3.md)、[Q98](../../qa/Q98.md)</sub>

<a id="SJ-045-026"></a>[\[SJ-045-026\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-026) 十二年，太子婴死。公子咎、公子虮虱争为太子。时虮虱质于楚。苏代谓韩咎曰：「虮虱亡在楚，楚王欲内之甚。今楚兵十余万在方城之外，公何不令楚王筑万室之都雍氏之旁，韩必起兵以救之，公必将矣。公因以韩楚之兵奉虮虱而内之，其听公必矣，必以楚韩封公也。」韩咎从其计。

<sub>被引：[苏代](../../entries/person/%E8%8B%8F%E4%BB%A3.md)、[Q98](../../qa/Q98.md)</sub>

<a id="SJ-045-027"></a>[\[SJ-045-027\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-027) 楚围雍氏，韩求救于秦。秦未为发，使公孙昧入韩。公仲曰：「子以秦为且救韩乎？」对曰：「秦王之言曰『请道南郑、蓝田，出兵于楚以待公』，殆不合矣。」公仲曰：「子以为果乎？」对曰：「秦王必祖张仪之故智。楚威王攻梁也，张仪谓秦王曰：『与楚攻魏，魏折而入于楚，韩固其与国也，是秦孤也。不如出兵以到之，魏楚大战，秦取西河之外以归。』今其状阳言与韩，其实阴善楚。公待秦而到，必轻与楚战。楚阴得秦之不用也，必易与公相支也。公战而胜楚，遂与公乘楚，施三川而归。公战不胜楚，楚塞三川守之，公不能救也。窃为公患之。司马庚三反于郢，甘茂与昭鱼遇于商于，其言收玺，实类有约也。」公仲恐，曰：「然则柰何？」曰：「公必先韩而后秦，先身而后张仪。公不如亟以国合于齐楚，齐楚必委国于公。公之所恶者张仪也，其实犹不无秦也。」于是楚解雍氏围。

<sub>被引：[蓝田](../../entries/place/%E8%93%9D%E7%94%B0.md)、[Q102](../../qa/Q102.md)</sub>

<a id="SJ-045-028"></a>[\[SJ-045-028\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-028) 苏代又谓秦太后弟芈戎曰：「公叔伯婴恐秦楚之内虮虱也，公何不为韩求质子于楚？楚王听入质子于韩，则公叔伯婴知秦楚之不以虮虱为事，必以韩合于秦楚。秦楚挟韩以窘魏，魏氏不敢合于齐，是齐孤也。公又为秦求质子于楚，楚不听，怨结于韩。韩挟齐魏以围楚，楚必重公。公挟秦楚之重以积德于韩，公叔伯婴必以国待公。」于是虮虱竟不得归韩。韩立咎为太子。齐、魏王来。

<sub>被引：[苏代](../../entries/person/%E8%8B%8F%E4%BB%A3.md)</sub>

<a id="SJ-045-029"></a>[\[SJ-045-029\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-029) 十四年，与齐、魏王共击秦，至函谷而军焉。十六年，秦与我河外及武遂。襄王卒，太子咎立，是为厘王。

### 韩厘王

<a id="SJ-045-030"></a>[\[SJ-045-030\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-030) 厘王三年，使公孙喜率周、魏攻秦。秦败我二十四万，虏喜伊阙。五年，秦拔我宛。六年，与秦武遂地二百里。十年，秦败我师于夏山。十二年，与秦昭王会西周而佐秦攻齐。齐败，湣王出亡。十四年，与秦会两周闲。二十一年，使暴䳒救魏，为秦所败，䳒走开封。

<sub>被引：[Q57](../../qa/Q57.md) · [二校](../../collation/review.md)：改字 2 处</sub>

<a id="SJ-045-031"></a>[\[SJ-045-031\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-031) 二十三年，赵、魏攻我华阳。韩告急于秦，秦不救。韩相国谓陈筮曰：「事急，愿公虽病，为一宿之行。」陈筮见穰侯。穰侯曰：「事急乎？故使公来。」陈筮曰：「未急也。」穰侯怒曰：「是可以为公之主使乎？夫冠盖相望，告敝邑甚急，公来言未急，何也？」陈筮曰：「彼韩急则将变而佗从，以未急，故复来耳。」穰侯曰：「公无见王，请今发兵救韩。」八日而至，败赵、魏于华阳之下。是岁，厘王卒，子桓惠王立。

### 韩桓惠王

<a id="SJ-045-032"></a>[\[SJ-045-032\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-032) 桓惠王元年，伐燕。九年，秦拔我陉，城汾旁。十年，秦击我于太行，我上党郡守以上党郡降赵。十四年，秦拔赵上党，杀马服子卒四十余万于长平。十七年，秦拔我阳城、负黍。二十二年，秦昭王卒。二十四年，秦拔我城皋、荥阳。二十六年，秦悉拔我上党。二十九年，秦拔我十三城。

### 韩王安

<a id="SJ-045-034"></a>[\[SJ-045-034\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-034) 王安五年，秦攻韩，韩急，使韩非使秦，秦留非，因杀之。

### 太史公曰

<a id="SJ-045-036"></a>[\[SJ-045-036\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%9F%A9%E4%B8%96%E5%AE%B6?pn=SJ-045-036) 太史公曰：韩厥之感晋景公，绍赵孤之子武，以成程婴、公孙杵臼之义，此天下之阴德也。韩氏之功，于晋未睹其大者也。然与赵、魏终为诸侯十余世，宜乎哉！
