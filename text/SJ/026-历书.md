<a id="SJ-026-001"></a>[\[SJ-026-001\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-001) 昔自在古，历建正作于孟春。于时冰泮发蛰，百草奋兴，秭鳺先滜。物廼岁具，生于东，次顺四时，卒于冬分，时鸡三号，卒明。抚十二节，卒于丑。日月成，故明也。明者孟也，幽者幼也，幽明者雌雄也。雌雄代兴，而顺至正之统也。日归于西，起明于东；月归于东，起明于西。正不率天，又不由人，则凡事易坏而难成矣。

<a id="SJ-026-002"></a>[\[SJ-026-002\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-002) 王者易姓受命，必慎始初，改正朔，易服色，推本天元，顺承厥意。

<a id="SJ-026-003"></a>[\[SJ-026-003\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-003) 太史公曰：神农以前尚矣。盖黄帝考定星历，建立五行，起消息，正闰余，于是有天地神祇物类之官，是谓五官。各司其序，不相乱也。民是以能有信，神是以能有明德。民神异业，敬而不渎，故神降之嘉生，民以物享，灾祸不生，所求不匮。

<sub>被引：[黄帝](../../entries/person/%E9%BB%84%E5%B8%9D.md)、[Q59](../../qa/Q59.md)、[Q123](../../qa/Q123.md)</sub>

<a id="SJ-026-004"></a>[\[SJ-026-004\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-004) 少暤氏之衰也，九黎乱德，民神杂扰，不可放物，祸菑荐至，莫尽其气。颛顼受之，乃命南正重司天以属神，命火正黎司地以属民，使复旧常，无相侵渎。

<sub>对读：[HS-025-002](../HS/025-%E9%83%8A%E7%A5%80%E5%BF%97.md#HS-025-002)</sub>

<a id="SJ-026-005"></a>[\[SJ-026-005\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-005) 其后三苗服九黎之德，故二官咸废所职，而闰余乖次，孟陬殄灭，摄提无纪，历数失序。尧复遂重、黎之后，不忘旧者，使复典之，而立羲和之官。明时正度，则阴阳调，风雨节，茂气至，民无夭疫。年耆禅舜，申戒文祖，云「天之历数在尔躬」。舜亦以命禹。由是观之，王者所重也。

<a id="SJ-026-006"></a>[\[SJ-026-006\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-006) 夏正以正月，殷正以十二月，周正以十一月。盖三王之正若循环，穷则反本。天下有道，则不失纪序；无道，则正朔不行于诸侯。

<a id="SJ-026-007"></a>[\[SJ-026-007\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-007) 幽、厉之后，周室微，陪臣执政，史不记时，君不告朔，故畴人子弟分散，或在诸夏，或在夷狄，是以其禨祥废而不统。周襄王二十六年闰三月，而春秋非之。先王之正时也，履端于始，举正于中，归邪于终。履端于始，序则不愆；举正于中，民则不惑；归邪于终，事则不悖。

<sub>对读：[ZZ-097-007](../ZZ/097-%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4.md#ZZ-097-007)</sub>

<a id="SJ-026-008"></a>[\[SJ-026-008\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-008) 其后战国并争，在于彊国禽敌，救急解纷而已，岂遑念斯哉！是时独有邹衍，明于五德之传，而散消息之分，以显诸侯。而亦因秦灭六国，兵戎极烦，又升至尊之日浅，未暇遑也。而亦颇推五胜，而自以为获水德之瑞，更名河曰「德水」，而正以十月，色上黑。然历度闰余，未能睹其真也。

<a id="SJ-026-009"></a>[\[SJ-026-009\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-009) 汉兴，高祖曰「北畤待我而起」，亦自以为获水德之瑞。虽明习历及张苍等，咸以为然。是时天下初定，方纲纪大基，高后女主，皆未遑，故袭秦正朔服色。

<sub>被引：[Q13](../../qa/Q13.md)</sub>

<a id="SJ-026-010"></a>[\[SJ-026-010\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-010) 至孝文时，鲁人公孙臣以终始五德上书，言「汉得土德，宜更元，改正朔，易服色。当有瑞，瑞黄龙见」。事下丞相张苍，张苍亦学律历，以为非是，罢之。其后黄龙见成纪，张苍自黜，所欲论著不成。而新垣平以望气见，颇言正历服色事，贵幸，后作乱，故孝文帝废不复问。

<sub>对读：[HS-042-004](../HS/042-%E5%BC%A0%E5%91%A8%E8%B5%B5%E4%BB%BB%E7%94%B3%E5%B1%A0%E4%BC%A0.md#HS-042-004)</sub>

<a id="SJ-026-011"></a>[\[SJ-026-011\]](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E5%8E%86%E4%B9%A6?pn=SJ-026-011) 至今上即位，招致方士，唐都分其天部，而巴落下闳运算转历，然后日辰之度与夏正同。乃改元，更官号，封泰山。因诏御史曰：「乃者，有司言星度之未定也，广延宣问，以理星度，未能詹也。盖闻昔者黄帝合而不死，名察度验，定清浊，起五部，建气物分数。然盖尚矣。书缺乐弛，朕甚闵焉。朕唯未能循明也，䌷绩日分，率应水德之胜。今日顺夏至，黄钟为宫，林钟为征，太蔟为商，南吕为羽，姑洗为角。自是以后，气复正，羽声复清，名复正变，以至子日当冬至，则阴阳离合之道行焉。十一月甲子朔旦冬至已詹，其更以七年为太初元年。年名『焉逢摄提格』，月名『毕聚』，日得甲子，夜半朔旦冬至。」
