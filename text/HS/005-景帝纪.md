### 前元

<a id="HS-005-003"></a>[\[HS-005-003\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-003) 元年冬十月，诏曰：「盖闻古者祖有功而宗有德，制礼乐各有由。歌者，所以发德也；舞者，所以明功也。高庙酎，奏武德、文始、五行之舞。孝惠庙酎，奏文始、五行之舞。孝文皇帝临天下，通关梁，不异远方；除诽谤，去肉刑，赏赐长老，收恤孤独，以遂群生；减耆欲，不受献，罪人不帑，不诛亡罪，不私其利也；除宫刑，出美人，重绝人之世也。朕既不敏，弗能胜识。此皆上世之所不及，而孝文皇帝亲行之。德厚侔天地，利泽施四海，靡不获福。明象乎日月，而庙乐不称，朕甚惧焉。其为孝文皇帝庙为昭德之舞，以明休德。然后祖宗之功德，施于万世，永永无穷，朕甚嘉之。其与丞相、列侯、中二千石、礼官具礼仪奏。」丞相臣嘉等奏曰：「陛下永思孝道，立昭德之舞以明孝文皇帝之盛德，皆臣嘉等愚所不及。臣谨议：世功莫大于高皇帝，德莫盛于孝文皇帝。高皇帝庙宜为帝者太祖之庙，孝文皇帝庙宜为帝者太宗之庙。天子宜世世献祖宗之庙。郡国诸侯宜各为孝文皇帝立太宗之庙。诸侯王列侯使者侍祠天子所献祖宗之庙。请宣布天下。」制曰：「可。」

<a id="HS-005-052"></a>[\[HS-005-052\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-052) 秋八月己酉，未央宫东阙灾。

<a id="HS-005-053"></a>[\[HS-005-053\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-053) 更名诸侯丞相为相。

<a id="HS-005-054"></a>[\[HS-005-054\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-054) 九月，诏曰：「法令度量，所以禁暴止邪也。狱，人之大命，死者不可复生。吏或不奉法令，以货赂为市，朋党比周，以苛为察，以刻为明，令亡罪者失职，朕甚怜之。有罪者不伏罪，奸法为暴，甚亡谓也。诸狱疑，若虽文致于法而于人心不厌者，辄谳之。」

<a id="HS-005-055"></a>[\[HS-005-055\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-055) 六年冬十月，行幸雍，郊五畤。

<a id="HS-005-056"></a>[\[HS-005-056\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-056) 十二月，改诸官名。定铸钱伪黄金弃市律。

<a id="HS-005-057"></a>[\[HS-005-057\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-057) 春三月，雨雪。

<a id="HS-005-058"></a>[\[HS-005-058\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-058) 夏四月，梁王薨，分梁为五国，立孝王子五人皆为王。

<sub>被引：[Q17](../../qa/Q17.md)</sub>

<a id="HS-005-059"></a>[\[HS-005-059\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-059) 五月，诏曰：「夫吏者，民之师也，车驾衣服宜称。吏六百石以上，皆长吏也，亡度者或不吏服，出入闾里，与民亡异。令长吏二千石车朱两轓，千石至六百石朱左轓。车骑从者不称其官衣服，下吏出入闾巷亡吏体者，二千石上其官属，三辅举不如法令者，皆上丞相御史请之。」先是吏多军功，车服尚轻，故为设禁。又惟酷吏奉宪失中，乃诏有司减笞法，定箠令。语在刑法志。

<a id="HS-005-060"></a>[\[HS-005-060\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-060) 六月，匈奴入鴈门，至武泉，入上郡，取苑马。吏卒战死者二千人。

### 后元

<a id="HS-005-062"></a>[\[HS-005-062\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-062) 后元年春正月，诏曰：「狱，重事也。人有智愚，官有上下。狱疑者谳有司。有司所不能决，移廷尉。有令谳而后不当，谳者不为失。欲令治狱者务先宽。」三月，赦天下，赐民爵一级，中二千石诸侯相爵右庶长。夏，大酺五日，民得酤酒。

<a id="HS-005-063"></a>[\[HS-005-063\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-063) 五月，地震。秋七月乙巳晦，日有蚀之。

<a id="HS-005-064"></a>[\[HS-005-064\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-064) 条侯周亚夫下狱死。

<sub>被引：[Q17](../../qa/Q17.md)、[Q173](../../qa/Q173.md)</sub>

<a id="HS-005-065"></a>[\[HS-005-065\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-065) 二年冬十月，省彻侯之国。

<a id="HS-005-066"></a>[\[HS-005-066\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-066) 春，匈奴入鴈门，太守冯敬与战死。发车骑材官屯。

<a id="HS-005-067"></a>[\[HS-005-067\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-067) 春，以岁不登，禁内郡食马粟，没入之。

<a id="HS-005-068"></a>[\[HS-005-068\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-068) 夏四月，诏曰：「雕文刻镂，伤农事者也；锦绣纂组，害女红者也。农事伤则饥之本也，女红害则寒之原也。夫饥寒并至，而能亡为非者寡矣。朕亲耕，后亲桑，以奉宗庙粢盛祭服，为天下先；不受献，减太官，省繇赋，欲天下务农蚕，素有畜积，以备灾害。彊毋攘弱，众毋暴寡，老耆以寿终，幼孤得遂长。今岁或不登，民食颇寡，其咎安在？或诈伪为吏，吏以货赂为市，渔夺百姓，侵牟万民。县丞，长吏也，奸法与盗盗，甚无谓也。其令二千石各修其职；不事官职耗乱者，丞相以闻，请其罪。布告天下，使明知朕意。」

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="HS-005-069"></a>[\[HS-005-069\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-069) 五月，诏曰：「人不患其不知，患其为诈也；不患其不勇，患其为暴也；不患其不富，患其亡厌也。其唯廉士，寡欲易足。今訾算十以上乃得宦，廉士算不必众。有市籍不得宦，无訾又不得宦，朕甚愍之。訾算四得宦，亡令廉士久失职，贪夫长利。」

<a id="HS-005-070"></a>[\[HS-005-070\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-070) 秋，大旱。

<a id="HS-005-071"></a>[\[HS-005-071\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-071) 三年春正月，诏曰：「农，天下之本也。黄金珠玉，饥不可食，寒不可衣，以为币用，不识其终始。间岁或不登，意为末者众，农民寡也。其令郡国务劝农桑，益种树，可得衣食物。吏发民若取庸采黄金珠玉者，坐臧为盗。二千石听者，与同罪。」

<a id="HS-005-072"></a>[\[HS-005-072\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-072) 皇太子冠，赐民为父后者爵一级。

<a id="HS-005-073"></a>[\[HS-005-073\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-073) 甲子，帝崩于未央宫。遗诏赐诸侯王列侯马二驷，吏二千石黄金二斤，吏民户百钱。出宫人归其家，复终身。二月癸酉，葬阳陵。

<sub>被引：[Q17](../../qa/Q17.md)</sub>

### 赞曰

<a id="HS-005-074"></a>[\[HS-005-074\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%99%AF%E5%B8%9D%E7%BA%AA?pn=HS-005-074) 孔子称「斯民三代之所以直道而行也」，信哉！周秦之敝，罔密文峻，而奸轨不胜。汉兴，扫除烦苛，与民休息。至于孝文，加之以恭俭，孝景遵业，五六十载之间，至于移风易俗，黎民醇厚。周云成康，汉言文景，美矣！
