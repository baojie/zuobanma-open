### 昭帝

<a id="HS-007-001"></a>[\[HS-007-001\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-001) 孝昭皇帝，武帝少子也。母曰赵婕妤，本以有奇异得幸，及生帝，亦奇异。语在外戚传。武帝末，戾太子败，燕王旦、广陵王胥行骄嫚，后元二年二月上疾病，遂立昭帝为太子，年八岁。以侍中奉车都尉霍光为大司马大将军，受遗诏辅少主。明日，武帝崩。戊辰，太子即皇帝位，谒高庙。帝姊鄂邑公主益汤沐邑，为长公主，共养省中。大将军光秉政，领尚书事，车骑将军金日䃅、左将军上官桀副焉。

<sub>被引：[Q54](../../qa/Q54.md)、[Q131](../../qa/Q131.md)</sub>

<a id="HS-007-002"></a>[\[HS-007-002\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-002) 夏六月，赦天下。

<a id="HS-007-003"></a>[\[HS-007-003\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-003) 秋七月，有星孛于东方。

<a id="HS-007-004"></a>[\[HS-007-004\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-004) 济北王宽有罪，自杀。

<a id="HS-007-005"></a>[\[HS-007-005\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-005) 赐长公主及宗室昆弟各有差。追尊赵婕妤为皇太后，起云陵。

<a id="HS-007-006"></a>[\[HS-007-006\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-006) 冬，匈奴入朔方，杀略吏民。发军屯西河，左将军桀行北边。

<sub>被引：[西河](../../entries/place/%E8%A5%BF%E6%B2%B3.md)、[Q71](../../qa/Q71.md)、[Q102](../../qa/Q102.md)</sub>

<a id="HS-007-007"></a>[\[HS-007-007\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-007) 始元元年春二月，黄鹄下建章宫太液池中。公卿上寿。赐诸侯王、列侯、宗室金钱各有差。

<a id="HS-007-008"></a>[\[HS-007-008\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-008) 己亥，上耕于钩盾弄田。

<a id="HS-007-009"></a>[\[HS-007-009\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-009) 益封燕王、广陵王及鄂邑长公主各万三千户。

<a id="HS-007-010"></a>[\[HS-007-010\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-010) 夏，为太后起园庙云陵。

<a id="HS-007-011"></a>[\[HS-007-011\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-011) 益州廉头、姑缯、牂柯谈指、同并二十四邑皆反。遣水衡都尉吕破胡募吏民及发犍为、蜀郡奔命击益州，大破之。

<a id="HS-007-012"></a>[\[HS-007-012\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-012) 有司请河内属冀州，河东属并州。

<sub>被引：[河内](../../entries/place/%E6%B2%B3%E5%86%85.md)</sub>

<a id="HS-007-013"></a>[\[HS-007-013\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-013) 秋七月，赦天下，赐民百户牛酒。大雨，渭桥绝。

<a id="HS-007-014"></a>[\[HS-007-014\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-014) 八月，齐孝王孙刘泽谋反，欲杀青州刺史隽不疑，发觉，皆伏诛。迁不疑为京兆尹，赐钱百万。

<a id="HS-007-015"></a>[\[HS-007-015\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-015) 九月丙子，车骑将军日䃅薨。

<a id="HS-007-016"></a>[\[HS-007-016\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-016) 闰月，遣故廷尉王平等五人持节行郡国，举贤良，问民所疾苦、冤、失职者。

<a id="HS-007-017"></a>[\[HS-007-017\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-017) 冬，无冰。

<a id="HS-007-018"></a>[\[HS-007-018\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-018) 二年春正月，大将军光、左将军桀皆以前捕斩反虏重合侯马通功封，光为博陆侯，桀为安阳侯。

<sub>被引：[安阳](../../entries/place/%E5%AE%89%E9%98%B3.md)、[Q131](../../qa/Q131.md)</sub>

<a id="HS-007-019"></a>[\[HS-007-019\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-019) 以宗室毋在位者，举茂才刘辟彊、刘长乐皆为光禄大夫，辟彊守长乐卫尉。

<a id="HS-007-020"></a>[\[HS-007-020\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-020) 三月，遣使者振贷贫民毋种、食者。秋八月，诏曰：「往年灾害多，今年蚕麦伤，所振贷种、食勿收责，毋令民出今年田租。」

<a id="HS-007-021"></a>[\[HS-007-021\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-021) 冬，发习战射士诣朔方，调故吏将屯田张掖郡。

<sub>被引：[Q71](../../qa/Q71.md)</sub>

<a id="HS-007-022"></a>[\[HS-007-022\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-022) 三年春二月，有星孛于西北。

<a id="HS-007-023"></a>[\[HS-007-023\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-023) 秋，募民徙云陵，赐钱田宅。

<a id="HS-007-024"></a>[\[HS-007-024\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-024) 冬十月，凤皇集东海，遣使者祠其处。

<a id="HS-007-025"></a>[\[HS-007-025\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-025) 十一月壬辰朔，日有蚀之。

<a id="HS-007-026"></a>[\[HS-007-026\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-026) 四年春三月甲寅，立皇后上官氏。赦天下。辞讼在后二年前，皆勿听治。夏六月，皇后见高庙。赐长公主、丞相、将军、列侯、中二千石以下及郎吏宗室钱帛各有差。

<a id="HS-007-027"></a>[\[HS-007-027\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-027) 徙三辅富人云陵，赐钱，户十万。

<a id="HS-007-028"></a>[\[HS-007-028\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-028) 秋七月，诏曰：「比岁不登，民匮于食，流庸未尽还，往时令民共出马，其止勿出。诸给中都官者，且减之。」

<a id="HS-007-029"></a>[\[HS-007-029\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-029) 冬，遣大鸿胪田广明击益州。

<a id="HS-007-030"></a>[\[HS-007-030\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-030) 廷尉李种坐故纵死罪弃市。

<a id="HS-007-031"></a>[\[HS-007-031\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-031) 五年春正月，追尊皇太后父为顺成侯。

<a id="HS-007-032"></a>[\[HS-007-032\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-032) 夏阳男子张延年诣北阙，自称卫太子，诬罔，要斩。

<a id="HS-007-033"></a>[\[HS-007-033\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-033) 夏，罢天下亭母马及马弩关。

<a id="HS-007-034"></a>[\[HS-007-034\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-034) 六月，封皇后父骠骑将军上官安为桑乐侯。

<a id="HS-007-035"></a>[\[HS-007-035\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-035) 诏曰：「朕以眇身获保宗庙，战战栗栗，夙兴夜寐，修古帝王之事，通保傅，传孝经、论语、尚书，未云有明。其令三辅、太常举贤良各二人，郡国文学高第各一人。赐中二千石以下至吏民爵各有差。」

<a id="HS-007-036"></a>[\[HS-007-036\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-036) 罢儋耳、真番郡。

<a id="HS-007-037"></a>[\[HS-007-037\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-037) 秋，大鸿胪广明、军正王平击益州，斩首捕虏三万余人，获畜产五万余头。

<a id="HS-007-038"></a>[\[HS-007-038\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-038) 六年春正月，上耕于上林。

<a id="HS-007-039"></a>[\[HS-007-039\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-039) 二月，诏有司问郡国所举贤良文学民所疾苦。议罢盐铁榷酤。

<a id="HS-007-040"></a>[\[HS-007-040\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-040) 栘中监苏武前使匈奴，留单于庭十九岁乃还，奉使全节，以武为典属国，赐钱百万。

<a id="HS-007-041"></a>[\[HS-007-041\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-041) 夏，旱，大雩，不得举火。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="HS-007-042"></a>[\[HS-007-042\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-042) 秋七月，罢榷酤官，令民得以律占租，卖酒升四钱。以边塞阔远，取天水、陇西、张掖郡各二县置金城郡。

<sub>被引：[Q80](../../qa/Q80.md)</sub>

<a id="HS-007-043"></a>[\[HS-007-043\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-043) 诏曰：「钩町侯毋波率其君长人民击反者，斩首捕虏有功。其立毋波为钩町王。大鸿胪广明将率有功，赐爵关内侯，食邑。」

<a id="HS-007-044"></a>[\[HS-007-044\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-044) 元凤元年春，长公主共养劳苦，复以蓝田益长公主汤沐邑。

<sub>被引：[蓝田](../../entries/place/%E8%93%9D%E7%94%B0.md)</sub>

<a id="HS-007-045"></a>[\[HS-007-045\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-045) 泗水戴王前薨，以毋嗣，国除。后宫有遗腹子煖，相、内史不奏言，上闻而怜之，立煖为泗水王。相、内史皆下狱。

<a id="HS-007-046"></a>[\[HS-007-046\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-046) 三月，赐郡国所选有行义者涿郡韩福等五人帛，人五十匹，遣归。诏曰：「朕闵劳以官职之事，其务修孝弟以教乡里。令郡县常以正月赐羊酒。有不幸者赐衣被一袭，祠以中牢。」

<a id="HS-007-047"></a>[\[HS-007-047\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-047) 武都氐人反，遣执金吾马适建、龙頟侯韩增、大鸿胪广明将三辅、太常徒，皆免刑击之。

<sub>[二校](../../collation/review.md)：改字 1 处</sub>

<a id="HS-007-048"></a>[\[HS-007-048\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-048) 夏六月，赦天下。

<a id="HS-007-049"></a>[\[HS-007-049\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-049) 秋七月乙亥晦，日有蚀之，既。

<a id="HS-007-050"></a>[\[HS-007-050\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-050) 八月，改始元为元凤。

<a id="HS-007-051"></a>[\[HS-007-051\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-051) 九月，鄂邑长公主、燕王旦与左将军上官桀、桀子票骑将军安、御史大夫桑弘羊皆谋反，伏诛。初，桀、安父子与大将军光争权，欲害之，诈使人为燕王旦上书言光罪。时上年十四，觉其诈。后有谮光者，上辄怒曰：「大将军国家忠臣，先帝所属，敢有谮毁者，坐之。」光由是得尽忠。语在燕王、霍光传。

<a id="HS-007-052"></a>[\[HS-007-052\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-052) 冬十月，诏曰：「左将军安阳侯桀、票骑将军桑乐侯安、御史大夫弘羊皆数以邪枉干辅政，大将军不听，而怀怨望，与燕王通谋，置驿往来相约结。燕王遣寿西长、孙纵之等赂遗长公主、丁外人、谒者杜延年、大将军长史公孙遗等，交通私书，共谋令长公主置酒，伏兵杀大将军光，征立燕王为天子，大逆毋道。故稻田使者燕仓先发觉，以告大司农敞，敞告谏大夫延年，延年以闻。丞相征事任宫手捕斩桀，丞相少史王寿诱将安入府门，皆已伏诛，吏民得以安。封延年、仓、宫、寿皆为列侯。」又曰：「燕王迷惑失道，前与齐王子刘泽等为逆，抑而不扬，望王反道自新，今乃与长公主及左将军桀等谋危宗庙。王及公主皆自伏辜。其赦王太子建、公主子文信及宗室子与燕王、上官桀等谋反父母同产当坐者，皆免为庶人。其吏为桀等所诖误，未发觉在吏者，除其罪。」

### 【赞】

<a id="HS-007-076"></a>[\[HS-007-076\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E6%98%AD%E5%B8%9D%E7%BA%AA?pn=HS-007-076) 赞曰：昔周成以孺子继统，而有管、蔡四国流言之变。孝昭幼年即位，亦有燕、盍、上官逆乱之谋。成王不疑周公，孝昭委任霍光，各因其时以成名，大矣哉！承孝武奢侈余敝师旅之后，海内虚耗，户口减半，光知时务之要，轻繇薄赋，与民休息。至始元、元凤之间，匈奴和亲，百姓充实。举贤良文学，问民所疾苦，议盐铁而罢榷酤，尊号曰「昭」，不亦宜乎！
