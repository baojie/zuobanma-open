<a id="HS-058-002"></a>[\[HS-058-002\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-002) 告巴蜀太守：蛮夷自擅，不讨之日久矣，时侵犯边境，劳士大夫。陛下即位，存抚天下，集安中国，然后兴师出兵，北征匈奴，单于怖骇，交臂受事，屈膝请和。康居西域，重译纳贡，稽首来享。〈师古曰：「来入朝觐，豫享祀也。一曰享，献也，献其国珍也。」〉移师东指，闽越相诛；右吊番禺，太子入朝。〈文颖曰：「吊，至也。番禺，南海郡治也。东伐越，后至番禺，故言右也。」师古曰：「南越为东越所伐，汉发兵救之，南越蒙天子德惠，故遣太子入朝，所以云吊耳，非训至也。」〉南夷之君，西僰之长，常效贡职，不敢惰怠，延颈举踵，喁喁然，〈师古曰：「喁喁，众口向上也，音鱼龙反。」〉皆乡风慕义，〈师古曰：「乡读曰向。」〉欲为臣妾，道里辽远，山川阻深，不能自致。〈师古曰：「致，至也。」〉夫不顺者已诛，而为善者未赏，故遣中郎将徃宾之，发巴蜀之士各五百人以奉币，卫使者不然，〈张揖曰：「不然之变也。」〉靡有兵革之事，战斗之患。今闻其乃发军兴制，〈师古曰：「以发军之法为兴众之制也。」〉惊惧子弟，忧患长老，郡又擅为转粟运输，皆非陛下之意也。当行者或亡逃自贼杀，〈师古曰：「贼犹害也。」〉亦非人臣之节也。

<a id="HS-058-003"></a>[\[HS-058-003\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-003) 夫边郡之士，闻㷭举燧燔，〈孟康曰：「㷭如覆米䉛，县著契臯头，有寇则举之。燧，积薪，有寇则燔然之也。」〉皆摄弓而驰，荷兵而走，〈师古曰：「摄谓张弓注矢而持之也。摄音女涉反。」〉流汗相属，惟恐居后，〈师古曰：「属，逮也，音之欲反。」〉触白刃，冒流矢，〈师古曰：「冒，犯也。」〉议不反顾，计不旋踵，人怀怒心，如报私雠。彼岂乐死恶生，非编列之民，而与巴蜀异主哉？〈师古曰：「编列，谓编户也。编音布先反。」〉计深虑远，急国家之难，而乐尽人臣之道也。故有剖符之封，析圭而爵，位为通侯，〈如淳曰：「析，中分也。白藏天子，青在诸侯也。」〉居列东第。〈师古曰：「东第，甲宅也。居帝城之东，故曰东第也。」〉终则遗显号于后世，传土地于子孙，事行甚忠敬，居位甚安佚，〈师古曰：「佚，乐也，读与逸同。」〉名声施于无穷，功烈著而不灭。是以贤人君子，肝脑涂中原，膏液润埜屮而不辞也。〈师古曰：「埜与野同，古野字也。屮，古草字。」〉今奉币役至南夷，即自贼杀，或亡逃抵诛，〈师古曰：「抵，至也，亡逃而至于诛也。」〉身死无名，〈师古曰：「无善名也。」〉谥为至愚，〈师古曰：「谥者，行之迹也。终以愚死，后叶传称，故谓之谥。」〉耻及父母，为天下笑。人之度量相越，岂不远哉！然此非独行者之罪也，父兄之教不先，子弟之率不谨，〈师古曰：「不先者，谓往日不素教之也。」〉寡廉鲜耻，而俗不长厚也。〈师古曰：「寡、鲜，皆少也。鲜音息浅反。」〉其被刑戮，不亦宜乎！

<a id="HS-058-004"></a>[\[HS-058-004\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-004) 陛下患使者有司之若彼，悼不肖愚民之如此，故遣信使，〈师古曰：「诚信之人以为使也。」〉晓谕百姓以发卒之事，〈师古曰：「谕，告也。」〉因数之以不忠死亡之罪，〈师古曰：「数，责也，音所具反。」〉让三老孝弟以不教诲之过。〈师古曰：「让，责也，责其教诲不备也。」〉方今田时，重烦百姓，〈师古曰：「重，难也，不欲召聚之也。」〉已亲见近县，〈师古曰：「近县之人，使者以自见而口谕之矣，故为檄文驰以示远所也。」〉恐远所谿谷山泽之民不徧闻，檄到，亟下县道，〈师古曰：「亟，急也。县有蛮夷曰道。」〉咸谕陛下意，毋忽！〈师古曰：「忽，怠忽也。」〉

<a id="HS-058-005"></a>[\[HS-058-005\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-005) 相如还报。〈师古曰：「使讫还报天子也。」〉唐蒙已略通夜郎，因通西南夷道，发巴蜀广汉卒，作者数万人。治道二岁，道不成，士卒多物故，〈师古曰：「物故，死也。解在苏武传。」〉费以亿万计。蜀民及汉用事者多言其不便。是时邛、莋之君长〈文颖曰：「邛者，今为邛都县。莋者，今为定莋县。」师古曰：「莋，才各反。」〉闻南夷与汉通，得赏赐多，多欲愿为内臣妾，请吏，比南夷。上问相如，相如曰：「邛、莋、冉、駹者近蜀，道易通，〈师古曰：「今夔州、开州等首领姓冉者，皆旧冉种也。駹音尨。」〉异时尝通为郡县矣，〈师古曰：「异时犹言往时也。」〉至汉兴而罢。今诚复通，为置县，愈于南夷。」〈晋灼曰：「南夷谓犍为、牂牁也。西夷谓越巂、益州也。」师古曰：「愈，胜也。」〉上以为然，乃拜相如为中郎将，建节徃使。副使者王然于、壶充国、吕越人，驰四乘之传，〈师古曰：「传音张恋反。」〉因巴蜀吏币物以赂西南夷。至蜀，太守以下郊迎，〈师古曰：「迎于郊界之上也。」〉县令负弩矢先驱，〈师古曰：「导路也。」〉蜀人以为宠。于是卓王孙、临邛诸公皆因门下献牛酒以交驩。卓王孙喟然而叹，自以得使女尚司马长卿晚，〈师古曰：「尚犹配也，义与尚公主同。今流俗书本此尚字作当，盖后人见前云文君恐不得当，故改此文以就之耳。」〉乃厚分与其女财，与男等。相如使略定西南夷，邛、莋、冉、駹、斯榆之君皆请为臣妾，除边关，边关益斥，〈师古曰：「斥，开广也。」〉西至沬、若水，〈张揖曰：「沬水出蜀广平徼外。若水出旄牛徼外。」师古曰：「沬音妹。」〉南至牂牁为徼，〈张揖曰：「徼谓以木石水为界者也。」如淳曰：「斯榆之君等自求去边关，欲与牂牁作徼塞也。」师古曰：「徼音工钓反。」〉通灵山道，桥孙水，〈张揖曰：「凿开灵山道，置灵道县。孙水出台登县，南至会无入若水。」师古曰：「于孙水上作桥也。」〉以通邛、莋。还报，天子大说。〈师古曰：「说读曰悦。」〉

<a id="HS-058-010"></a>[\[HS-058-010\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-010) 盖世必有非常之人，然后有非常之事；有非常之事，然后有非常之功。非常者，固常人之所异也。〈师古曰：「常人见之以为异也。」〉故曰非常之元，黎民惧焉；〈师古曰：「元，始也。非常之事，其始难知，众人惧之。」〉及臻厥成，天下晏如也。〈师古曰：「臻，至也。晏，安也。」〉

<a id="HS-058-023"></a>[\[HS-058-023\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-023) 世有大人兮，在乎中州。〈师古曰：「大人，以谕天子也。中州，中国也。」〉宅弥万里兮，曾不足以少留。〈师古曰：「弥，满也。」〉悲世俗之迫隘兮，朅轻举而远游。〈师古曰：「朅，去意也，音丘例反。」〉乘绛幡之素蜺兮，载云气而上浮。〈张揖曰：「乘，用也。赤气为幡，缀以白气也。」师古曰：「上音时掌反。」〉建格泽之修竿兮，〈张揖曰：「格泽之气如炎火状，黄白色，起地上至天，下大上锐。修，长也。建此气为长竿也。」师古曰：「格音胡各反。泽音大各反。」〉总光燿之采旄。〈张揖曰：「旄，葆也。总，系也。系光耀之气于长竿以为葆也。」师古曰：「总音摠。葆即今所谓纛头也。」〉垂旬始以为㡎兮，〈李奇曰：「旬始，气如雄鸡，见北斗旁。」张揖曰：「㡎，旒也。县旬始于葆下，以为十二旒也。」师古曰：「㡎音所衔反。」〉曳彗星而为髾。〈张揖曰：「髾，燕尾也。枻彗星缀者旒以为燕尾也。」〉掉指桥以偃寋兮，〈张揖曰：「指桥，随风指靡也。偃寋，委曲貌。」师古曰：「掉音徒钓反。寋音居偃反。」〉又猗抳以招摇。〈晋灼曰：「猗音依倚反。抳音年𫄥反。」张揖曰：「猗抳，下垂貌。招摇，跳踃也。」师古曰：「招音韶。踃音萧。」〉㨫搀抢以为旌兮，靡屈虹而为绸。〈张揖曰：「彗星为搀抢。注髦首曰旌，今以彗星代之也。靡，顺也。绸，韬也。以断虹为旌杠之韬也。」师古曰：「韬谓裹冒旌旗之竿也。搀音初咸反。抢音初衡反。屈音其勿反。绸音直流反。」〉红杳眇以玄湣兮，猋风涌而云浮。〈苏林曰：「玄音炫。湣音面。」晋灼曰：「红，赤色貌。杳眇，深远也。玄湣，混合也。言自绛幡以下，众气色盛，光采相燿，幽蔼炫乱也。」师古曰：「如猋风之涌，如云之浮，言轻举也。猋音必遥反。」〉驾应龙象舆之蠖略委丽兮，骖赤螭青虬之蚴蟉宛蜒。〈文颖曰：「有翼曰应龙，最其神妙者也。」师古曰：「蠖略委丽、蚴蟉宛蜒，皆其行步进止之貌也。蠖音于缚反，丽音力尔反。蚴音一纠反。蟉音力纠反。宛音于元反。蜒音延。」〉低卬夭𫊸裾以骄骜兮，诎折隆穷躩以连卷。〈张揖曰：「裾，直项也。骄骜，纵恣也。诎折，曲委也。隆穷，举鬐也。躩，跳也。连卷，句蹄也。」师古曰：「裾音倨。骄音居召反。骜音五到反。躩音巨缚反。卷音巨圆反。」〉沛艾赳螑仡以佁儗兮，〈张揖曰：「沛艾，𫘟騀也。赳螑，申颈低卬也。仡，举头也。佁儗，不前也。」师古曰：「沛音普盖反。赳音古幼反。螑音火幼反。仡音鱼乞反。佁音丑吏反。儗音鱼吏反。佁儗又音态碍。」〉放散畔岸骧以孱颜。〈师古曰：「畔岸，自纵之貌也。骧，举也。孱颜，不齐也。孱音士颜反。」〉跮踱輵螛容以骫丽兮，〈张揖曰：「跮踱，互前却也。輵螛，摇目吐舌也。容，龙体貌也。骫丽，左右相随也。」师古：「跮音丑日反。踱音丑略反。輵音遏。螛音曷。骫，古委字也。丽音力尔反。」〉蜩蟉偃寋怵㚟以梁倚。〈张揖曰：「蜩蟉，掉头也。怵㚟，奔走也。梁倚，相著也。」师古曰：「蜩音徒钓反。蟉音卢钓反。怵音黜。㚟音丑若反。倚音于绮反。」〉纠蓼叫奡踏以朡路兮，〈张揖曰：「纠蓼，相引也。叫奡，相呼也。踏，下也。朡，著也。皆下著道也。」师古曰：「叫奡，高举之貌。蓼音力纠反。奡音五到反。踏音沓。朡音届。」〉薎蒙踊跃腾而狂趭。〈张揖曰：「薎蒙，飞扬也。踊跃，跳也。腾，驰也。趭，奔走也。」师古曰：「蒙音莫孔反。趭音醮。」〉莅飒芔歙焱至电过兮，焕然雾除，霍然云消。〈张揖曰：「莅飒，飞相及也。芔歙，走相追也。」师古曰：「莅音利。飒音立。芔音讳。歙音翕。」〉

<a id="HS-058-024"></a>[\[HS-058-024\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-024) 邪绝少阳而登太阴兮，与真人乎相求。〈张揖曰：「少阳，东极。太阴，北极。邪度东极而升北极也。真人，谓若士也，游于太阴之中。」师古曰：「真人，至真之人也，非指谓若士也。」〉互折窈窕以右转兮，横厉飞泉以正东。〈张揖曰：「飞泉，飞谷也，在昆仑山西南。」师古曰：「厉，渡也。」〉悉征灵圉而选之兮，部署众神于摇光。〈张揖曰：「摇光，北斗杓头第一星。」〉使五帝先导兮，反大壹而从陵阳。〈应劭曰：「五帝，五畤，太皞之属也。」如淳曰：「天极，大星，一明者，太一常居也。」张揖曰：「陵阳，仙人陵阳子明也。」师古曰：「令太一反其所居，而使陵阳侍从于己。」〉左玄冥而右黔雷兮，〈张揖曰：「玄冥，北方黑帝佐也。黔雷，黔嬴也，天上造化神名也。楚辞曰『召黔嬴而见之』。或曰水神也。」〉前长离而后矞皇。〈服虔曰：「皆神名也。」师古曰：「长离，灵鸟也，解在礼乐志。矞音以出反。」〉厮征伯侨而役羡门兮，诏岐伯使尚方。〈应劭曰：「厮，役也。」张揖曰：「伯侨，仙人王子侨也。羡门，碣石山上仙人羡门高也。尚，主也。岐伯者，黄帝太医，属使主方药也。」师古曰：「征伯侨者，仙人，姓征，名伯侨，非王子侨也。郊祀志征字作正，其音同耳。或说云征谓役使之，非也。」〉祝融警而跸御兮，清气氛而后行。〈张揖曰：「祝融，南方炎帝之佐也，兽身人面，乘两龙。」师古曰：「跸，止行人也。御，御也。氛，恶气也。」〉屯余车而万乘兮，綷云盖而树华旗。〈师古曰：「綷，合也，合五采云以为盖也。綷音子内反。」〉使句芒其将行兮，吾欲徃乎南娭。〈张揖曰：「句芒，东方青帝之佐也，鸟身人面，乘两龙。」师古曰：「将行，将领从行也。娭音许其反。」〉

<a id="HS-058-025"></a>[\[HS-058-025\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-025) 历唐尧于崇山兮，过虞舜于九疑。〈张揖曰：「崇山，狄山也。海外经曰狄山，帝尧葬于其阳。九疑山在零陵营道县，舜所葬也。」师古曰：「疑，似也。山有九峰，其形相似，故曰九疑。」〉纷湛湛其差错兮，杂遝胶輵以方驰。〈师古曰：「湛湛，积厚之貌。差错，交互也。杂遝，重絫也。胶輵犹交加也。湛音徒感反。遝音大合反。輵音葛。」〉骚櫌冲苁其纷挐兮，滂濞泱轧丽以林离。〈张揖曰：「冲苁，相入貌。滂濞，众盛貌。泱轧，不前也。丽，靡也。林离，椮𪲔也。」师古曰：「冲音尺勇反。苁音相勇反。挐音女居反。滂音普郎反。濞音普备反。泱音乌朗反。轧音于黠反。椮音所林反。𪲔音所宜反。」〉攒罗列聚丛以茏茸兮，衍曼流烂痑以陆离。〈张揖曰：「痑，众貌，一曰罢极也。陆离，参差也。」师古曰：「茏茸，聚貌。流烂，布散也。痑，自放纵也。茏音来孔反。茸音而孔反。衍音弋扇反。痑音式尔反，张云罢极，义则非矣。」〉径入雷室之砰磷郁律兮，洞出鬼谷之堀礨崴魁。〈张揖曰：「雷室，雷渊也。洞，通也。鬼谷在昆仑北直北辰下，众鬼之所聚也。堀礨崴魁，不平也。」师古曰：「砰磷郁律，深峻貌。砰音普萌反。磷音力耕反。堀音口骨反。礨音洛贿反。崴音一回反。」〉徧览八纮而观四海兮，朅度九江越五河。〈张揖曰：「九江在庐江寻阳县南，皆东合为大江者。」服虔曰：「河有九，今越其五也。」晋灼曰：「五河，五湖，取河之声合其音耳。」师古曰：「服、晋说五河皆非也。五河，五色之河也。仙经说有紫碧绛青黄之河，非谓九河之内，亦非五湖也。」〉经营炎火而浮弱水兮，杭绝浮渚涉流沙。〈应劭曰：「楚辞曰『越炎火之万里』。弱水出张掖删丹，西至酒泉合黎余波入于流沙。」张揖曰：「杭，船也。绝，度也。浮渚，流沙中渚也。流沙，沙与水流行也。」师古曰：「弱水谓西域绝远之水，乘毛车以度者耳，非张掖弱水也。又流沙但有沙流，本无水也。言绝度浮渚，乃涉流沙也。杭音下郎反。」〉奄息葱极泛滥水娭兮，〈张揖曰：「奄然休息也。葱极，葱领山也，在西域中。」〉使灵娲鼓琴而舞冯夷。〈服虔曰：「灵娲，女娲也。伏牺作琴，使女娲鼓之。冯夷，河伯字也，淮南子曰『冯夷得道以潜大川』。」师古曰：「娲音瓜，又工蛙反。」〉时若暧暧将混浊兮，召屏翳诛风伯，刑雨师。〈应劭曰：「屏翳，天神使也。」张揖曰：「风伯字飞廉。」师古曰：「屏音步丁反。」〉西望昆仑之轧沕荒忽兮，〈张揖曰：「昆仑去中国五万里，天帝之下都也。其山广袤百里，高八万仞，增城九重，面有九井，以玉为槛，旁有五门，开明兽守之。轧沕荒忽，不分明之貌。」师古曰：「沕音勿。荒音呼广反。」〉直径驰乎三危。〈张揖曰：「三危山在鸟鼠山之西，与崏山相近，黑水出其南陂，书曰『导黑水至于三危』也。」〉排阊阖而入帝宫兮，载玉女而与之归。〈张揖曰：「玉女，青要、乘弋等也。」〉登阆风而遥集兮，亢鸟腾而壹止。〈张揖曰：「阆风山在昆仑阊阖之中。遥，远也。」应劭曰：「亢然高飞，如鸟之腾也。」师古曰：「阆音浪。亢音抗。」〉低徊阴山翔以纡曲兮，吾乃今日覩西王母。暠然白首戴胜而穴处兮，亦幸有三足乌为之使。〈张揖曰：「阴山在昆仑西二千七百里。西王母其状如人，豹尾虎首，蓬发暠然白首，石城金室，穴居其中。三足鸟，三足青鸟也，主为西王母取食，在昆仑墟之北。」如淳曰：「山海经曰『西王母梯几而戴胜』。」师古曰：「低徊犹徘徊也。胜，妇人首饰也，汉代谓之华胜。暠音工老反，字或作翯，音学。」〉必长生若此而不死兮，虽济万世不足以喜。〈师古曰：「昔之谈者咸以西王母为仙灵之最，故相如言大人之仙，娱游之盛，顾视王母，鄙而陿之，不足羡慕也。」〉

<a id="HS-058-037"></a>[\[HS-058-037\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-037) 宛宛黄龙，兴德而升；〈文颖曰：「起至德而见也。」〉采色玄耀，炳炳𪸩煌。〈师古曰：「玄读曰炫。𪸩煌，光貌。𪸩音下本反。」〉正阳显见，觉寤黎烝。〈文颖曰：「阳，明也。」师古曰：「黎烝，众庶也。」〉于传载之，云受命所乘。〈师古曰：「谓易云『时乘六龙以御天也』。」〉

<sub>对读：[SJ-117-027](../SJ/117-%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E5%88%97%E4%BC%A0.md#SJ-117-027)</sub>

<a id="HS-058-038"></a>[\[HS-058-038\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-038) 厥之有章，不必谆谆。〈文颖曰：「天之所命，表以符瑞，章明其德，不必谆谆然有语言也。」师古曰：「谆谆，告喻之熟也，音之纯反。」〉依类托寓，谕以封峦。〈文颖曰：「寓，寄也。峦，山也。言依事类托寄，以喻封禅。」〉

<a id="HS-058-039"></a>[\[HS-058-039\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-039) 披蓺观之，天人之际已交，上下相发允荅。圣王之事，兢兢翼翼。〈师古曰：「兢兢，戒也。翼翼，敬也。」〉故曰于兴必虑衰，安必思危。是以汤武至尊严，不失肃祗，〈师古曰：「言居天子之位，犹不忘恭敬也。」〉舜在假典，顾省厥遗：〈师古曰：「在，察也。假，大也。典，则也。言舜察琁玑玉衡，恐己政化有所遗失，不合天心。今汉亦当顺天意而封禅也。」〉此之谓也。

### 【赞】

<a id="HS-058-042"></a>[\[HS-058-042\]](https://zuobanma.memify.wiki/#%E6%B1%89%E4%B9%A6%C2%B7%E5%8F%B8%E9%A9%AC%E7%9B%B8%E5%A6%82%E4%BC%A0%E4%B8%8B?pn=HS-058-042) 赞曰：司马迁称「《春秋》推见至隐，〈李奇曰：「隐犹微也。言其义显而文隐，若隐公见弑死，而经不书，隐讳之也。」〉易本隐以之显，〈张揖曰：「作八卦以通神明之德，是本隐也。有天道焉，有地道焉，有人道焉，以类万物之情，是之显也。」师古曰：「之，往也。」〉大雅言王公大人，而德逮黎庶，〈张揖曰：「谓文王、公刘在位，大人之德下及众民者也。」〉小雅讥小己之得失，其流及上。〈张揖曰：「己，诗人自谓也。己小有得失，不得其所，作诗流言，以讽其上也。」师古曰：「小己者，谓卑少之人，以对上言大人耳。」〉所言虽殊，其合德一也。相如虽多虚辞滥说，然要其归引之于节俭，此亦诗之风谏何异？」〈师古曰：「风读曰讽，次下亦同。」〉杨雄以为靡丽之赋，劝百而风一，〈师古曰：「奢靡之辞多，而节俭之言少也。」〉犹骋郑卫之声，曲终而奏雅，不已戏乎！〈张揖曰：「不亦轻戏乎哉！」〉
