# 左班马互鉴 · 开放数据

《左传》《史记》《汉书》三书对读的开放语料。**全部内容按段组织**：原文的每一段有一个段落编号（PN），词条和问答的每一句、二校的每一条记录、三书之间的每一组平行段，都挂在 PN 上。

在线站点：<https://zuobanma.memify.wiki/>

## 一个 PN 能查到什么

以 [`SJ-008-048`](text/SJ/008-%E9%AB%98%E7%A5%96%E6%9C%AC%E7%BA%AA.md#SJ-008-048) 为例，这是《史记·高祖本纪》第 48 段，楚汉相持时汉王在广武数落项羽十条罪状：

| | |
|---|---|
| **原文** | 「楚汉久相持未决，丁壮苦军旅，老弱罢转馕。汉王项羽相与临广武之闲而语……」 |
| **在线** | [zuobanma.memify.wiki/#史记·高祖本纪?pn=SJ-008-048](https://zuobanma.memify.wiki/#%E5%8F%B2%E8%AE%B0%C2%B7%E9%AB%98%E7%A5%96%E6%9C%AC%E7%BA%AA?pn=SJ-008-048)，打开即定位到这一段并高亮 |
| **被引** | 2 个词条、13 条问答引用了这一段 |
| **对读** | 《汉书·高帝纪》[`HS-001-055`](text/HS/001-%E9%AB%98%E5%B8%9D%E7%BA%AA.md#HS-001-055)，两段约六成文字重合 |
| **二校** | 删去 1 个衍字：「罪一。~~秦~~项羽矫杀卿子冠军」 |
| **指纹** | `a88759f025e5`，文字一旦改动，指纹随之改变 |

这些信息在原文页上就是这一段下面的一行小字；词条和问答里出现的每个 PN 都能点击，直接跳到原文的这一段。

**PN 的格式、稳定性承诺、引用格式、怎么查、改号历史，见 [PN.md](PN.md)。**

## 内容

## 底本与校勘

- **底本**：维基文库《春秋左氏傳》《史記》《漢書》，用 OpenCC 繁转简，并统一少数字形异体（矦→侯、髙→高 等）；彊、迺、菑等古字和通假字保留原样。左传按年分章；史记一卷一章；汉书一卷一章，上、中、下各自成章，正文中的颜师古注保留。
- **二校**：左传以中华书局《春秋左传诂》（洪亮吉撰，李解民点校）为校本，史记、汉书以中华书局点校本为校本，只比汉字。差异逐条复核：判为底本讹、脱、衍、错乱的，按 `collation/corrections.json` 改入底本，PN 不变；判为异文、体例差异的不改；拿不准的列入存疑。
- 校本原文受版权保护，**本仓库只收差异字和判定理由，不收校本原文**。

### 校勘总结

二校共逐条复核差异 8,077 条（左传 1,323、史记 1,166、汉书 5,588），其中 1,744 条判为底本错误并改入正文：讹字 1,317、脱文 250、错乱 76、注文混入 50（用〈〉括出，不删）、衍文 42、整段脱失 9。改字只在段内进行，所有 PN 保持不变。底本与校本的汉字相似度：左传 98.61%、史记 97.87%、汉书 94.06%。145 条判不了的列为存疑，12 条改法没通过核验的待人工处理。

底本的错主要有几种：一是繁转简造成的误字（如「汜」作「泛」、「市」作「巿」）；二是生僻字在录文时被换成形近的常用字；三是整段漏抄；四是《史记》三家注和录文者的校语混进正文。二校还顺带查出导入程序本身的两个错误——繁简保护字整字丢失约 4,800 字、分章行号逐章偏移，均已修复。成批出现的用字差异（唯/惟、迺/乃、并/幷等）和点校者的校改不向点校本统一，底本保留所据版本的原貌。各类问题的详细说明和例子见 [collation/README.md](collation/README.md)。

## 词条与问答的产生方式

词条和问答由 AI 依据本站原文写成，每句都挂 PN。精答发布前由程序核验：PN 必须在本题的证据包里，直接引用的原文必须与所挂 PN 逐字吻合；查出问题就交回 AI 改一轮再核。尽管如此，仍可能有理解错误或遗漏，引用前请回到原文核对。

每条精答的核验过程全部公开在 [`verification/`](verification/README.md)：检索词、证据包、初稿被查出的问题和改法，以及导出时按现行原文逐条重核的结果。重核记下了所依据的原文版本和每个被引段的文字指纹。183 条精答中，162 条的初稿被查出问题后改正发布；按现行原文重核，230 处直引因为原文后来经过二校改字、补回丢字而对不上，答案写作时它们是逐字吻合的。
