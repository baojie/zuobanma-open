# 二校记录

本目录是《左传》《史记》《汉书》第二次校勘（二校）的全部结论。

- **底本**：本站正文，即维基文库录文经繁转简后的文字。
- **校本**：左传用中华书局《春秋左传诂》（洪亮吉撰，李解民点校，校前剥去【诂】注）；史记、汉书用中华书局点校本。点校本汉书缺卷五十七，这一卷改用殆知阁本经校勘后的文字，只用来查脱文和段落脱失。
- **对校范围**：只比汉字，不比标点。
- 校本原文受版权保护，本目录**只收差异字和判定理由**，不收校本原文。

| 文件 | 内容 |

| `summary-{ZZ,SJ,HS}.json` | 分章相似度与字数 |

## 流程

1. **机器对校**：把底本和校本逐章对齐，只比汉字，差异分为四类：sub（一字）、minor（2–3 字）、major（4 字以上）、用字（成批出现的字对）。
2. **字对分拣**：成批出现的用字差异先按字对分拣。异体、古今、通假、繁简残留这类两通的字对（如 唯/惟、斗/鬭、迺/乃、并/幷）整对放过。形近易讹的字对（如 已/己/巳、戌/戍、大/太、宫/官）转入逐条复核。
3. **逐条复核**：共 8,077 条，每条附底本所在段、校本对应段（保留点校本的〔补〕（删）记号和校勘记），逐条判定。原则是从严：没有把握的不改，判为存疑或异文。
4. **入底本**：凡判为改的，生成改字表，按段套用到底本。改字表里的原文串必须在该段中唯一出现，否则拒绝套用，列入 `rejected.md`。改字只在段内替换，**不拆段、不并段、不增删段，PN 不变**。

## 判定类别

| 判定 | 处理 | 含义 |
|---|---|---|
| 底本讹字 | 改 | 底本字明显错（形近、音近、不成义） |
| 底本脱文 | 改 | 底本漏字、漏句，校本有，且不在点校本〔〕补字之内 |
| 段落脱失 | 改 | 校本有整段而底本没有；补文接在相邻段的段首或段末 |
| 底本衍文 | 改 | 底本多出的字（重抄、错入） |
| 注文混入 | 加〈〉 | 后人注混入正文而未加标记；不删，用〈〉括出 |
| 底本错乱 | 改 | 错简、颠倒、乱码，据校本复原 |
| 点校本校改 | 不改 | 差异处是点校者以〔〕补改、以（）删的字；底本保留原貌 |
| 异文 | 不改 | 两通的版本异文、通假、古今字、异体字 |
| 体例差异 | 不改 | 小标题、卷题、表格、注、赞语位置、分篇方式等编排不同 |
| 校本问题 | 不改 | 校本自身残缺、有误或没对齐 |
| 存疑 | 不改 | 判不了，留待人工 |

## 遇到的问题

### 一、底本（维基文库录文）的错

- **繁转简造成的误字**：繁转简时把形近或同源的字转错，例如「汜水」作「泛水」、「长安西市」的「市」作「巿」（蔽膝的「巿」）。这类错误整批出现，不像抄写错误那样零散。
- **形近、音近的录入错误**：例如「愿从者十余人」作「愿从诸十余人」、「彭越」作「彭城」、「汝为将」作「奴为将」，以及若干不成字义的替换字（如「钛」「饨」「轺」，原字分别是𦋺、匄、㥦）。生僻字和扩展区汉字（𡰥、𦋺、𢢀 等）在录文时最容易被替换成形近的常用字。
- **整段脱失**：底本有时整段漏抄。例如《史记·卫康叔世家》从灵公五年到蒯聩出奔一大段、《汉书·扬雄传》所列《法言》十三篇的篇目、《汉书·萧望之传》「前弘恭奏望之等狱决」两段。这些都在相邻段落补回，没有新增 PN。
- **注文混入正文**：《史记》的三家注（「集解徐广曰……」）没加任何标记就混进正文；《汉书》里录文者的校语（「一作某」「一多某字」）也混进了正文。按体例一律用〈〉括出，不删。
- **错乱**：字序颠倒（「轻钱」作「钱轻」），或者校语插进正文时连带吞掉了相邻的字（「睚眦之意」作「睚真谖」）。
- **汉书卷五十七重复**：维基文库卷五十七上、下两页都收了全卷，导入后 057、058 两章逐字相同。现已按点校本和颜注「自喻巴蜀之后分为下卷」在「相如为郎数岁」处重新分卷，相关 PN 已重挂。

### 二、导入程序的错（二校顺带查出）

- **繁简保护字丢失**：维基文库用 `-{X}-` 标记不做繁简转换的字，原导入程序把这些字整字丢掉了，约 4,800 字。这是二校时发现的，已在导入程序里修复，没有靠改字表逐条补。
- **分章行号偏移**：段内换行没有按实际行数计入章节表，偏移逐章累积，导致左传文公七年以后、汉书各卷赞语被分到了错误的章。修复后重建了章节页，旧 PN 到新 PN 的对照另行保存，词条和问答里的引用已同步重挂。

### 三、校本一侧的问题

- 判为「校本问题」的条目汉书最多（1,148 条），主要原因是校本缺卷、残缺或没对齐。例如《汉书·窦田灌韩传》校本只对上 1,185 字（底本 6,318 字），这些差异不能当作底本的错。
- 相似度低于 90% 的章集中在表和志（史记各年表、汉书诸侯王表、功臣表、百官公卿表、古今人表、地理志、艺文志）。底本把表格逐行转成段落、单元格用「｜」分隔，行序和取舍都与点校本的排版不同。这类差异大多判为体例差异，不改。

### 四、不改的大头

- **用字差异**占差异的大多数，例如左传 唯→惟 140 次、史记 乃→迺 165 次、汉书 迺→乃 155 次、并→幷 116 次。底本保留维基文库所据版本的用字，不向点校本统一。彊、迺、菑等古字和通假字一律保留。
- **点校本校改**（史记 156 条、汉书 406 条）：点校者依据他本补改或删去的字，底本保留原貌，即使点校本的意见是对的。这样可以保证底本反映的是所据版本本身，而不是点校成果。左传的校本《春秋左传诂》不用〔〕（）记号，所以这一类是 0。
